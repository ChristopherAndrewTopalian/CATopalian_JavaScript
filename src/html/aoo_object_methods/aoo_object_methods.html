Embedded Action Protocols (Methods)

In JavaScript, Objects aren't just filing cabinets for static data like text or numbers. They can also store living instructions. When a function is placed inside an Object, it is called a Method.

By embedding anonymous functions directly inside our Array of Objects, we can give every vessel its own unique behavior or communication protocol. This perfectly binds our data to our actions and completely eliminates the need for dangerous legacy commands like eval(), keeping our fleet secure and our codebase perfectly organized. 

// Example 1: Defining the Fleets Action Protocols

// We predefine our worldwide command functions
function redAlert() 
{
    console.log("Shields up! Weapons online!");
}

function standardHail() 
{
    console.log("Hailing on all frequencies...");
}

function transmit(message) 
{
    console.log("Transmission sent: " + message);
}

// We embed anonymous functions into the action property of each ship
let starfleet = [
    {
        registry: "Enterprise",
        class: "Cruiser",
        action: function() {
            standardHail();
        }
    },
    {
        registry: "Defiant",
        class: "Escort",
        action: function() {
            redAlert();
        }
    },
    {
        registry: "Voyager",
        class: "Intrepid",
        action: function() {
            transmit("Janeway to Starfleet Command. We are home.");
        }
    }
];

// If we manually call the Defiants action, it triggers redAlert()
starfleet[1].action();
// Result: Shields up! Weapons online!

// Example 2: Generating a Tactical Control Panel

function makeInterface() 
{
    // We use a traditional, high-speed for loop to read the registry
    for (let i = 0; i < starfleet.length; i++) 
    {
        // We create a button for the current ship
        let shipBtn = document.createElement('button');
        shipBtn.textContent = "Command " + starfleet[i].registry;
        
        // We bind the button click directly to the ships embedded action
        shipBtn.onclick = function() 
        {
            starfleet[i].action(); 
        };
        
        // We append the button to the interface
        document.body.append(shipBtn);
    }
}

makeInterface();
/* 
Result: 3 Interface Buttons are generated on the screen.
Clicking "Command Enterprise" outputs: "Hailing on all frequencies..."
Clicking "Command Defiant" outputs: "Shields up! Weapons online!"
Clicking "Command Voyager" outputs: "Transmission sent: Janeway to Starfleet Command. We are home."
*/

Syntax 

let objectName = {
    propertyName: "String Data",
    methodName: function() {
        // Execute commands here
    }
};

objectName.methodName();

Return Value

Type: Varies. The method will return whatever the embedded function is programmed to return. If there is no explicit return statement, it simply executes the code and returns undefined.

Description:

Embedding anonymous functions into Objects is the bedrock of modern User Interface design. Instead of writing massive, complex if/else statements to figure out which button was clicked, we simply tell the button to look at its corresponding Object and execute whatever protocol is stored inside the action property. This makes the code highly modular, if we add 100 new ships to the array, the for loop automatically generates 100 new working buttons without us having to write a single extra line of logic!
