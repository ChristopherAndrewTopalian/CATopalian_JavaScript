Math.floor()

The Math.floor() method stands for "Floor." While the ceiling method pushes numbers up, the floor method forces numbers down to the nearest whole integer. We use this constantly for resource management and safety protocols! If our tactical computers calculate that we have enough emergency battery power for 4.9 lightyears of travel, we cannot safely plot a course for 5 lightyears. We must round down to the solid floor of 4 complete lightyears to ensure the crew arrives safely without running out of power in the middle of deep space. 

let totalPowerReserves = 49;
let powerPerJump = 10;

// A raw division gives us a decimal fraction.
let theoreticalJumps = totalPowerReserves / powerPerJump;

console.log(theoreticalJumps); 
// Result: 4.9 (We do not have enough power to complete that 5th jump!)

// We use Math.floor() to always round down to the nearest safe integer.
let safeJumps = Math.floor(theoreticalJumps);

console.log(safeJumps);
// Result: 4 (We can safely execute 4 complete jumps.)

// Watch closely how it handles negative coordinates. 
// It rounds DOWN, meaning it moves further away from zero into negative space!
console.log(Math.floor(-7.2)); // Result: -8

// Let us create a standard function to calculate deployable defense satellites:
function calculateSatellites(cargoBayVolume, satelliteVolume) {
    let deployableUnits = Math.floor(cargoBayVolume / satelliteVolume);
    console.log("Tactical, we can fully assemble and deploy " + deployableUnits + " satellites.");
}

calculateSatellites(150, 40); 
// Result: Tactical, we can fully assemble and deploy 3 satellites.

Syntax 

Math.floor(x)

Return Value

Type: Number (The largest integer that is less than or equal to the given number.)

Description:

In mathematics, the floor function maps a real number to the largest previous integer. Math.floor() is a standard static method, meaning we never create a "new Math" object; we simply call it directly from the ships database. It is vital for our engineers to note that if the number is already a perfect integer (like 5), or if we pass it exactly 0 or -0, it returns that exact same number without changing it. If our sensors malfunction and pass it text that cannot be converted to a number, it will protect the system by returning NaN (Not-a-Number).
