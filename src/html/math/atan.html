Math.atan()

The Math.atan() method stands for "Arctangent." In game development, this is our classic "Slope Decoder." When we know the slope of a target's trajectory on our 2D radar grid (how far it moves up divided by how far it moves sideways), we feed that number into this method. It calculates the exact angle we need to point our ship or our weapon turrets! 

// A target is moving across our local grid.
// For every 1 kilometer it moves forward (X), it moves 1 kilometer up (Y).
// The slope is 1 divided by 1, which equals 1.0!
let targetSlope = 1.0;

// We ask the targeting computer to find the angle of that slope:
let angleInRadians = Math.atan(targetSlope);

console.log(angleInRadians); 
// Result: 0.785398... (The computer calculates in Radians!)

// The Professional Solution: We translate Radians into Degrees!
let angleInDegrees = angleInRadians * (180 / Math.PI);

// We round the number so it looks clean on our tactical UI.
console.log(Math.round(angleInDegrees));
// Result: 45 (Turret locked! Point exactly at a 45-degree angle!)

// Math.atan() easily handles massive numbers and negative slopes!
let divingSlope = -1.0;
let divingAngle = Math.atan(divingSlope) * (180 / Math.PI);

console.log(Math.round(divingAngle));
// Result: -45 (The target is diving down at a 45-degree angle!)

Syntax 

Math.atan(x)

Return Value

Type: Number (The arctangent of the given number, returned in radians between -Pi/2 and Pi/2.)

Description:

The Math.atan() method is a foundational tool for rotating objects in a 2D space. It takes a single number representing a slope and returns the angle in radians. Because it only accepts one number (the already-calculated slope), it has a hidden limitation: it cannot tell the difference between a target moving forward and up, versus a target moving backward and down (because a negative divided by a negative is still a positive slope!). Just like all our trigonometry functions, we must remember to multiply the result by (180 / Math.PI) to translate the computer's radians into human-readable degrees for our user interfaces.
