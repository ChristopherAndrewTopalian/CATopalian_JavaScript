Math.abs()

The Math.abs() method stands for "Absolute Value." It acts as a mathematical magnitude filter. If we give it a negative number, it instantly strips away the minus sign and returns the positive version of that number. If we give it a positive number, it leaves it completely alone. We universally use this in game engines to calculate the true distance between two coordinates! 

let starshipZ = 450;
let spatialAnomalyZ = 800;

// Standard math might give us a negative number if we subtract in the wrong order!
let rawCalculation = starshipZ - spatialAnomalyZ;

console.log(rawCalculation); 
// Result: -350 (Sensors failing: distance cannot be negative!)

// The Professional Solution: We use Math.abs() to get the absolute magnitude!
let trueDistance = Math.abs(starshipZ - spatialAnomalyZ);

console.log(trueDistance);
// Result: 350 (The anomaly is exactly 350 units away, regardless of direction.)

// It also works directly on raw numbers:
console.log(Math.abs(-99.5)); // Result: 99.5
console.log(Math.abs(42));    // Result: 42

Syntax 

Math.abs(x)

Return Value

Type: Number (The absolute, positive value of the given number.)

Description:

In mathematics, the absolute value of x is written as |x|. It represents the distance of a number from zero on a number line, which means it is physically impossible for it to be negative. Math.abs() is a static method, meaning we never create a "new Math" object; we simply call it directly. It is a critical tool for collision detection in game development. If we pass an empty string or an empty array into this method, it will secretly convert it to a 0. If we pass it text that cannot be converted into a number, it will return NaN (Not-a-Number).
