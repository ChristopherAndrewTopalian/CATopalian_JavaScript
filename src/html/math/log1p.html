Math.log1p()

The Math.log1p() method stands for "Natural Logarithm of 1 plus the number." This is a highly specialized tracking tool! When we are sweeping the sector for the microscopic energy emissions of a cloaked vessel, the raw sensor numbers are incredibly tiny—so close to zero that standard math might round them away into nothingness. If we manually add 1 to these tiny numbers before taking the standard natural logarithm, the ship's computer can lose precision. We use Math.log1p() to perform the calculation internally, preserving absolute microscopic accuracy so the cloaked ship cannot slip past our defenses! 

// Sensors pick up a microscopic tachyon fluctuation.
let tachyonSignal = 1e-15; // This is 0.000000000000001

// If we do this the standard way, floating-point math loses precision:
let standardMath = Math.log(1 + tachyonSignal);

console.log(standardMath); 
// Result: 1.1102230246251565e-15 (Inaccurate! The target lock is drifting!)

// We use Math.log1p() to get the true, highly precise value:
let preciseMath = Math.log1p(tachyonSignal);

console.log(preciseMath);
// Result: 9.999999999999995e-16 (Perfect precision! Target locked!)

// Let's build a sensor sweep function to detect cloaked ships:
function sweepForCloak(fluctuation) {
    let trueSignature = Math.log1p(fluctuation);
    
    if (trueSignature > 0) {
        console.log("Alert! Cloaked vessel detected at signature level: " + trueSignature);
    } else {
        console.log("Sector clear. No tachyon emissions detected.");
    }
}

sweepForCloak(0.000000005);
// Result: Alert! Cloaked vessel detected at signature level: 4.999999987500001e-9

Syntax 

Math.log1p(x)

Return Value

Type: Number (The natural logarithm of 1 plus the given number.)

Description:

Math.log1p() is a static method that is the mathematical inverse of Math.expm1(). It evaluates the expression Math.log(1 + x) but does so in a way that avoids rounding errors when x is extremely close to zero. If we pass it 0, it will confidently return 0. If we pass it exactly -1, it returns -Infinity. However, just like standard logarithms, if we pass it a number lower than -1, it represents a physical impossibility for our sensors, and it returns NaN (Not-a-Number).
