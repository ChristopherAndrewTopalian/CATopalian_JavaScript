Math.trunc()

The Math.trunc() method stands for "Truncate." In engineering, to truncate something means to chop off the end of it. Sometimes during a mission, we don't want the computer to politely round a number up or down, we just want it to take a laser scalpel and completely slice away the decimal! If our matter fabricator says we have enough raw material to print 4.9 warp coils, we only actually have 4 complete, usable coils. The rest is just scrap. Math.trunc() instantly strips away that fractional scrap and gives us the pure, whole number we can rely on! 

// Engineering is printing emergency warp coils.
let coilMaterial = 4.99; 

// We use Math.trunc() to find out how many complete coils we get.
let completeCoils = Math.trunc(coilMaterial);

console.log(completeCoils); 
// Result: 4 (It completely ignored the .99! We only have 4 solid coils.)

// Watch how it handles negative space differently than Math.floor()!
// Math.floor(-4.5) would push the number down to -5.
// Math.trunc() just chops the decimal off, leaving the core number intact:
console.log(Math.trunc(-4.5)); 
// Result: -4 (Perfect for isolating grid sectors in negative coordinate space!)

// Let us create a logistics function for the cargo bay:
function countCompleteCrates(rawTonnage, crateCapacity) {
    let exactYield = rawTonnage / crateCapacity;
    let sealedCrates = Math.trunc(exactYield);
    
    console.log("Logistics: We have securely packed " + sealedCrates + " complete crates for transport.");
}

countCompleteCrates(1050, 100); 
// Result: Logistics: We have securely packed 10 complete crates for transport.

Syntax 

Math.trunc(x)

Return Value

Type: Number (The integer part of the given number.)

Description:

Math.trunc() is a highly efficient static method that simply removes any fractional digits from a number. It does not round the number at all. Because it simply drops the decimal, it behaves slightly differently than Math.floor() when dealing with negative numbers, making it incredibly useful for finding absolute coordinates without shifting the target further away. If we pass it 0 or an empty string, it returns 0. If we pass it text that cannot be evaluated, the ship's computer returns NaN (Not-a-Number).
