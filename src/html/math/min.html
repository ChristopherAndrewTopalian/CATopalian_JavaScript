Math.min()

The Math.min() method stands for "Minimum." When we are coordinating defenses on the bridge, we often need to find the smallest value in a vast sea of data. If our radar tracks several incoming rogue asteroids and we need to know which one will cross our path first, we are looking for the shortest distance! We use this method to instantly compare a list of numbers and return only the absolute lowest value. It is critical for calculating minimum safe distances and identifying our most immediate, close-range priorities! 

// Tactical tracks three rogue asteroids on an intercept course.
let asteroidAlphaDist = 1200; // Kilometers away
let asteroidBetaDist = 450;
let asteroidGammaDist = 3100;

// We use Math.min() to instantly find the closest, most urgent threat.
let closestAsteroid = Math.min(asteroidAlphaDist, asteroidBetaDist, asteroidGammaDist);

console.log(closestAsteroid); 
// Result: 450 (Asteroid Beta is the closest and needs immediate attention!)

// Just like with Math.max(), we can use the "spread" operator (...) to scan an array.
// Let's check our various cargo bays to see which one has the lowest power level.
let cargoBayPowerLevels = [85, 92, 41, 78, 99];
let lowestPower = Math.min(...cargoBayPowerLevels);

console.log(lowestPower);
// Result: 41 (One of our bays is dropping to 41% power, we should reroute energy!)

// Let us create a standard function for the navigation team:
function verifySafeDistance(shipA, shipB, shipC) {
    let nearestVessel = Math.min(shipA, shipB, shipC);
    console.log("Navigation, our nearest neighbor is exactly " + nearestVessel + " km away.");
}

verifySafeDistance(5000, 2200, 8900); 
// Result: Navigation, our nearest neighbor is exactly 2200 km away.

Syntax 

Math.min(value1, value2, ...)

Return Value

Type: Number (The smallest of the given numbers.)

Description:

Math.min() is the direct counterpart to the maximum method. It takes any amount of numbers separated by commas, evaluates them all, and returns the lowest one. If any of the values we pass to it cannot be converted into a number by the ship's computer, the entire calculation fails and returns NaN (Not-a-Number). Fascinatingly, if we call Math.min() and give it no arguments at all, the computer returns Infinity. This is the exact opposite of what happens when we pass empty arguments to the maximum method!
