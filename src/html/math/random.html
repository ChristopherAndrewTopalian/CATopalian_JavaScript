Math.random()

The Math.random() method stands for "Random." When we are running combat simulations or programming our ship's automated evasive maneuvers, we absolutely cannot have our flight paths be perfectly predictable! If our movements are a simple, repeating pattern, a hostile targeting computer will easily lock onto our hull. We use this method to introduce pure unpredictability. By itself, it only generates a tiny decimal number, but by multiplying it, we can create random coordinates anywhere on the tactical grid, keeping our ship completely unpredictable and safe from attack! 

// The computer generates a raw, unpredictable decimal.
let evasiveFactor = Math.random();

console.log(evasiveFactor); 
// Result: 0.458291048... (A completely random decimal between 0 and 1)

// To make it useful for navigation, we multiply it by our grid size (e.g., 100 kilometers).
let randomGridCoordinate = Math.random() * 100;

console.log(randomGridCoordinate);
// Result: 73.81930... (A random coordinate somewhere between 0 and 99.999...)

// For a clean whole number, we combine it with our old friend, Math.floor()!
let pureCoordinate = Math.floor(Math.random() * 100);

console.log(pureCoordinate);
// Result: 73 (A perfect, whole-number random coordinate!)

// Let us create an evasive maneuver function for the helm:
function executeEvasivePattern() {
    let randomX = Math.floor(Math.random() * 500);
    let randomY = Math.floor(Math.random() * 500);
    console.log("Helm, initiate Evasive Pattern! Target new coordinates: X-" + randomX + " / Y-" + randomY);
}

executeEvasivePattern(); 
// Result: Helm, initiate Evasive Pattern! Target new coordinates: X-342 / Y-115

Syntax 

Math.random()

Return Value

Type: Number (A floating-point, pseudo-random number between 0 (inclusive) and 1 (exclusive).)

Description:

Math.random() is a static method that takes zero arguments. Every time we call it, the ship's computer generates a floating-point number from 0 up to, but not including, 1. This means it might occasionally generate a perfect 0, but it will never generate a perfect 1 (the highest it goes is 0.999...). Because computers are highly logical machines, true randomness is technically impossible; therefore, this method produces what we call "pseudo-random" numbers based on an incredibly complex underlying algorithm. It is the absolute best tool we have for generating unpredictable scenarios!
