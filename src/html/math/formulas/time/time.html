How It Works: The Code

Beginner Level: The Pure Math

At its core, calculating time is just taking the total distance and dividing it by your speed. In a vacuum, the code is beautifully simple: 

function calculateTime(distance, speed) {
    let time = distance / speed;
    return time;
}

Pro Level: Sanitizing the Inputs

Out in the real universe, users make mistakes. They might accidentally type a letter, or leave a box empty. A Pro-level function sterilizes the data first to ensure the ship's computer doesn't crash! 

function calculateTimePro(distance, speed) {
    let cleanDistance = Number(distance);
    let cleanSpeed = Number(speed);

    // Ensure we don't divide by zero!
    if (isNaN(cleanDistance) || isNaN(cleanSpeed) || cleanSpeed === 0) {
        return "Invalid Sensor Data";
    }

    return Math.round(cleanDistance / cleanSpeed);
}
