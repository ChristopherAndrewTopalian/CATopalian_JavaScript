Calculate: Time to Intercept

In the heat of battle, knowing exactly when your ordnance will strike the enemy is the difference between victory and defeat. If a Klingon Bird of Prey is attempting to retreat, and Tactical fires a photon torpedo, we need to know exactly how many seconds it will take for the torpedo to cross the void and make impact. By dividing the distance to the target by the speed of our torpedo, we find our exact time to intercept! 

// Tactical Function: Calculate Time to Intercept
// Formula: Time = Distance / Speed

function calculateImpactTime(targetDistance, torpedoSpeed) {
    // We divide the total distance by how fast the torpedo is traveling
    let secondsToImpact = targetDistance / torpedoSpeed;
    
    // We use Math.round() to keep the tactical display clean!
    let cleanTime = Math.round(secondsToImpact);
    
    console.log("Torpedo away! Impact in exactly " + cleanTime + " seconds.");
    return cleanTime;
}

// A Klingon ship is 15,000 kilometers away.
// Our torpedo travels at 2,500 kilometers per second.
calculateImpactTime(15000, 2500); 
// Result: Torpedo away! Impact in exactly 6 seconds.

The Math Behind the Code:

Kinematics: t = d / v

This function relies on the fundamental physics equation where Time (t) equals Distance (d) divided by Velocity or Speed (v). In scripting, isolating this into a simple function with only two inputs makes it incredibly easy for the ship's main computer to run this calculation thousands of times a second for multiple targets without crashing the system!
