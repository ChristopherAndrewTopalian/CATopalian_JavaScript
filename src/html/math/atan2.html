Math.atan2()

The Math.atan2() method stands for "Arctangent 2-Argument." In our game engines, this is our "Omnidirectional Targeting System." Instead of just taking a raw slope, it takes the exact X and Y coordinates of a target on our radar. Because it has both coordinates, it never gets confused about whether the target is in front of us or behind us, giving us a flawless 360-degree firing angle! 

// A Romulan warbird drops out of cloak behind us and below us!
// Its coordinates on our local grid: X is -5, Y is -5.
let targetX = -5;
let targetY = -5;

// THE FATAL TRAP: 
// Math.atan2() asks for the Y coordinate FIRST, and the X coordinate SECOND!
let angleInRadians = Math.atan2(targetY, targetX);

// The Professional Solution: We translate Radians into Degrees!
let angleInDegrees = angleInRadians * (180 / Math.PI);

console.log(Math.round(angleInDegrees));
// Result: -135 (Turret locked! Pointing down and backward to fire!)

// Let's see what the old Math.atan() would have done with that slope (-5 / -5 = 1):
let oldMethodAngle = Math.atan(1) * (180 / Math.PI);
console.log(Math.round(oldMethodAngle));
// Result: 45 (The old method would have fired forward into empty space!)

Syntax 

Math.atan2(y, x)

Return Value

Type: Number (The exact angle in radians between the positive X-axis and the given point, ranging from -Pi to Pi.)

Description:

This method is universally used to make objects point at the user's mouse cursor or track moving enemies. By feeding it both the vertical (Y) and horizontal (X) distances to a target, Math.atan2() maps the exact angle across all four quadrants of a 2D grid. The absolute most important rule we must memorize is the Parameter Order Trap: almost everywhere else in mathematics and programming, coordinates are written as (X, Y). But this specific method requires the y coordinate to be passed in first, followed by the x coordinate! If we accidentally flip them, our game objects will rotate completely backward!
