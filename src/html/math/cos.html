Math.cos()

The Math.cos() method stands for "Cosine." In our navigational computers, we use this mathematical function to figure out the exact horizontal position (the X-coordinate) of an object relative to us, based on its angle and distance. If we send a scout ship out at a specific angle, Math.cos() tells us exactly how far left or right they have traveled on our tactical grid. It is an essential building block for creating circular movement, radar sweeps, and advanced flight paths in our simulation engines! 

// In JavaScript, trigonometric functions always expect angles in "radians", not degrees.
// First, we create a standard function to convert degrees into radians for the main computer.
function degreesToRadians(degrees) {
    return degrees * (Math.PI / 180);
}

// Now, let's track a scout ship.
let distance = 5000; // The scout ship is 5000 kilometers away.
let flightAngle = 60; // They launched at a 60-degree angle.

// Convert the angle, then calculate the horizontal X-coordinate using Math.cos()
let radians = degreesToRadians(flightAngle);
let horizontalPosition = distance * Math.cos(radians);

console.log(horizontalPosition); 
// Result: 2500.0000000000005 (The scout ship is precisely 2500 km to our "right" on the X-axis)

// We can wrap this up in a neat function for the tactical console:
function calculateXTarget(targetDistance, targetAngle) {
    let rad = degreesToRadians(targetAngle);
    let xCoord = targetDistance * Math.cos(rad);
    
    // We can even round it off so the display is clean!
    console.log("Target's horizontal X-coordinate is: " + Math.round(xCoord));
}

calculateXTarget(10000, 180);
// Result: Target's horizontal X-coordinate is: -10000 (Exactly 10000 km to our "left")

Syntax 

Math.cos(x)

Return Value

Type: Number (Returns a numeric value between -1 and 1, which represents the cosine of the angle.)

Description:

The Math.cos() static method returns the cosine of the specified angle. It is important to remember that the parameter x must be an angle measured in radians, not degrees. If we pass a 0 into it, it returns 1. If we pass it Math.PI (which is 180 degrees), it returns -1. By multiplying this baseline -1 to 1 result by our total distance (the radius or hypotenuse), we scale it up to find our true position on the grid. If we feed the method empty strings or non-numeric data, our ship's computer will return NaN (Not-a-Number).
