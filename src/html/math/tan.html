Math.tan()

The Math.tan() method stands for "Tangent." This is the final piece of our primary trigonometry trio! While sine and cosine are perfect for mapping circular radar sweeps, tangent is uniquely suited for calculating ratios and steep slopes. If our ship is holding a high orbital altitude and we need to beam an away team down to a planetary anomaly, our sensors often give us our current altitude and the downward angle of our scanners. By using Math.tan() on that angle, we instantly calculate the exact horizontal distance along the planet's surface to the target! 

// Just like with sine and cosine, we must convert our angles into "radians" first.
// We keep our trusty conversion function ready:
function degreesToRadians(degrees) {
    return degrees * (Math.PI / 180);
}

// Our ship is in high orbit, exactly 800 kilometers above the planet's surface.
let orbitalAltitude = 800; 
// Scanners lock onto a target at a 45-degree downward angle.
let targetingAngle = 45;

// Convert the angle, then calculate the surface distance using Math.tan()
let radians = degreesToRadians(targetingAngle);
let surfaceDistance = orbitalAltitude * Math.tan(radians);

console.log(surfaceDistance); 
// Result: 799.9999999999999 (The target is exactly 800 km along the surface from our position!)

// Let us create an orbital targeting function for the tactical station:
function calculateSurfaceTarget(altitude, angle) {
    let rads = degreesToRadians(angle);
    // We use Math.round() to keep the tactical display completely clean!
    let horizontalDist = Math.round(altitude * Math.tan(rads));
    
    console.log("Orbital lock confirmed. Surface target is " + horizontalDist + " km from our nadir point.");
}

calculateSurfaceTarget(1000, 60);
// Result: Orbital lock confirmed. Surface target is 1732 km from our nadir point.

Syntax 

Math.tan(x)

Return Value

Type: Number (Returns a numeric value that represents the tangent of the angle.)

Description:

The Math.tan() static method returns the tangent of a given angle. It evaluates the mathematical ratio of the sine of an angle divided by its cosine. Just like our other trig functions, it is crucial that the parameter x is an angle measured in radians, not degrees. If we pass it 0, it returns exactly 0. If our sensors malfunction and we pass it text that cannot be processed mathematically, the ship's computer protects itself by returning NaN (Not-a-Number).
