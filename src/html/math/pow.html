Math.pow()

The Math.pow() method stands for "Power." When we need to calculate massive, multiplying numbers on the fly, this is our primary tool. If the tactical team is arming a photon torpedo with a base yield of 10, and they set the magnetic compression to level 3, the computer does not just multiply 10 by 3. It raises 10 to the power of 3 (10 * 10 * 10). We use this method constantly in engineering to calculate explosive blast radiuses, shield grid harmonics, and thruster output curves! 

// Tactical is arming a compressed photon torpedo.
let baseYield = 10; // 10 megatons of base energy
let compressionLevel = 3; // Compressing the energy 3 times over

// We use Math.pow() to find the total explosive yield.
let totalBlastYield = Math.pow(baseYield, compressionLevel);

console.log(totalBlastYield); 
// Result: 1000 (The torpedo will output an incredible 1,000 megatons of energy!)

// We can also use it to calculate shield harmonics! 
// A base frequency of 2, layered 8 times:
console.log(Math.pow(2, 8)); 
// Result: 256 (The shields are operating at 256 terajoules!)

// Let's create a standard engineering function to boost our deflectors:
function boostDeflectors(basePower, gridMultiplier) {
    let shieldCapacity = Math.pow(basePower, gridMultiplier);
    console.log("Deflectors boosted! Total shield capacity is now " + shieldCapacity + " terajoules.");
}

boostDeflectors(5, 4); 
// Result: Deflectors boosted! Total shield capacity is now 625 terajoules.

Syntax 

Math.pow(base, exponent)

Return Value

Type: Number (Returns the base raised to the exponent power.)

Description:

Math.pow() is a highly versatile static method that takes exactly two arguments: the base number first, followed by the exponent. It evaluates the mathematical expression baseexponent. It is fascinating to note that if we pass an exponent of 0, it will always return 1, no matter how massive the base number is. If we pass an exponent of 1, it simply returns the exact same base number we started with. However, if the ship's computer cannot convert one of our arguments into a valid number, the method will fail and return NaN (Not-a-Number).
