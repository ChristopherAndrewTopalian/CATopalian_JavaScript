Math.sin()

The Math.sin() method stands for "Sine." In our tactical systems, it acts as the vital partner to the cosine method. While cosine calculates the horizontal left-or-right position of a target, the sine method calculates the vertical up-or-down position (the Y-coordinate) based on its angle and distance from our ship. By using both of these methods together, we can track the exact circular orbit of a satellite or plot a perfect sweeping pattern for our radar dishes! 

// Just like with cosine, we must convert our angles into "radians" first.
// We keep this standard conversion function handy in the computer core:
function degreesToRadians(degrees) {
    return degrees * (Math.PI / 180);
}

// Let us track a satellite currently in orbit around our ship.
let distance = 5000; // The satellite is 5000 kilometers away.
let orbitalAngle = 30; // It is currently at a 30-degree angle on the grid.

// Convert the angle, then calculate the vertical Y-coordinate using Math.sin()
let radians = degreesToRadians(orbitalAngle);
let verticalPosition = distance * Math.sin(radians);

console.log(verticalPosition); 
// Result: 2499.9999999999995 (The satellite is exactly 2500 km "up" on the Y-axis)

// Let us build a targeting function that maps both X and Y coordinates!
function lockOnTarget(targetDist, targetAngle) {
    let rads = degreesToRadians(targetAngle);
    
    // We use Math.cos() for the X-axis and Math.sin() for the Y-axis!
    let xCoord = Math.round(targetDist * Math.cos(rads));
    let yCoord = Math.round(targetDist * Math.sin(rads));
    
    console.log("Target locked at grid coordinates: X:" + xCoord + " / Y:" + yCoord);
}

lockOnTarget(10000, 90);
// Result: Target locked at grid coordinates: X:0 / Y:10000 (Exactly 10000 km straight ahead!)

Syntax 

Math.sin(x)

Return Value

Type: Number (Returns a numeric value between -1 and 1, which represents the sine of the angle.)

Description:

The Math.sin() static method returns the sine of a given angle. It is crucial for the navigation team to remember that the parameter x must be an angle measured in radians, not degrees. If we pass exactly 0 into it, it returns 0 (meaning there is no vertical elevation at a 0-degree angle). If we pass it Math.PI / 2 (which is exactly 90 degrees), it returns 1 (maximum vertical height). By multiplying this -1 to 1 range by our radar's distance, we map out exact physical coordinates. If our systems feed it non-numeric text, it returns NaN (Not-a-Number).
