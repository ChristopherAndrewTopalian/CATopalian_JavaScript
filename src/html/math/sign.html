Math.sign()

The Math.sign() method stands for "Sign." On the tactical bridge, tracking target vectors is critical for our survival. When an object is detected, the computer often registers its speed relative to our position. A positive speed means it is traveling away, a negative speed means the gap is closing and it is heading right toward us, and zero means it is holding position. In high-stakes situations, we use this method to strip away the complex speed calculations and instantly determine pure trajectory. It simply tells us if a number is positive, negative, or zero! 

// Tactical tracks the relative velocities of three contacts.
let contactAlphaVelocity = -8500; // Kilometers per hour (Closing in!)
let contactBetaVelocity = 4200;   // Kilometers per hour (Moving away)
let contactGammaVelocity = 0;     // Holding steady

// We use Math.sign() to instantly determine their trajectories.
let alphaTrajectory = Math.sign(contactAlphaVelocity);

console.log(alphaTrajectory); 
// Result: -1 (Red Alert! The target is approaching!)

console.log(Math.sign(contactBetaVelocity));
// Result: 1 (The target is retreating.)

// Let us create an automated defense function based on trajectory:
function assessThreatVector(relativeVelocity)
{
    let trajectory = Math.sign(relativeVelocity);
    
    if (trajectory === -1) {
        console.log("Warning! Target is on an approach vector. Raise shields!");
    } else if (trajectory === 1) {
        console.log("Target is moving away. Stand down from Red Alert.");
    } else {
        console.log("Target is stationary. Keep weapons locked.");
    }
}

assessThreatVector(-300); 
// Result: Warning! Target is on an approach vector. Raise shields!

Syntax 

Math.sign(x)

Return Value

Type: Number (Returns 1, -1, 0, -0, or NaN to indicate the sign of the given number.)

Description:

Math.sign() is a highly efficient static method that tells us whether a number is positive or negative. It ignores the actual magnitude of the number entirely. If we pass it a positive number (like 45 or 0.002), it returns exactly 1. If we pass it a negative number (like -9 or -1000), it returns exactly -1. Interestingly, the ship's computer differentiates between positive and negative zero in its core programming, so passing 0 returns 0, and passing -0 returns -0. As always, passing non-numeric text causes the method to return NaN (Not-a-Number).
