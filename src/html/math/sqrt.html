Math.sqrt()

The Math.sqrt() method stands for "Square Root." In our engineering and damage control departments, we constantly deal with flat 2D surfaces. If a micrometeorite causes a hull breach and we deploy an emergency square forcefield, the generator usually tells us its total energy output in square meters. To make sure the forcefield will actually fit over the breach, we need to reverse-engineer that total area to find the exact length of its sides. Math.sqrt() instantly calculates this! It is one of the most heavily used functions on the ship, forming the foundation of distance and area calculations. 

// Engineering is deploying a square emergency forcefield.
let totalShieldArea = 144; // The generator outputs exactly 144 square meters.

// We use Math.sqrt() to calculate the length of one side of the forcefield.
let shieldSideLength = Math.sqrt(totalShieldArea);

console.log(shieldSideLength); 
// Result: 12 (Each side of the forcefield is exactly 12 meters long! It fits!)

// What if the generator outputs 400 square meters?
console.log(Math.sqrt(400));
// Result: 20 (A massive 20x20 meter forcefield!)

// Let us create a standard damage control function to automatically calculate coverage:
function calibrateForcefield(areaOutput) {
    let sideLength = Math.sqrt(areaOutput);
    console.log("Damage Control: Forcefield calibrated. Coverage spans exactly " + sideLength + " meters per side.");
}

calibrateForcefield(81); 
// Result: Damage Control: Forcefield calibrated. Coverage spans exactly 9 meters per side.

Syntax 

Math.sqrt(x)

Return Value

Type: Number (The square root of the given number.)

Description:

Math.sqrt() is a standard static method that reverses multiplication for identical numbers (since 12 * 12 = 144, the square root of 144 is 12). However, it is vital for our engineers to remember a core rule of physics in this universe: you cannot multiply a number by itself and get a negative result. Because of this, if we attempt to pass a negative number into Math.sqrt(), the ship's computer recognizes it as a mathematical impossibility and immediately returns NaN (Not-a-Number). If we pass it 0, it returns exactly 0.
