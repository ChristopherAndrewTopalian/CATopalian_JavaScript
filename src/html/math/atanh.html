Math.atanh()

The Math.atanh() method stands for "Hyperbolic Arctangent." In our engineering bay, we use this as our "Subspace Compression Calculator." It measures how much energy is required to contain a warp field based on a compression ratio. The absolute most important rule is that this ratio must stay strictly between -1 and 1. If it hits exactly 1, the energy goes infinite! 

// Engineering reports a subspace compression ratio of 0.5.
let compressionRatio = 0.5;

// We ask the main computer to calculate the required containment energy:
let containmentEnergy = Math.atanh(compressionRatio);

console.log(containmentEnergy); 
// Result: 0.549306... (Containment field is stable!)

// THE FATAL TRAP: The ratio absolutely cannot reach 1.0 or higher!
// What happens if the ratio hits exactly 1.0?
let criticalRatio = Math.atanh(1);

console.log(criticalRatio);
// Result: Infinity (Warp core breach! Infinite energy required!)

// What if the ratio exceeds the physical limits of the universe?
let impossibleRatio = Math.atanh(2);

console.log(impossibleRatio);
// Result: NaN (Physics breakdown! The engine physically crashes!)

Syntax 

Math.atanh(x)

Return Value

Type: Number (The hyperbolic arctangent of the given number. Returns Infinity if 1, -Infinity if -1, and NaN if outside the -1 to 1 range.)

Description:

In advanced physics simulations, Math.atanh(x) is used to calculate limits. Mathematically, it is equivalent to the formula 1/2 * ln((1 + x) / (1 - x)). The most critical engineering lesson for this method is its microscopic domain. The value of x must be greater than -1 and less than 1. If we feed it exactly 1 or -1, we hit a vertical asymptote, and JavaScript returns Infinity or -Infinity. If we pass a number greater than 1 or less than -1, the equation becomes impossible to solve in real numbers, and the system immediately returns NaN to warn us that our math has failed!
