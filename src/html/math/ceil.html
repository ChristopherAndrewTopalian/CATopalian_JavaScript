Math.ceil()

The Math.ceil() method stands for "Ceiling." Whenever our navigational computers or life-support sensors return a decimal, but we absolutely need a whole number, we use this function to round up to the next highest integer. It is crucial for Starfleet logistics! If we calculate that we need 4.2 shuttlecraft to evacuate a scientific outpost, we cannot send a fraction of a ship; we must round the requirement up to the ceiling to ensure we send 5 full shuttles. 

let escapingScientists = 42;
let shuttleCapacity = 10;

// A raw division gives us a decimal fraction.
let exactShuttlesNeeded = escapingScientists / shuttleCapacity;

console.log(exactShuttlesNeeded); 
// Result: 4.2 (We can not fly 0.2 of a shuttle!)

// We use Math.ceil() to always round up to the nearest whole integer.
let actualShuttlesLaunched = Math.ceil(exactShuttlesNeeded);

console.log(actualShuttlesLaunched);
// Result: 5 (All 42 scientists are safely accommodated!)

// Notice how it handles negative subspace coordinates. 
// It rounds UP, meaning it moves towards zero!
console.log(Math.ceil(-7.8)); // Result: -7

// Let's write a standard function for the flight deck to automate this:
function prepareShuttles(crewCount, seats) {
    let shuttles = Math.ceil(crewCount / seats);
    console.log("Flight deck, please prep " + shuttles + " shuttles for immediate departure.");
}

prepareShuttles(105, 20); 
// Result: Flight deck, please prep 6 shuttles for immediate departure.

Syntax 

Math.ceil(x)

Return Value

Type: Number (The smallest integer that is greater than or equal to the given number.)

Description:

In mathematics, the ceiling function maps a real number to the smallest succeeding integer. Math.ceil() is a static method, meaning we just call it directly from the ship's main computer without needing to construct a "new Math" object. It is important for our engineering teams to remember that if the number is already a perfect integer, or if we pass it 0 or -0, it simply returns that exact same number. If we encounter a sensor glitch and pass it a value that cannot be converted to a number, it will alert us by returning NaN (Not-a-Number).
