Math.log10()

The Math.log10() method stands for "Base-10 Logarithm." When we are scanning deep space, the raw energy output of a star or a distress beacon can be hundreds of millions of units. We cannot easily read a number that long on our tactical displays during a crisis! We use this method to compress those massive numbers into a simple, readable scale. Because it operates on Base-10, every time the energy multiplies by ten, our display number only increases by one. It is the perfect mathematical tool for translating raw, overwhelming sensor data into a clear 1-to-10 threat level! 

// A standard communications beacon outputs 1,000 gigawatts of power.
let beaconPower = 1000;

// We use Math.log10() to calculate its readable signal level.
let signalLevel = Math.log10(beaconPower);

console.log(signalLevel); 
// Result: 3 (Because 10 * 10 * 10 = 1000. It is a Level 3 signal!)

// Suddenly, we detect a massive stellar flare!
let flarePower = 100000; 

console.log(Math.log10(flarePower));
// Result: 5 (The energy is 100 times stronger, but the level only goes up to 5!)

// Let us create a tactical alert function for the main viewscreen:
function analyzeEnergySpike(rawEnergy) {
    let threatLevel = Math.log10(rawEnergy);
    
    if (threatLevel >= 6) {
        console.log("Red Alert! Level " + threatLevel + " energy spike detected!");
    } else {
        console.log("Energy spike is a manageable Level " + threatLevel + ".");
    }
}

analyzeEnergySpike(1000000); 
// Result: Red Alert! Level 6 energy spike detected!

Syntax 

Math.log10(x)

Return Value

Type: Number (The base-10 logarithm of the given number.)

Description:

Math.log10() is a standard static method used constantly in sensor arrays and communications arrays. If we pass it the number 10, it returns 1. If we pass it 100, it returns 2. It is a very clean, predictable mathematical function. However, if our sensors malfunction and pass a negative number into the method, it will return NaN (Not-a-Number), because calculating the base-10 logarithm of a negative number is mathematically impossible in standard space. If we pass it exactly 0, it alerts the computer by returning -Infinity.
