Math.round()

The Math.round() method stands for "Round." When we are in the middle of a tense encounter, we need our tactical displays to be clean, sharp, and easy to read. If our targeting scanners return a messy, long decimal distance for an incoming vessel, we use this method to instantly smooth it out to the nearest whole number. It works exactly like standard mathematics: if the decimal portion is .5 or higher, the computer rounds up to the next number. If it is .4 or lower, the computer rounds down. It is our primary tool for keeping the bridge interfaces perfectly readable! 

// Tactical returns a messy decimal distance for a target.
let targetDistance = 452.738; 

// We use Math.round() to clean up the display.
let cleanDistance = Math.round(targetDistance);

console.log(cleanDistance); 
// Result: 453 (Because .7 is higher than .5, it tipped upward!)

// Let us see what happens if the decimal is lower.
let asteroidDistance = 89.2; 

console.log(Math.round(asteroidDistance));
// Result: 89 (Because .2 is lower than .5, it settled downward.)

// Let us create a standard function for the main viewscreen:
function smoothSensorData(rawDistance) {
    let readableDistance = Math.round(rawDistance);
    console.log("Viewscreen updated. Target is " + readableDistance + " km away.");
}

smoothSensorData(1024.5); 
// Result: Viewscreen updated. Target is 1025 km away.

Syntax 

Math.round(x)

Return Value

Type: Number (The value of the given number rounded to the nearest integer.)

Description:

Math.round() is a standard static method. It evaluates the fractional portion of the number you give it. If the fractional portion is exactly 0.5 or greater, the argument is rounded to the next highest integer. If it is less than 0.5, the argument is rounded to the next lowest integer. It is important for our engineering teams to note how it handles negative space! If we pass it -4.5, it rounds towards positive infinity (meaning closer to zero), so it will actually return -4. As always, if the computer cannot convert the input into a valid number, it will protect the system by returning NaN (Not-a-Number).
