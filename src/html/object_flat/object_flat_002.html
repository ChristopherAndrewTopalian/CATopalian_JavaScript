The Object Scanner (For...In)

While flat Objects are incredibly fast for instant data retrieval, there are times when we need the computer to perform a comprehensive sweep of the entire data registry. To do this, we use the for...in loop.

This acts as an automated sensor sweep. The engine jumps from coordinate to coordinate, extracting the Key (the name of the data) and using it to unlock the exact Value stored at that location. This is a critical foundation for when we eventually construct massive, multi-layered Objects of Objects. 

let starshipClasses = {
    enterprise: 'constitution',
    defiant: 'escort'
};

// Initiate a sequential sweep of the objects keys
for (let key in starshipClasses)
{
    // 'key' isolates the property name (e.g., enterprise)
    // starshipClasses[key] accesses the stored data (e.g., constitution)
    console.log(key + ' and ' + starshipClasses[key]);
}

/*
enterprise and constitution
defiant and escort
*/

Syntax 

for (let key in objectName) { // Execute logic }

Return Value

Type: Iteration (Executes a block of code for every enumerable string property found within the Object).

Description:

The for...in loop does not rely on numbered arrays to scan. Instead, it mathematically iterates over the flat keys of the Object. By defining a temporary variable (in this case, let key), the engine temporarily holds the name of the property as a string. We then dynamically pass that string back into the main Object using bracket notation objectName[key] to extract the actual value. This dynamic key extraction allows the engine to process vast amounts of unstructured data without knowing the specific keys in advance.
