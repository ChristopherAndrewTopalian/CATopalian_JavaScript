Expanding the Registry (Adding Properties)

Starfleet is always expanding, and our data registries need to be able to adapt. JavaScript Objects are mutable, which means we can modify them, add to them, or delete parts of them after they have already been created.

To add a brand new entry to an existing Object, we can use the same Dot Notation we use for reading data. If we point to a Key that does not exist yet and assign it a Value, the JavaScript engine will automatically create that new coordinate in the memory banks. 

let starshipClasses = {
    enterprise: 'constitution',
    defiant: 'escort'
};

// Commission a new vessel directly into the database
starshipClasses.voyager = 'intrepid';

console.log(starshipClasses.voyager);

console.log(starshipClasses);

/*
intrepid
*/

/*
Object { enterprise: "constitution", defiant: "escort", voyager: "intrepid" }

defiant: "escort"

enterprise: "constitution"

voyager: "intrepid"

: Object { … }
*/

Syntax 

objectName.newProperty = "value";

Return Value

Type: Assignment (Returns the assigned string, but permanently mutates the targeted Object in memory).

Description:

When you use Dot Notation combined with the assignment operator (=), the engine performs a quick check. It scans the Object for the designated Key (like voyager). If it finds it, it overwrites the existing data. If it does not find it, it expands the Object, creates a new Key by that name, and slots the new Value into place. This allows developers to dynamically construct and expand database structures on the fly as an application runs.
