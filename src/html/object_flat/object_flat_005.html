Decommissioning Data (Deleting Properties)

Just as new ships are commissioned into the fleet, older vessels are eventually decommissioned or reassigned. Because JavaScript Objects are mutable, we can permanently erase a coordinate from the memory banks using the delete operator.

When we use the delete operator on a specific Key, it doesn't just empty the data, it completely destroys both the Key and the Value, removing that entry from the database entirely. Let's run a sensor sweep to verify the ship is gone. 

let starshipClasses = {
    enterprise: 'constitution',
    defiant: 'escort',
    voyager: 'intrepid'
};

// Permanently delete a vessel from the registry
delete starshipClasses.defiant;

// Initiate a sequential sweep of the updated registry
for (let key in starshipClasses)
{
    // 'key' isolates the property name
    // starshipClasses[key] accesses the stored data
    console.log(key + ' and ' + starshipClasses[key]);
}

/*
enterprise and constitution
voyager and intrepid
*/

Syntax 

delete objectName.propertyName;

Return Value

Type: Boolean (Returns true if the property was successfully deleted, but its main purpose is to mutate the Object directly).

Description:

The delete operator is a powerful tool for memory management and data manipulation. You simply write the word delete followed by the direct comm link (Dot Notation) to the property you want to target. Once executed, that Key-Value pair ceases to exist within the Object. If you try to scan an Object using a for...in loop after a deletion, the engine will act as if that data was never there to begin with.
