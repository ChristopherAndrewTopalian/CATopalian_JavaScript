The Direct Comm Link (Dot Notation)

We have learned how to build a data registry and how to run a full sensor sweep using a loop. But what if we already know exactly which ship we are looking for? We don't need to scan the whole database; we just need a direct comm link to that specific coordinate.

In JavaScript, the most common way to target a specific property inside an Object is by using Dot Notation. 

let starshipClasses = {
    enterprise: 'constitution',
    defiant: 'escort'
};

// Open a direct channel to the 'enterprise' key
console.log(starshipClasses.enterprise);

/*
constitution
*/

Syntax 

objectName.propertyName;

Return Value

Type: Variable (Returns the specific data type stored at that exact Key—in this case, a String).

Description:

Dot Notation acts as a hardwired pathway into an Object. By typing the name of the Object, followed by a period (.), and then the exact name of the Key, the engine instantly retrieves the attached Value. It is faster and cleaner to write than bracket notation, making it the standard operating procedure for accessing data. However, it only works if you already know the exact name of the Key beforehand, and the Key name must not contain spaces or start with a number.
