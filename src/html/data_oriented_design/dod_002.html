The Tactical Sweep (Batch Processing)

In our previous lesson, we separated our Logic from our Data. We fed a single ship into a central damage system. However, in a massive Starfleet simulation running at 60 frames per second, we cannot manually execute a command for every individual ship.

To achieve true engine efficiency, our Central Systems must be designed for Batch Processing. Instead of passing one ship into the system, we pass the entire Object of Objects registry. The system uses a high-speed loop to sweep the database, instantly calculating physics, damage, or shield regeneration for the entire fleet in a single maneuver. 

// THE DATA: Pure Factory Function
function createStarship(shipName, startingShields, combatStatus) {
    return {
        name: shipName,
        shields: startingShields,
        inCombat: combatStatus
    };
}

// THE SYSTEM: A Fleet-Wide Batch Processor
function runShieldRegenerationCycle(fleetRegistry) {
    console.log("--- Initiating Fleet-Wide Shield Regeneration ---");
    
    // Sweep the entire Object of Objects database
    for (let key in fleetRegistry) {
        let ship = fleetRegistry[key];
        
        // Only regenerate shields if the ship is NOT in combat, and shields are below 100
        if (!ship.inCombat && ship.shields < 100) {
            ship.shields += 10;
            // Cap shields at 100 maximum
            if (ship.shields > 100) ship.shields = 100; 
            
            console.log(ship.name + ": Shields regenerated to " + ship.shields + "%");
        }
    }
}

// THE SIMULATION: Generating the World State
let starfleetDatabase = {
    enterprise: createStarship('Enterprise', 85, false), // Damaged, safe
    defiant: createStarship('Defiant', 40, true),        // Damaged, under fire
    voyager: createStarship('Voyager', 100, false)       // Full health, safe
};

// THE GAME LOOP: Fire the Central System once to update the entire world
runShieldRegenerationCycle(starfleetDatabase);

/*
--- Initiating Fleet-Wide Shield Regeneration ---
Enterprise: Shields regenerated to 95%
*/

Syntax 

function processWorldState(registryObject) { 
    for (let key in registryObject) { /* execute batch logic */ } 
}

Return Value

Type: World State Mutation (The function executes a sweeping update across the entire database, directly mutating multiple objects in active memory without needing to return a single value).

Description:

Batch processing is the heartbeat of a logic engine. By passing the entire starfleetDatabase into a central function, the CPU can read the contiguous data structures at blistering speeds. Notice how the Defiant and Voyager were skipped by the logic gate, the engine quickly checks their pure data properties (inCombat and shields) and decides whether to spend processing power on them. This architecture allows developers to handle massive worlds, updating thousands of entities with just one line of code per simulation frame.
