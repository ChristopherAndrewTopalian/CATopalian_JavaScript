Desktop Operations (Introducing NW.js)

In our first lesson, we ran code inside a web browser and a basic terminal. But what if we want to build a standalone, professional desktop application? What if we want to build a fully functioning LCARS radar screen or a 3D Holodeck interface that runs directly on our ship's operating system?

For this, Starfleet Engineers use a framework called NW.js.
NW.JS It is an incredible piece of technology that fuses a web browser directly with the computer's underlying file system. It allows us to build powerful desktop software using the exact same HTML, CSS, and JavaScript we already know.

The Trade-Off (Size vs. Speed)

In software engineering, everything is a trade-off. The NW.js engine is extremely powerful, but the base executable file is quite heavy, around 187 MB. However, because that heavy engine does all the heavy lifting, your actual project files will be incredibly tiny! Most of the applications you write will be less than 1 Megabyte in size.

Step 1: The Ship's Manifest (package.json)

Every NW.js application requires a manifest file. This is a simple data file named package.json that tells the engine how to boot up your app, what to name the window, and which HTML file to load first. Here is a standard configuration for an advanced AI interface: 

{
    "name": "catopalian-nwjs-true-ai",
    "version": "3.0.0",
    "description": "True AI - A living logical mind with persistent memory.",
    "main": "CATopalian_NWJS_TRUE_AI.html",
    "window":
    {
        "title": "CATopalian NWJS TRUE AI",
        "icon": "src/media/textures/icons/catopalian_true_ai.png",
        "width": 1280,
        "height": 720,
        "position": "center",
        "resizable": true,
        "frame": true
    },
    "nodejs": true
}

Step 2: The Drag-and-Drop Workflow

Developing apps with NW.js is incredibly fast because you do not have to "compile" your code every time you make a change. You just drag and drop!

  • 1. Create a Shortcut: Download the NW.js engine and extract it. Find the nw.exe file inside, right-click it, and create a shortcut. Move that shortcut directly to your computer's Desktop.
  • 2. Build Your Folder: Create a new folder for your project. Inside it, place your package.json file and your main HTML file.
  • 3. Launch the App: Simply click and drag your entire project folder and drop it directly onto the nw.exe shortcut on your Desktop. The engine will instantly read your manifest and launch your custom desktop application!

Summary

NW.js gives you full access to the computer. Because we set "nodejs": true in our manifest, our JavaScript can now read and write files directly to the hard drive, interface with hardware, and process data at blazing V8 engine speeds. It is the ultimate tool for Starfleet application design.
