Initializing the Engine (How to Run Code)

Welcome to the Academy. Before we can build deep-space tracking algorithms or multidimensional arrays, you need to know how to turn the engine on. The language of our LCARS systems is JavaScript.

Our very first command is console.log(). This command acts as a subspace transmission, it simply tells the computer to print a message to the screen so we can see that the engine is working. But to see this message, we need to know where to type the code. There are three main ways to run a JavaScript program.

Method 1: The Browser Console (The Quick Diagnostic)

Every modern web browser has a built-in JavaScript engine. You can access it right now by pressing F12 (or Right-Click -> Inspect) and clicking the "Console" tab.

Security Protocol Override: Modern browsers have high security. If you try to paste code into the console for the first time, the computer will block it. It is protecting you from executing malicious code. To bypass this, you must manually type the words allow pasting and hit Enter. Once authorized, you can run your first command: 

// Type this directly into the F12 Console and hit Enter
console.log("Hi everyone, the Comm-Link is established!");

/*
Hi everyone, the Comm-Link is established!
*/

Method 2: The HTML Construct (The Visual Holodeck)

If you want to build visual interfaces, buttons, and graphics, you need to link your JavaScript to a web page (an HTML file). We do this by placing our code inside a <script> tag, usually up in the <head> of the document. When you double-click the HTML file to open it in your browser, the script runs automatically. 

<!DOCTYPE html>
<html>
<head>
    <title> My First Script </title>
    <script>
        // The browser reads the file and executes this immediately
        console.log("Hi everyone, the HTML engine is running!");
    </script>
</head>
<body>
    <h1> Check your F12 Console! </h1>
</body>
</html>

Method 3: Node.js (The Engineering Core)

When we build massive server architectures or raw data logic engines, we don't need a visual web browser at all. We can run JavaScript directly on our computer's operating system using a program called Node.js.

You must go to the official Node.js website, download the installer, and make sure the option to "Add to PATH" is checked during installation. Once installed, you can save your code in a plain text file (like mission.js) and execute it using your computer's command terminal. 

// 1. Make a new folder named ourApp
// 2. Save this inside a file named: mission.js
console.log("Hi everyone, Main Engineering is online.");

// 3. In the ourApp folder address bar type the letters cmd
and then press Enter.
This opens the folder in the command prompt.

// 4. Open your command terminal and type:
// node mission.js

/*
Hi everyone, Main Engineering is online.
*/

Summary

Whether you use the F12 Console for quick tests, HTML for visual UI, or Node.js for heavy logic processing, the JavaScript code remains exactly the same. You are simply choosing which engine room you want to execute the commands from.
