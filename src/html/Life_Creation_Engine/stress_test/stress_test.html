Life Creation Engine: The Rendering Stress Test

Welcome to the Proving Grounds, Cadets. Today, we answer a critical question: Why do we use the HTML5 Canvas for physics and biology simulations? Why can't we just use standard HTML <div> elements and move them around with CSS?

To find out, we are going to push the engine to the breaking point. We are going to spawn 5,000 entities simultaneously. Open your computer's Task Manager or Activity Monitor. Copy the complete scripts below into separate .html files, run them, and watch your CPU's reaction.

Simulation 1: The DOM Method (HTML Divs)

Copy this complete code into a file named dom_test.html. Watch how the browser struggles, stutters, and lags as it tries to calculate the CSS for 5,000 separate HTML elements every single frame. 

<!DOCTYPE html>
<html>
<head>
<style>
    body { background-color: black; overflow: hidden; margin: 0; }
    .entity {
        position: absolute;
        width: 4px; height: 4px;
        background-color: red;
    }
</style>
</head>
<body>

<script>
    // Shortcuts
    function ce(whichType) { return document.createElement(whichType); }
    function ba(whichElement) { return document.body.append(whichElement); }

    let entities = [];
    let speed = 2;

    // Spawn 5,000 HTML Divs
    for(let i = 0; i < 5000; i++) {
        let div = ce("div");
        div.className = "entity";
        
        // Random starting positions
        let x = Math.random() * window.innerWidth;
        let y = Math.random() * window.innerHeight;
        
        div.style.left = x + "px";
        div.style.top = y + "px";
        
        ba(div);

        // Store the math data and the physical HTML div together
        entities.push({
            element: div,
            x: x, y: y,
            dx: (Math.random() - 0.5) * speed,
            dy: (Math.random() - 0.5) * speed
        });
    }

    function gameLoop() {
        // Update the CSS of 5,000 DOM elements every frame
        for(let i = 0; i < entities.length; i++) {
            let e = entities[i];
            e.x += e.dx;
            e.y += e.dy;
            
            // This is what kills the CPU!
            e.element.style.left = e.x + "px";
            e.element.style.top = e.y + "px";
        }
        requestAnimationFrame(gameLoop);
    }

    gameLoop();
</script>

</body>
</html>

Simulation 2: The Canvas Method (Pixel Drawing)

Now, copy this complete code into a file named canvas_test.html. We are spawning the exact same 5,000 entities, doing the exact same math. Watch the simulation glide flawlessly at 60 Frames Per Second. 

<!DOCTYPE html>
<html>
<head>
<style>
    body { background-color: black; overflow: hidden; margin: 0; }
    canvas { display: block; }
</style>
</head>
<body>

<canvas id="gameCanvas"></canvas>

<script>
    // Shortcuts
    function ge(whichId) { return document.getElementById(whichId); }

    const canvas = ge("gameCanvas");
    const ctx = canvas.getContext("2d");
    
    canvas.width = window.innerWidth;
    canvas.height = window.innerHeight;

    let entities = [];
    let speed = 2;

    // Spawn 5,000 pure math objects (No HTML elements!)
    for(let i = 0; i < 5000; i++) {
        entities.push({
            x: Math.random() * canvas.width, 
            y: Math.random() * canvas.height,
            dx: (Math.random() - 0.5) * speed,
            dy: (Math.random() - 0.5) * speed
        });
    }

    function gameLoop() {
        // Wipe the single canvas clean
        ctx.clearRect(0, 0, canvas.width, canvas.height);
        
        ctx.fillStyle = "cyan";

        // Calculate math and paint pixels instantly
        for(let i = 0; i < entities.length; i++) {
            let e = entities[i];
            e.x += e.dx;
            e.y += e.dy;
            
            // Draw a 4x4 square of pixels
            ctx.fillRect(e.x, e.y, 4, 4);
        }
        requestAnimationFrame(gameLoop);
    }

    gameLoop();
</script>

</body>
</html>

Astrometrics Math: Retained vs. Immediate Rendering

The DOM (Retained Mode): The Document Object Model (DOM) is designed for static documents, not physics. When you move 5,000 <div> elements, the browser has to physically recalculate the margins, padding, borders, and layout of the entire website 5,000 times per frame. It retains all that memory overhead, causing the CPU to overheat and lag.

The Canvas (Immediate Mode): The Canvas is a single, blank sheet of glass connected directly to your computer's Graphics Processing Unit (GPU). Our Javascript objects exist purely as math in the background. Every frame, the engine wipes the glass clean, looks at the math, and instantly paints colored pixels directly onto the screen. It forgets them the moment they are drawn. Because there is no HTML layout to calculate, the engine can render tens of thousands of entities effortlessly!
