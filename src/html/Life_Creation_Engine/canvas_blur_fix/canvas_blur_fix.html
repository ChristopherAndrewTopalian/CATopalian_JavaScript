JavaScript Life Creation Engine: The Canvas Blur Anomaly

Attention, Cadets. Today we address a critical environmental hazard: The Blur Anomaly. If we build a standard Canvas on an older monitor, it looks fine. But if we load that exact same simulation on a modern 4K Television or a Retina display, your crisp text and entities will look like a blurry, out-of-focus photograph.

We must scale the internal memory of the Canvas to match the physical hardware of the screen. Below are the two standard Starfleet protocols for initializing a clean, sharp canvas.

// Method 1: Full-Screen Standalone 

// METHOD 1: FULL-SCREEN STANDALONE (Use for independent apps)
function initFullScreen() {
    canvas = ge("gameCanvas");
    ctx = canvas.getContext("2d");

    // Get the exact pixel ratio of the users monitor
    const dpr = window.devicePixelRatio || 1;

    // Grab the exact inner dimensions of the entire browser window
    const STAGE_WIDTH = window.innerWidth;
    const STAGE_HEIGHT = window.innerHeight;

    // Scale the internal canvas memory up
    canvas.width = STAGE_WIDTH * dpr;
    canvas.height = STAGE_HEIGHT * dpr;

    // Force CSS to match so the browser does not stretch it
    canvas.style.width = STAGE_WIDTH + 'px';
    canvas.style.height = STAGE_HEIGHT + 'px';

    // Tell the drawing context to use the new high-res scale
    ctx.scale(dpr, dpr);

    startSimulation();
}

Astrometrics Math: Window Inner-Width

The Hardware Reality: High-definition displays pack multiple physical hardware pixels into the space of a single "CSS Pixel". By multiplying the Canvas memory (canvas.width) by the window.devicePixelRatio, we give the engine enough pixels to draw razor-sharp text.

When to use this: We use this method when our Canvas is the only thing on the page, and we want it to fill the entire monitor edge-to-edge. We use window.innerWidth to measure the entire screen.

// Method 2: iFrame / Container Safe 

// METHOD 2: IFRAME / CONTAINER SAFE (Use for Academy Tutorials)
function initEmbedded() {
    canvas = ge("gameCanvas");
    ctx = canvas.getContext("2d");

    const dpr = window.devicePixelRatio || 1;
    
    // Ask the Canvas how big its specific CSS box physically is
    const STAGE_WIDTH = canvas.clientWidth;
    const STAGE_HEIGHT = canvas.clientHeight;

    // Scale the internal canvas memory up
    canvas.width = STAGE_WIDTH * dpr;
    canvas.height = STAGE_HEIGHT * dpr;

    // We DO NOT force the CSS width here, letting the iFrame manage it
    ctx.scale(dpr, dpr);

    startSimulation();
}

Astrometrics Math: Canvas Client-Width

The Containment Protocol: When we embed our simulation inside a constrained layout like this Starfleet Academy tutorial page, using window.innerWidth would force the canvas to bleed right off the page and break the UI!

When to use this: Use this method when our Canvas lives inside a specific box, div, or iFrame. Instead of measuring the whole window, we use canvas.clientWidth to measure only the specific box the canvas lives inside. Notice we also do not force the CSS styles at the end, allowing the parent webpage to dictate the size.
