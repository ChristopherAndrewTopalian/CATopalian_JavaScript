// GATE: XOR (Exclusive OR - The Difference Detector)
// Output is 1 ONLY if the inputs are different.
function gateXor(a, b)
{
    if ((a == 1 && b == 0) ||
        (a == 0 && b == 1))
    {
        return 1;
    }
    else
    {
        return 0;
    }
}

// GATE: XNOR (Equivalence - The Similarity Detector)
// Output is 1 ONLY if the inputs are exactly the same.
function gateXnor(a, b)
{
    if ((a == 0 && b == 0) ||
        (a == 1 && b == 1))
    {
        return 1;
    }
    else
    {
        return 0;
    }
}

The Character of the Gates: The Great Discriminators

The Mirror: The Relationship of Opposites

XOR and XNOR are perfect cognitive opposites. Where XOR sees conflict (1 and 0) and declares it a "True" difference, XNOR sees that same conflict and declares it a "False" mismatch. Running an XOR gate through a NOT gate instantly produces an XNOR.
