toString()

While join() allows us to stitch an array together using custom spaces or characters, toString() is a raw, unformatted data dump. It simply converts the entire array into one long text string, separating every item with a standard comma.

Crucial Note: If we use toString() directly on an array of objects, it will just output a string of [object Object]! We must first use map() to isolate the specific text or numbers you want to transmit, and then chain the command onto the end! 

let fleet = [
    { name: "Enterprise", sector: 10 },
    { name: "Defiant", sector: 45 },
    { name: "Voyager", sector: 99 }
];

// WARNING: Calling toString directly on objects creates a garbled transmission!
let badTransmission = fleet.toString();

console.log(badTransmission); 
// Result: "[object Object],[object Object],[object Object]"

// THE FIX: Map the sector coordinates into a standard array first, then convert!
let goodTransmission = fleet.map(ship => ship.sector).toString();

console.log(goodTransmission); 
// Result: "10,45,99"

Syntax 

array.map(element => element.property).toString()

Return Value

Type: String (A single, comma-separated text string of the extracted data)

Description:

This method performs a raw data dump of the fleet's coordinates or manifests. Because we are dealing with complex objects, we must first isolate the exact data we want to transmit using a map() command. It then takes every single extracted item, converts them all into standard text, and fuses them together into one continuous string separated only by commas. Unlike join(), we cannot specify custom separators (like spaces or dashes). It is the fastest, most rigid way to serialize array data for a basic communications transmission.
