flat()

Sometimes, an array contains other arrays tucked inside of it (this is called a multi-dimensional array or a nested array).

The flat() method takes all of those separated, internal arrays and dumps their objects out into one single, unified, one-dimensional list. 

// We have a main array containing two separate sub-squadron arrays
let sectorGrids = [
    [ // Alpha Squadron Array
        { name: "Alpha-1", class: "Fighter" },
        { name: "Alpha-2", class: "Bomber" }
    ], 
    [ // Beta Squadron Array
        { name: "Beta-1", class: "Fighter" },
        { name: "Beta-2", class: "Recon" }
    ]
];

// Flatten the nested structure into one continuous command list
let unifiedGrid = sectorGrids.flat();

console.log(unifiedGrid); 
/* Result: [
    { name: "Alpha-1", class: "Fighter" },
    { name: "Alpha-2", class: "Bomber" },
    { name: "Beta-1", class: "Fighter" },
    { name: "Beta-2", class: "Recon" }
] */

Syntax 

array.flat(/* optional: */ depth)

Return Value

Type: Array (A brand-new, unified array containing all the extracted objects)

Description:

If our array contains other arrays inside of it (like a massive Carrier ship holding nested squadrons of fighters), the flat() command orders them all to deploy into a single, unified battle line. It extracts the nested ship objects and places them directly into a brand-new array. By default, it only unpacks one level deep, but we can provide a depth number to tell it exactly how many nested layers to unpack!
