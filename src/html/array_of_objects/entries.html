entries()

The entries() method returns a special Array Iterator object. When we loop through it, it provides an array containing both the Index Number (the docking bay) and the Value (the complete ship object) for every single item in our fleet. 

let fleet = [
    {
        name: "Enterprise",
        class: "Cruiser"
    },
    {
        name: "Defiant",
        class: "Escort"
    },
    {
        name: "Voyager",
        class: "Intrepid"
    }
];

let dockingManifest = fleet.entries();

// Use a classic for...of loop to read the iterator
for (let entry of dockingManifest) {
    console.log(entry);
}
// Output:
// [0, { name: "Enterprise", class: "Cruiser" }]
// [1, { name: "Defiant", class: "Escort" }]
// [2, { name: "Voyager", class: "Intrepid" }]

Syntax 

array.entries()

Return Value

Type: Array Iterator (A specialized data stream of key/value pairs)

Description:

This command generates a complete, secure manifest of the entire fleet. Instead of just listing the ships, it creates an "Iterator" that outputs a paired data packet containing both the exact registry slot (the index) and the ship object itself (the element). It is highly useful when we need to loop through a formation of complex objects and require absolute confirmation of both what the object is and exactly where it is parked.
