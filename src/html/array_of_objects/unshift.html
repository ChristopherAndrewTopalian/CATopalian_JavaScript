unshift()

Adding to the Beginning

unshift() places a new object into the very first slot (Index 0) and bumps all the other objects down one space to make room.

Crucial Note: Just like push(), this method is destructive. If we assign the result of unshift() to a variable, it does not save the array. Instead, it returns the new total length (an integer) of the array! 

let fleet = [
    {
        name: "Defiant",
        class: "Escort"
    },
    {
        name: "Voyager",
        class: "Intrepid"
    }
];

// A new flagship object takes the lead position at Index 0
let newFleetSize = fleet.unshift({ name: "Enterprise", class: "Cruiser" }); 

console.log(fleet); 
/* Result: [
    { name: "Enterprise", class: "Cruiser" },
    { name: "Defiant", class: "Escort" },
    { name: "Voyager", class: "Intrepid" }
] */

// unshift() returns the new total number of ships!
console.log(newFleetSize);
// Result: 3

Syntax 

array.unshift(element1, element2, /* ..., */ elementN)

Return Value

Type: Number (The new total length of the array)

Description:

This method inserts new objects at the absolute front of the array (Index 0). Warning: This is a destructive method that permanently mutates the original array! The rest of the fleet is safely pushed back to higher index numbers to make room. After successfully adding the new elements, it calculates the new size of the formation and returns that length property as an integer.
