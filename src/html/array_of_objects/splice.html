splice()

splice() is the ultimate array tool. It allows us to add, remove, or replace objects anywhere inside the array. We just tell it exactly what index number to start at, and how many objects to delete before adding new ones.

Warning: This is a highly destructive command! It permanently mutates the original array. 

let fleet = [
    { name: "Enterprise", class: "Cruiser" }, // Index 0
    { name: "Defiant", class: "Escort" },     // Index 1
    { name: "Voyager", class: "Intrepid" }    // Index 2
];

// Start at Index 1. Delete 0 ships. Insert the "Discovery" object.
let removedShips = fleet.splice(1, 0, { name: "Discovery", class: "Science" }); 

console.log(fleet); 
/* Result: [
    { name: "Enterprise", class: "Cruiser" },
    { name: "Discovery", class: "Science" },
    { name: "Defiant", class: "Escort" },
    { name: "Voyager", class: "Intrepid" }
] (The Discovery successfully pushed its way into Index 1!) */

// splice() always returns an array of the removed objects
console.log(removedShips);
// Result: [] (Because we told it to delete 0 ships!)

Syntax 

array.splice(start, deleteCount, item1, item2, /* ..., */ itemN)

Return Value

Type: Array (A new array containing the removed objects, or an empty array if nothing was deleted)

Description:

This is a heavy-duty, destructive command. It physically alters the original array by removing objects, inserting new ones, or doing both simultaneously. It begins at the start index, removes the exact number of objects specified by the deleteCount, and then inserts any new objects directly into that gap. It actively returns an array containing any ship objects that were successfully removed from the formation so we don't lose their data!
