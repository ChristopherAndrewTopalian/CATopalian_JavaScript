sort()

The sort() method is a permanent, fleet-wide reorganization command. By default, it sorts items alphabetically as strings. But when we have an array of complex objects, we must provide a compare function so the system knows exactly which property to use for the ranking!

Warning: This method physically alters our original array rather than making a safe copy! 

// Example 1: ES5 Version

let fleet = [
    { name: "Voyager", registry: 74656 },
    { name: "Enterprise", registry: 1701 },
    { name: "Defiant", registry: 75633 },
    { name: "Reliant", registry: 1864 }
];

// Reorganize the fleet objects numerically from lowest to highest registry
fleet.sort(function(a, b) {
    return a.registry - b.registry;
});

console.log(fleet); 
/* Result: [
    { name: "Enterprise", registry: 1701 },
    { name: "Reliant", registry: 1864 },
    { name: "Voyager", registry: 74656 },
    { name: "Defiant", registry: 75633 }
] (The original array is permanently altered!) */

// Example 2: ES6 Version

let fleet = [
    { name: "Voyager", registry: 74656 },
    { name: "Enterprise", registry: 1701 },
    { name: "Defiant", registry: 75633 },
    { name: "Reliant", registry: 1864 }
];

// Reorganize the fleet objects numerically from lowest to highest registry
fleet.sort((a, b) => a.registry - b.registry);

console.log(fleet); 
/* Result: [
    { name: "Enterprise", registry: 1701 },
    { name: "Reliant", registry: 1864 },
    { name: "Voyager", registry: 74656 },
    { name: "Defiant", registry: 75633 }
] (The original array is permanently altered!) */

Syntax (ES5 Version) 

array.sort(function(a, b) { 
    /* return a negative number, positive number, or zero */ 
})

Syntax (ES6 Version) 

array.sort((a, b) => { /* return a negative, positive, or zero */ })

Return Value

Type: Array (The original array, completely reordered)

Description:

This is the ultimate reorganization command. The Admiral issues a metric (like tonnage, alphabetical order, or a specific object property like registry number), and the entire fleet physically shifts positions to comply. We pass it a "compare function" that looks at two ship objects at a time (a and b) to determine their rank by subtracting their target properties. Warning: This is a destructive maneuver! It does not create a new array; it permanently alters the physical formation of the original array.
