toSorted()

toSorted() is the modern, purely functional version of the classic sort() command. It organizes our objects using a compare function and hands us a brand-new, safely copied array without mutating the original list's formation!

Crucial Note (The Shallow Copy): While the new array's order is completely independent of the old array, the objects inside are identical memory references! If we change a ship's property in the sorted array, it will change in the original array too. 

// Example 1: ES5 Version

let fleet = [
    { name: "Voyager", registry: 74656 },
    { name: "Enterprise", registry: 1701 },
    { name: "Defiant", registry: 75633 }
];

// Sort the fleet numerically without destroying the original formation
let sortedFleet = fleet.toSorted(function(a, b) {
    return a.registry - b.registry;
});

console.log(sortedFleet); 
/* Result: [
    { name: "Enterprise", registry: 1701 },
    { name: "Voyager", registry: 74656 },
    { name: "Defiant", registry: 75633 }
] */

// Proof that the original array formation is completely untouched:
console.log(fleet[0].name);
// Result: "Voyager" (It is still parked at Index 0!)

// Example 2: ES6 Version

let fleet = [
    { name: "Voyager", registry: 74656 },
    { name: "Enterprise", registry: 1701 },
    { name: "Defiant", registry: 75633 }
];

// Sort the fleet numerically without destroying the original formation
let sortedFleet = fleet.toSorted((a, b) => a.registry - b.registry);

console.log(sortedFleet); 
/* Result: [
    { name: "Enterprise", registry: 1701 },
    { name: "Voyager", registry: 74656 },
    { name: "Defiant", registry: 75633 }
] */

Syntax (With ES5 Compare Function) 

array.toSorted(function(a, b) { 
    /* return a negative number, positive number, or zero */ 
})

Syntax (With ES6 Compare Function) 

array.toSorted((a, b) => { /* return a negative, positive, or zero */ })

Return Value

Type: Array (A brand-new array containing shallow copies in their new sorted order)

Description:

This is the completely safe, non-destructive version of the classic sort() command. Introduced in the ES2023 update, it performs the exact same fleet reorganization using a compare function to evaluate object properties. But instead of mutating the original array, it returns a brand-new array containing the sorted elements. The original fleet's physical formation remains perfectly intact. Just remember that the new array contains shallow copies of the original objects!
