keys()

The keys() method is the direct counterpart to the entries() method we reviewed earlier. Instead of giving us both the index number and the object itself, keys() completely ignores the objects and returns an iterator containing only the array's index numbers (the docking bays).

Crucial Note: Do not confuse this with Object.keys()! Because we are running this on an Array, it will only give us the array's coordinates (0, 1, 2), not the property names inside the ship objects! 

let fleet = [
    {
        name: "Enterprise",
        class: "Cruiser"
    },
    {
        name: "Defiant",
        class: "Escort"
    },
    {
        name: "Voyager",
        class: "Intrepid"
    }
];

let dockingBays = fleet.keys();

// Loop through to see the available bay numbers
for (let bay of dockingBays) {
    console.log(bay);
}

// Output:
// 0
// 1
// 2
// (Notice it completely ignores the complex ship objects!)

Syntax 

array.keys()

Return Value

Type: Array Iterator (A specialized data stream of index numbers)

Description:

This command generates a strict manifest of the active docking bays. It completely bypasses the complex ship objects parked in the array and generates an "Iterator" that outputs only the exact registry slots (the index numbers). It is highly useful when we only care about the size and structure of our formation, rather than the specific objects currently occupying it.
