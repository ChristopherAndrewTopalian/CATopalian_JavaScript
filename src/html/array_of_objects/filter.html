filter()

filter() is one of the most powerful methods in JavaScript. It sweeps through our original array, tests every object against a rule we create, and returns a brand-new array containing only the objects that passed the test! 

// Example 1: ES5 Version

let fleet = [
    {
        name: "Enterprise",
        class: "Cruiser"
    },
    {
        name: "Defiant",
        class: "Escort"
    },
    {
        name: "Voyager",
        class: "Cruiser"
    }
];

// Sweep the fleet array and isolate only the "Cruiser" class ships
let cruisers = fleet.filter(function(ship) {
    return ship.class === "Cruiser";
});

console.log(cruisers); 
// Result: [{name: "Enterprise", class: "Cruiser"}, {name: "Voyager", class: "Cruiser"}]

// Example 2: ES6 Version

let fleet = [
    {
        name: "Enterprise",
        class: "Cruiser"
    },
    {
        name: "Defiant",
        class: "Escort"
    },
    {
        name: "Voyager",
        class: "Cruiser"
    }
];

// Sweep the fleet array and isolate only the "Cruiser" class ships
let cruisers = fleet.filter(ship => ship.class === "Cruiser");

console.log(cruisers); 
// Result: [{name: "Enterprise", class: "Cruiser"}, {name: "Voyager", class: "Cruiser"}]

Notice that the original fleet array remains completely unchanged in both examples. filter() always generates a safe, modified copy of our data, no matter which syntax we use to write it.

Syntax (ES5) 

array.filter(function(element, index, array) { 
    /* return true or false */ 
})

Syntax (ES6) 

array.filter((element, index, array) => { /* return true or false */ })

Return Value

Type: Array (A brand-new array containing the filtered objects)

Description:

This method executes a system-wide sensor sweep across an array of objects. It tests every single object in the array against a specific condition that we define (like checking a specific property's value). If an object passes the test (evaluates to true), it is copied into a brand-new array. If it fails, it is left behind. Our original fleet of objects remains completely untouched and safely docked.
