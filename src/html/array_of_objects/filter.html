filter()

filter() is one of the most powerful methods in JavaScript. It sweeps through your original array, tests every item against a rule you create, and returns a brand-new array containing only the items that passed the test! 

let fleet = [
    { name: "Enterprise", class: "Cruiser" },
    { name: "Defiant", class: "Escort" },
    { name: "Voyager", class: "Cruiser" }
];

// Sweep the fleet array and isolate only the "Cruiser" class ships
let cruisers = fleet.filter(ship => ship.class === "Cruiser");

console.log(cruisers); 
// Result: [{name: "Enterprise"...}, {name: "Voyager"...}]
