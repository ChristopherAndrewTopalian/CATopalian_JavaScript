find()

While filter() returns an array of everything that matches our search, find() is a precision strike. It sweeps the array and returns the very first object that matches the condition, and then it immediately stops looking. 

// Example 1: ES5 Version

let crew = [
    {
        name: "Riker",
        role: "First Officer"
    },
    {
        name: "Data",
        role: "Operations"
    },
    {
        name: "Worf",
        role: "Tactical"
    },
    {
        name: "Data", // A backup hologram Data
        role: "Hologram"
    }
];

// Locate the first instance where the name is "Data"
let androidTarget = crew.find(function(member) {
    return member.name === "Data";
});

console.log(androidTarget); 
// Result: { name: "Data", role: "Operations" }
// (It completely ignores the hologram Data at the end of the list!)

// Example 2: ES6 Version

let crew = [
    {
        name: "Riker",
        role: "First Officer"
    },
    {
        name: "Data",
        role: "Operations"
    },
    {
        name: "Worf",
        role: "Tactical"
    },
    {
        name: "Data", // A backup hologram Data
        role: "Hologram"
    }
];

// Locate the first instance where the name is "Data"
let androidTarget = crew.find(member => member.name === "Data");

console.log(androidTarget); 
// Result: { name: "Data", role: "Operations" }
// (It completely ignores the hologram Data at the end of the list!)

Syntax (ES5 Version) 

array.find(function(element, index, array) { 
    /* return true or false */ 
})

Syntax (ES6 Version) 

array.find((element, index, array) => { /* return true or false */ })

Return Value

Type: Object (Returns the matching object itself, or undefined if not found)

Description:

While filter() gathers every ship object that matches a condition into a new array, find() is a precision strike. It sweeps the array from left to right and returns the very first object that successfully passes our test. The absolute millisecond it finds a match, the method stops scanning to save processing power. If the entire sweep finishes and no object matches the condition, it safely returns undefined.
