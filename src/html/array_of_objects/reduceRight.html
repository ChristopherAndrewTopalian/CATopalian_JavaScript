reduceRight()

reduceRight() does the exact same massive computation as reduce(), compiling data from the entire array into a single value. The only difference is its tactical approach: it starts accumulating from the absolute end of the array and works its way backward to the front.

Crucial Note: Just like standard reduce(), when we are extracting data from an array of objects, we must provide an initialValue (like an empty string "")! If we forget it, the method will accidentally grab the entire last object and ruin the compilation! 

// Example 1: ES5 Version

let interceptedPackets = [
    { id: 1, fragment: "A" },
    { id: 2, fragment: "H" },
    { id: 3, fragment: "P" },
    { id: 4, fragment: "L" },
    { id: 5, fragment: "A" }
];

// Decode the signal by reading the objects backward and combining their fragments
let decodedWord = interceptedPackets.reduceRight(function(total, packet) {
    return total + packet.fragment;
}, ""); // <-- This empty string is our CRITICAL initialValue!

console.log(decodedWord); 
// Result: "ALPHA"

// Example 2: ES6 Version

let interceptedPackets = [
    { id: 1, fragment: "A" },
    { id: 2, fragment: "H" },
    { id: 3, fragment: "P" },
    { id: 4, fragment: "L" },
    { id: 5, fragment: "A" }
];

// Decode the signal by reading the objects backward and combining their fragments
let decodedWord = interceptedPackets.reduceRight((total, packet) => total + packet.fragment, "");

console.log(decodedWord); 
// Result: "ALPHA"

Syntax (ES5 Version) 

array.reduceRight(function(accumulator, currentValue, currentIndex, array) { 
    /* return the updated accumulator */ 
}, initialValue)

Syntax (ES6 Version) 

array.reduceRight((accumulator, currentValue, currentIndex, array) => { 
    /* return the updated accumulator */ 
}, initialValue)

Return Value

Type: Any (Returns a single compiled value, like a String, Number, or Object)

Description:

This heavyweight command performs the exact same fleet-wide compilation as reduce(), but it executes its sequence in reverse. Starting from the rear guard and working its way to the vanguard, it uses an "accumulator" to keep a running total or, in this case, a combined string. It is the perfect tool for decrypting backward transmissions or processing a queue of objects from last-in to first-out. Always remember our initialValue when working with objects!
