lastIndexOf()

The lastIndexOf() method is a highly tactical search tool. It does the exact same job as indexOf(), locating a specific object and returning its index number, but it executes its scan in reverse.

It starts at the absolute end of the array and sweeps backward. If we have the exact same object reference stationed in our fleet multiple times, it will pinpoint the one furthest in the back.

Crucial Note: Remember our lesson from indexOf()! This command requires strict equality. It searches for the exact object in our computer's memory, not just a clone with matching data! 

let escortShip = { 
    name: "Defiant", 
    class: "Escort" 
};

let fleet = [
    escortShip, // Stationed as the forward guard at Index 0
    { 
        name: "Enterprise", 
        class: "Cruiser" 
    },
    { 
        name: "Voyager", 
        class: "Intrepid" 
    },
    escortShip  // Stationed AGAIN as the rear guard at Index 3
];

// Locate the rearmost position of this exact ship reference
let rearGuardPosition = fleet.lastIndexOf(escortShip);

console.log(rearGuardPosition); 
// Result: 3 (It sweeps backward and hits Index 3 first, completely ignoring Index 0!)

Syntax 

array.lastIndexOf(searchElement, /* optional: */ fromIndex)

Return Value

Type: Number (The exact index position, or -1 if not found)

Description:

This command operates exactly like the forward scanner, but it initiates its sweep from the absolute rear of the formation and works backward. Because it uses strict equality, it is perfect for finding the last known position of a specific, original object stationed multiple times in the array. Just like its forward counterpart, if the rear-guard sweep finishes and detects absolutely nothing that matches that memory reference, it safely returns a -1.
