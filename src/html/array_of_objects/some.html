some()

Earlier we used every() to check if the entire fleet passed a test. some() is much more sensitive. It sweeps the array of objects and returns true if at least one single object matches the condition.

The absolute millisecond it finds a single match, it immediately triggers the alert and stops scanning the rest of the array to save processing power! 

// Example 1: ES5 Version

let fleet = [
    { name: "Enterprise", shields: 100 },
    { name: "Discovery", shields: 100 },
    { name: "Defiant", shields: 45 },
    { name: "Voyager", shields: 100 }
];

// Scan the fleet to see if ANY ship object has shields below 50%
let redAlert = fleet.some(function(ship) {
    return ship.shields < 50;
});

console.log(redAlert); 
// Result: true (Because the Defiant's shields at 45 triggered the sensor!)

// Example 2: ES6 Version

let fleet = [
    { name: "Enterprise", shields: 100 },
    { name: "Discovery", shields: 100 },
    { name: "Defiant", shields: 45 },
    { name: "Voyager", shields: 100 }
];

// Scan the fleet to see if ANY ship object has shields below 50%
let redAlert = fleet.some(ship => ship.shields < 50);

console.log(redAlert); 
// Result: true (Because the Defiant's shields at 45 triggered the sensor!)

Syntax (ES5 Version) 

array.some(function(element, index, array) { 
    /* return true or false */ 
})

Syntax (ES6 Version) 

array.some((element, index, array) => { /* return true or false */ })

Return Value

Type: Boolean (true or false)

Description:

This method is our highly sensitive early warning system. It sweeps the array and checks if at least one single object matches our specific condition (like dipping below a certain shield threshold). The absolute millisecond it finds a single match, it immediately triggers the alert (returns true) and halts the scan. If the sweep completes the entire formation and finds absolutely no matches, it safely returns false.
