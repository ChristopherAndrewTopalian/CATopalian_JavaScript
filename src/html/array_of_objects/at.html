at()

The at() method takes an integer value and returns the object at that specific index. While it works just like standard bracket notation [0], its true superpower is that it allows negative integers to count backward from the end of the array!

This means we can easily target the last ship object in the fleet without needing to calculate fleet.length - 1. 

let fleet = [
    {
        name: "Enterprise",
        class: "Cruiser"
    },
    {
        name: "Defiant",
        class: "Escort"
    },
    {
        name: "Voyager",
        class: "Intrepid"
    }
];

// Target the first ship object
let flagship = fleet.at(0);
console.log(flagship); 
// Result: { name: "Enterprise", class: "Cruiser" }

// Target the very last ship object in the formation
let rearGuard = fleet.at(-1); 
console.log(rearGuard.name); 
// Result: "Voyager"

Syntax 

array.at(index)

Return Value

Type: Object (Returns the exact object at that coordinate, or undefined if it doesn't exist)

Description:

This method is an upgraded targeting scanner. While we traditionally use square brackets (like fleet[0]) to target a ship object, the at() command allows us to use negative numbers to instantly target the rear guard! For example, fleet.at(-1) will always lock onto the very last object in the formation, no matter how large the fleet is, without needing to calculate the total length first.
