push()

Adding to the End

If we want to deploy a new object to the very back of our array, we use push().

Crucial Note: Because this is a destructive method that mutates the original array, saving the result to a variable does not save the array. Instead, push() returns the new total length (an integer) of the array after the object is added! 

let fleet = [
    {
        name: "Enterprise",
        class: "Cruiser"
    },
    {
        name: "Defiant",
        class: "Escort"
    }
];

// Send a brand new ship object to join the rear of the fleet
let newFleetSize = fleet.push({ name: "Voyager", class: "Intrepid" }); 

console.log(fleet); 
/* Result: [
    { name: "Enterprise", class: "Cruiser" },
    { name: "Defiant", class: "Escort" },
    { name: "Voyager", class: "Intrepid" }
] */

// push() returns the new total number of ships!
console.log(newFleetSize);
// Result: 3

Syntax 

array.push(element1, element2, /* ..., */ elementN)

Return Value

Type: Number (The new total length of the array)

Description:

This method issues a direct order to append new reinforcements to the rear guard. It takes one or more objects and physically attaches them to the very end of the array. Warning: This is a destructive method that permanently mutates your original array! After successfully adding the new elements, it calculates the new size of the formation and returns that length property as an integer.
