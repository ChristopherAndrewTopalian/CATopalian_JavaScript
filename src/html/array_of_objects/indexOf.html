indexOf()

The indexOf() method is a lightning-fast locator beacon. We hand it a specific object, and it sweeps the array from left to right to find it. The moment it detects a perfect match, it returns the Index Number of that object.

Crucial Note: Just like includes(), this method checks for the exact memory reference of the object! If we give it an identical-looking clone, it will fail the scan and return -1. 

let flagship = { 
    name: "Enterprise", 
    class: "Cruiser" 
};

let fleet = [
    { name: "Voyager", class: "Intrepid" },
    flagship, // Docking the exact object reference at Index 1
    { name: "Defiant", class: "Escort" }
];

// Request the exact docking index of the Enterprise reference
let bayNumber = fleet.indexOf(flagship);

console.log(bayNumber); 
// Result: 1 (Remember, arrays always start counting at 0!)

// What happens if we scan for a clone instead of the original?
let cloneNumber = fleet.indexOf({ name: "Enterprise", class: "Cruiser" });

console.log(cloneNumber); 
// Result: -1 (Because the clone is a different object in memory!)

Syntax 

array.indexOf(searchElement, /* optional: */ fromIndex)

Return Value

Type: Number (The exact index position, or -1 if not found)

Description:

This method locks onto a specific target object and sweeps the fleet from front to back. Because it requires strict equality (the exact object reference), we must pass it the original variable, not just matching data. The absolute millisecond it detects the original object, it returns the exact index number (coordinates) of that first match and stops scanning. If the target is nowhere to be found, it safely returns a -1.

Pro-Tip: When working with arrays of objects, developers usually prefer findIndex() over indexOf() so they can search by property names instead of strict memory references!
