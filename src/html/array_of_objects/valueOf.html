valueOf()

The valueOf() method is a foundational JavaScript command that operates under the hood. When we call it on an array, it simply returns the exact array itself.

Crucial Note (Memory References): Because it returns the array itself, it does not make a copy! If we save the result of valueOf() to a new variable, both variables are now pointing to the exact same array in our computer's memory. 

let fleet = [
    { name: "Enterprise", class: "Cruiser" },
    { name: "Defiant", class: "Escort" }
];

// Request the primitive value of the array
let actualValue = fleet.valueOf();

console.log(actualValue); 
/* Result: [
    { name: "Enterprise", class: "Cruiser" },
    { name: "Defiant", class: "Escort" }
] */

// PROVING THE MEMORY REFERENCE:
console.log(actualValue === fleet); 
// Result: true (They are the exact same array!)

actualValue[0].class = "Flagship";
console.log(fleet[0].class); 
// Result: "Flagship" (Changing one immediately changes the other!)

Syntax 

array.valueOf()

Return Value

Type: Array (The original array itself, not a copy!)

Description:

This method is the default behavior for arrays when JavaScript needs to see the "raw" object. We rarely ever type this command out manually, as JavaScript automatically invokes it behind the scenes whenever it needs to evaluate the raw data. It is highly useful for understanding memory in JavaScript, as it proves that returning an array simply returns a pointer to the original fleet, rather than constructing a new one.
