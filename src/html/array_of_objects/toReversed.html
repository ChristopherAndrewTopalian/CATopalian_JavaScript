toReversed()

The classic reverse() method is dangerous because it physically alters the original array. The modern toReversed() method solves this by executing the exact same 180-degree flip, but it safely returns the result as a brand-new array.

Crucial Note (The Shallow Copy): While the new array is physically separate from the old array, it still contains references to the exact same objects! If we mutate an object in the reversed array, it will alter the original object too! 

let standardFormation = [
    { role: "Flagship", ship: "Enterprise" }, // Index 0
    { role: "Escort", ship: "Defiant" },      // Index 1
    { role: "Rear Guard", ship: "Voyager" }   // Index 2
];

// Execute the maneuver safely, generating a completely new array
let invertedFormation = standardFormation.toReversed();

console.log(invertedFormation); 
/* Result: [
    { role: "Rear Guard", ship: "Voyager" },
    { role: "Escort", ship: "Defiant" },
    { role: "Flagship", ship: "Enterprise" }
] */

// The original array's physical formation is perfectly untouched!
console.log(standardFormation[0].role); 
// Result: "Flagship"

// PROVING THE SHALLOW COPY:
invertedFormation[0].ship = "Voyager-B";
console.log(standardFormation[2].ship); 
// Result: "Voyager-B" (The original ship in the rear guard was altered too!)

Syntax 

array.toReversed()

Return Value

Type: Array (A brand-new array containing shallow copies in reverse order)

Description:

Introduced in the modern ES2023 update, this is the completely safe, non-destructive alternative to the classic reverse() command. It executes a complete 180-degree fleet about-face, moving the rear guard to the vanguard and vice versa. However, instead of mutating our existing data structure, it returns the newly ordered formation as a brand-new array. Just remember that it is a shallow copy, the objects inside the new array are the exact same objects sitting in the original array!
