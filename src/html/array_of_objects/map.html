map()

map() is arguably one of the most used methods in all of JavaScript. It sweeps through our original array, takes every single object, runs a function to modify it, and then constructs a brand-new array out of the upgraded results.

It is the ultimate tool for running a fleet-wide retrofit without permanently altering our original database records. 

// Example 1: ES5 Version

let oldFleet = [
    { name: "Enterprise", class: "Cruiser" },
    { name: "Defiant", class: "Escort" },
    { name: "Voyager", class: "Intrepid" }
];

// Upgrade the fleet by creating brand-new objects with a "status" property
let upgradedFleet = oldFleet.map(function(ship) {
    return {
        name: ship.name,
        class: ship.class,
        status: "Refitted"
    };
});

console.log(upgradedFleet); 
/* Result: [
    { name: "Enterprise", class: "Cruiser", status: "Refitted" },
    { name: "Defiant", class: "Escort", status: "Refitted" },
    { name: "Voyager", class: "Intrepid", status: "Refitted" }
] */

// The original fleet remains safely untouched!
console.log(oldFleet[0].status); // Result: undefined

// Example 2: ES6 Version

let oldFleet = [
    { name: "Enterprise", class: "Cruiser" },
    { name: "Defiant", class: "Escort" },
    { name: "Voyager", class: "Intrepid" }
];

// In ES6, wrap the returned object {} in parentheses () to avoid syntax errors!
let upgradedFleet = oldFleet.map(ship => ({
    name: ship.name,
    class: ship.class,
    status: "Refitted"
}));

console.log(upgradedFleet); 
/* Result: [
    { name: "Enterprise", class: "Cruiser", status: "Refitted" },
    { name: "Defiant", class: "Escort", status: "Refitted" },
    { name: "Voyager", class: "Intrepid", status: "Refitted" }
] */

Syntax (ES5 Version) 

array.map(function(element, index, array) { 
    /* return the modified object */ 
})

Syntax (ES6 Version) 

array.map((element, index, array) => { /* return the modified object */ })

Return Value

Type: Array (A brand-new array containing the upgraded objects)

Description:

This method executes a complete fleet-wide retrofit. It sweeps through the array, takes every single object, runs our function to extract or modify its data, and then constructs a brand-new array out of the upgraded results. Because we construct completely new objects inside the return statement, it is the ultimate tool for safely upgrading data without permanently mutating our original fleet records.
