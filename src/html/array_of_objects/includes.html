includes()

If we need to know immediately if a specific object exists in our massive database, run an includes() check. It returns a simple, lightning-fast true or false boolean value.

Crucial Note: When searching for an object, includes() checks for the exact memory reference, not just matching data! An identical-looking clone will return false. We must scan for the original object itself! 

let defiantShip = { 
    name: "Defiant", 
    class: "Escort" 
};

let fleet = [
    { name: "Enterprise", class: "Cruiser" },
    defiantShip, // Adding the exact original object to the fleet
    { name: "Voyager", class: "Intrepid" }
];

// Scan the array for the exact object reference in memory
let isDefiantSafe = fleet.includes(defiantShip);

console.log(isDefiantSafe); 
// Result: true

// Scan for an identical-looking ship (but a new object in memory)
let isCloneSafe = fleet.includes({ name: "Defiant", class: "Escort" });

console.log(isCloneSafe); 
// Result: false (Because it is a clone, not the original ship!)

Syntax 

array.includes(searchElement, /* optional: */ fromIndex)

Return Value

Type: Boolean (true or false)

Description:

This method is a simple, highly effective proximity scanner. It checks if our array contains one specific object. Because it checks strict equality (the exact object reference in our computer's memory), we cannot just pass it a similar-looking set of data. If the exact target object is detected anywhere in the formation, it instantly returns true. If the scan completes and the target is missing, it returns false.
