of()

Just like from(), Array.of() is a Static Method called directly on the worldwide Array object. It takes whatever individual arguments we hand it (including complex objects) and instantly packs them into a brand-new array.

It was specifically engineered to fix a weird quirk in older JavaScript where typing Array(7) would create an array with 7 empty ghost slots, but typing Array.of(7) correctly creates an array containing the actual number 7! 

// Requisition a new Away Team by passing in standalone officer objects
let awayTeam = Array.of(
    { name: "Worf", role: "Security" },
    { name: "Data", role: "Operations" },
    { name: "Riker", role: "First Officer" }
);

console.log(awayTeam); 
/* Result: [
    { name: "Worf", role: "Security" },
    { name: "Data", role: "Operations" },
    { name: "Riker", role: "First Officer" }
] */

// The historical number quirk it fixes:
console.log(Array.of(7)); 
// Result: [7]

Syntax 

Array.of(element0, element1, /* ..., */ elementN)

Return Value

Type: Array (A brand-new, officially commissioned array of objects)

Description:

Notice: This is a Static Method! Called directly on the Array master computer, this command directly requisitions a new fleet from a list of independent ships, objects, or data points. It bypasses the historical "ghost fleet" anomaly (where Array(7) generates seven empty slots) and guarantees that exactly what we request, whether it's an integer or a complex object literal, is exactly what gets loaded into the new array format.
