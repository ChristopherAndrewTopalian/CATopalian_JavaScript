slice()

Sometimes we need to look at a section of our array without destroying the original list. slice() makes a perfect copy of a specific chunk of the array. It takes a starting index and an ending index.

Crucial Note (The Shallow Copy): When using slice() on an array of objects, it copies the references to those objects, not the objects themselves! If we alter an object in our new sliced array, that same object will also change in our original array! 

let fleet = [
    { name: "Enterprise", class: "Cruiser" }, // Index 0
    { name: "Discovery", class: "Science" },  // Index 1
    { name: "Defiant", class: "Escort" },     // Index 2
    { name: "Voyager", class: "Intrepid" }    // Index 3
];

// Copy from Index 1 up to (but not including) Index 3
let assaultTeam = fleet.slice(1, 3); 

console.log(assaultTeam); 
/* Result: [
    { name: "Discovery", class: "Science" },
    { name: "Defiant", class: "Escort" }
] */

// PROVING THE SHALLOW COPY:
assaultTeam[0].class = "Warship";
console.log(fleet[1].class); 
// Result: "Warship" (The original Discovery was altered too!)

Syntax 

array.slice(start, /* optional: */ end)

Return Value

Type: Array (A brand-new array containing shallow copies of the extracted objects)

Description:

This method safely extracts a specific sector of our array and returns it as a new array. It begins copying at the start index and stops right before the end index. If we do not provide an end index, it copies everything from the start point all the way to the end of the line. The original fleet array remains structurally untouched, but beware: because this is a shallow copy, both arrays are still pointing to the exact same ship objects in our computer's memory!
