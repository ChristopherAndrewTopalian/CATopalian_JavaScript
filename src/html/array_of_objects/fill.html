fill()

fill() is a heavy-handed command. It takes an existing array of objects and completely overwrites the items inside it with a single, static object. We can overwrite the entire array, or specify a start and end index to only overwrite a specific sector.

Crucial Note: When filling with an object, it places the exact same object reference into every targeted slot. Modifying one of those filled objects will modify all of them! 

let dockingBays = [
    {
        bay: 1,
        status: "Empty"
    },
    {
        bay: 2,
        status: "Empty"
    },
    {
        bay: 3,
        status: "Empty"
    },
    {
        bay: 4,
        status: "Empty"
    }
];

let standardShuttle = { 
    name: "Type-8 Shuttle", 
    status: "Docked" 
};

// A fleet just arrived. Overwrite bays starting at Index 1 up to Index 3.
dockingBays.fill(standardShuttle, 1, 3);

console.log(dockingBays); 
/* Result: [
    { bay: 1, status: "Empty" },
    { name: "Type-8 Shuttle", status: "Docked" },
    { name: "Type-8 Shuttle", status: "Docked" },
    { bay: 4, status: "Empty" }
] */

Syntax 

array.fill(value, /* optional: */ start, end)

Return Value

Type: Array (The original array, physically modified)

Description:

This method issues a blanket replacement order across the fleet. It takes one static value (in our case, a single ship object) and aggressively overwrites the existing objects in the array with it. We can deploy it across the entire array, or restrict it to a specific sector using the start and end indexes. Warning: This is a destructive maneuver! It permanently destroys the original objects in those target slots and replaces them with a uniform clone.
