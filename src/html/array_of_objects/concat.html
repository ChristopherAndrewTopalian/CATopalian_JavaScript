concat()

When we have two separate arrays of objects and we need to merge them into one massive fleet, we use concat(). This method does not alter our original arrays; instead, it returns a brand-new array containing all the combined ship objects. 

let alphaSquadron = [
    {
        name: "Enterprise",
        class: "Cruiser"
    },
    {
        name: "Discovery",
        class: "Science"
    }
];

let betaSquadron = [
    {
        name: "Defiant",
        class: "Escort"
    },
    {
        name: "Voyager",
        class: "Intrepid"
    }
];

// Merge Beta Squadron objects into Alpha Squadron
let grandArmada = alphaSquadron.concat(betaSquadron);

console.log(grandArmada); 
/* Result: [
    { name: "Enterprise", class: "Cruiser" },
    { name: "Discovery", class: "Science" },
    { name: "Defiant", class: "Escort" },
    { name: "Voyager", class: "Intrepid" }
] */
Star Fleet Video Tutorial

Syntax 

array.concat(array2, array3, /* ..., */ arrayN)

Return Value

Type: Array (A brand-new, combined array containing all the objects)

Description:

This method is used to assemble a massive allied armada. It takes our original array of objects and seamlessly merges it with one or more additional arrays of objects. The most important tactical detail: it is completely non-destructive! It leaves the original squadron arrays perfectly intact in their respective sectors and returns a brand-new array containing the combined forces.
