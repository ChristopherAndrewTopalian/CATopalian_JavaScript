flatMap()

The flatMap() method is a highly efficient, two-in-one command. First, it sweeps through our array and runs a function on every object (just like a standard map()). Then, it automatically takes the results and flattens them into a single, one-dimensional array.

It is the perfect tool for when we need to deploy multiple sub-objects (like shuttles) from a list of parent ships, but we want all those deployed objects to end up in one unified list, rather than a bunch of separate, nested lists. 

// Example 1: ES5 Version

let ships = [
    {
        name: "Enterprise",
        class: "Cruiser"
    },
    {
        name: "Voyager",
        class: "Intrepid"
    }
];

// Command each ship object to deploy an array of two shuttle objects
let deployedShuttles = ships.flatMap(function(ship) {
    return [
        { parent: ship.name, designation: "Shuttle 1" },
        { parent: ship.name, designation: "Shuttle 2" }
    ];
});

console.log(deployedShuttles); 
/* Result: [
    { parent: "Enterprise", designation: "Shuttle 1" },
    { parent: "Enterprise", designation: "Shuttle 2" },
    { parent: "Voyager", designation: "Shuttle 1" },
    { parent: "Voyager", designation: "Shuttle 2" }
] */

// Example 2: ES6 Version

let ships = [
    {
        name: "Enterprise",
        class: "Cruiser"
    },
    {
        name: "Voyager",
        class: "Intrepid"
    }
];

// Command each ship object to deploy an array of two shuttle objects
let deployedShuttles = ships.flatMap(ship => [
    { parent: ship.name, designation: "Shuttle 1" },
    { parent: ship.name, designation: "Shuttle 2" }
]);

console.log(deployedShuttles); 
/* Result: [
    { parent: "Enterprise", designation: "Shuttle 1" },
    { parent: "Enterprise", designation: "Shuttle 2" },
    { parent: "Voyager", designation: "Shuttle 1" },
    { parent: "Voyager", designation: "Shuttle 2" }
] */

Syntax (ES5 Version) 

array.flatMap(function(element, index, array) { 
    /* return the modified and unpacked object */ 
})

Syntax (ES6 Version) 

array.flatMap((element, index, array) => { /* return the modified and unpacked object */ })

Return Value

Type: Array (A brand-new, completely unpacked array of objects)

Description:

This advanced command executes two distinct tactical maneuvers at the exact same time. First, it sweeps the fleet and modifies each object (just like map()). But then, if any of those modified results are themselves an array (like returning a squadron of fighter objects from a carrier), it immediately "unpacks" them, flattening everything out into one single, unified brand-new array. Note that it only flattens one level deep.
