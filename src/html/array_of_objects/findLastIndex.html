findLastIndex()

findLastIndex() scans our array of objects in reverse (starting from the back) and returns the index number of the very first match it encounters. 

// Example 1: ES5 Version

let commsLog = [
    {
        time: "0800",
        status: "Clear"
    },
    {
        time: "0900",
        status: "Static"
    },
    {
        time: "1000",
        status: "Clear"
    },
    {
        time: "1100",
        status: "Static"
    },
    {
        time: "1200",
        status: "Clear"
    }
];

// Find the exact index number of the most recent "Static" burst
let latestInterferenceIndex = commsLog.findLastIndex(function(log) {
    return log.status === "Static";
});

console.log(latestInterferenceIndex); 
// Result: 3 (Because the 1100 log entry is sitting at index 3!)

// Example 2: ES6 Version

let commsLog = [
    {
        time: "0800",
        status: "Clear"
    },
    {
        time: "0900",
        status: "Static"
    },
    {
        time: "1000",
        status: "Clear"
    },
    {
        time: "1100",
        status: "Static"
    },
    {
        time: "1200",
        status: "Clear"
    }
];

// Find the exact index number of the most recent "Static" burst
let latestInterferenceIndex = commsLog.findLastIndex(log => log.status === "Static");

console.log(latestInterferenceIndex); 
// Result: 3 (Because the 1100 log entry is sitting at index 3!)

Syntax (ES5 Version) 

array.findLastIndex(function(element, index, array) { 
    /* return true or false */ 
})

Syntax (ES6 Version) 

array.findLastIndex((element, index, array) => { /* return true or false */ })

Return Value

Type: Number (The index position, or -1)

Description:

findLastIndex() scans our array of objects in reverse (starting from the back) and returns the exact index number (coordinates) of the very first matching object it encounters. If the rear-guard sweep finishes and detects absolutely no objects matching the condition, it safely returns a -1.
