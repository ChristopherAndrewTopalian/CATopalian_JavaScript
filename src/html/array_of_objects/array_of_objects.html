Arrays of Objects

What is an Array of Objects?

So far, we have used arrays to store simple lists of strings or numbers, like a list of ship names. But what if we need to store a lot of details about each ship?

By placing Objects (which hold data in key-value pairs) inside an Array (which keeps things in an ordered list), we can build a highly organized, easily searchable database.

Building the Fleet Database

Notice that the array is still wrapped in square brackets [ ], but every individual item inside the list is an object wrapped in curly braces { }. 

let starfleet = [
    {
        name: "Enterprise",
        class: "Galaxy",
        captain: "Picard"
    },
    {
        name: "Defiant",
        class: "Escort",
        captain: "Sisko"
    },
    {
        name: "Voyager",
        class: "Intrepid",
        captain: "Janeway"
    }
];

Accessing the Data

To read data from an array of objects, we have to combine two tools: Bracket Notation to find the exact object in the line, and Dot Notation to pull the specific property out of that object. 

// 1. First, we target the first ship in the array (Index 0)
// 2. Then, we ask for its "name" property

let flagship = starfleet[0].name; 
console.log(flagship); // Returns "Enterprise"

let toughShip = starfleet[1].class;
console.log(toughShip); // Returns "Escort"

let lostCaptain = starfleet[2].captain;
console.log(lostCaptain); // Returns "Janeway"

Why is this so powerful?

Because this structure perfectly mimics how data is sent across the internet (like JSON). Once your data is formatted as an array of objects, you can easily use JavaScript to filter out specific ships, sort them by class, or loop through the entire list to display them on a screen!
