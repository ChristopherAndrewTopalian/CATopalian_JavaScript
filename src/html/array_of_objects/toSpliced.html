toSpliced()

The classic splice() is a heavy-duty, destructive tool that permanently rips objects out of the original array. The modern toSpliced() allows us to remove or inject objects at a specific index, but it generates a fresh, updated copy of the array instead of tearing the original one apart.

Crucial Note (The Return Value): Unlike the classic method which hands us back the deleted objects, toSpliced() hands us the entire new array. And because it creates a new array, remember that it is a Shallow Copy, the objects inside still share the same memory references as the original! 

let fleet = [
    { name: "Enterprise", class: "Cruiser" }, // Index 0
    { name: "Defiant", class: "Escort" },     // Index 1
    { name: "Voyager", class: "Intrepid" }    // Index 2
];

// Target Index 1. Remove 1 ship (Defiant). Insert the Discovery object.
let updatedFleet = fleet.toSpliced(1, 1, { name: "Discovery", class: "Science" });

console.log(updatedFleet); 
/* Result: [
    { name: "Enterprise", class: "Cruiser" },
    { name: "Discovery", class: "Science" },
    { name: "Voyager", class: "Intrepid" }
] (The Discovery successfully took Index 1 in the NEW array!) */

// Proof that the original fleet is completely untouched!
console.log(fleet[1].name); 
// Result: "Defiant" (It is still safely sitting at Index 1 in the old array!)

Syntax 

array.toSpliced(start, deleteCount, item1, item2, /* …, */ itemN)

Return Value

Type: Array (A brand-new array containing shallow copies, with the specified modifications applied)

Description:

Introduced in the modern ES2023 update, this is the completely safe, non-destructive alternative to the classic splice() maneuver. It allows you to target a specific coordinate (index), remove a specific number of ships, and instantly deploy new ship objects into that exact gap. However, instead of permanently mutilating the original data, it executes these heavy modifications and returns the final result as a brand-new array. Our original fleet remains safely docked and perfectly intact.
