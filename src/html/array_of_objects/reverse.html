reverse()

The reverse() method takes our array of objects and physically flips the entire order of the fleet from front to back.

Warning: This method physically alters our original array rather than making a safe copy! 

let formation = [
    {
        role: "Flagship",
        ship: "Enterprise"
    },
    {
        role: "Escort",
        ship: "Defiant"
    },
    {
        role: "Rear Guard",
        ship: "Voyager"
    }
];

// Execute a 180-degree fleet-wide turn
formation.reverse();

console.log(formation); 
/* Result: [
    { role: "Rear Guard", ship: "Voyager" },
    { role: "Escort", ship: "Defiant" },
    { role: "Flagship", ship: "Enterprise" }
] */

Syntax 

array.reverse()

Return Value

Type: Array (The original array, completely inverted)

Description:

This method orders an immediate, fleet-wide about-face. It physically flips the entire formation end-to-end, so the ship object parked in the front becomes the rear guard, and the ship object in the back becomes the new vanguard. The objects themselves remain perfectly intact, just in a new order. Warning: Just like the sort() command, this is a destructive maneuver! It does not create a new array; it permanently alters the physical formation of the original array.
