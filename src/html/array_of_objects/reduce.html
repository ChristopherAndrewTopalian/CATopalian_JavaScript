reduce()

reduce() is arguably the most powerful (and most complex) method in JavaScript. It sweeps through our entire array of objects and "reduces" specific data from them down into one single output value (like a total sum).

It uses an "Accumulator" (a running total) that gets updated every time it looks at the next ship in the line.

Crucial Note: When reducing objects, we must provide an initialValue (like 0) at the end of the method! If we forget it, JavaScript will try to use the first entire object as a number, completely breaking the math! 

// Example 1: ES5 Version

let fleet = [
    { name: "Enterprise", crew: 1000 },
    { name: "Defiant", crew: 150 },
    { name: "Voyager", crew: 500 }
];

// Calculate the total number of personnel in the fleet
// 'total' is the accumulator, 'ship' is the current object being counted
let totalPersonnel = fleet.reduce(function(total, ship) {
    return total + ship.crew;
}, 0); // <-- This 0 is ABSOLUTELY CRITICAL when working with objects!

console.log(totalPersonnel); 
// Result: 1650

// Example 2: ES6 Version

let fleet = [
    { name: "Enterprise", crew: 1000 },
    { name: "Defiant", crew: 150 },
    { name: "Voyager", crew: 500 }
];

// Calculate the total number of personnel in the fleet
let totalPersonnel = fleet.reduce((total, ship) => total + ship.crew, 0);

console.log(totalPersonnel); 
// Result: 1650

Syntax (ES5 Version) 

array.reduce(function(accumulator, currentValue, currentIndex, array) { 
    /* return the updated accumulator */ 
}, initialValue)

Syntax (ES6 Version) 

array.reduce((accumulator, currentValue, currentIndex, array) => { 
    /* return the updated accumulator */ 
}, initialValue)

Return Value

Type: Any (Returns a single compiled value, like a Number, String, or even a new Object)

Description:

This is the absolute heavyweight champion of JavaScript. It sweeps through the entire array of objects and "reduces" their internal data down into one single output value (like calculating the total crew count of an entire fleet). It uses an "accumulator" to keep a running total as it moves from ship to ship. We must always provide an initialValue (like 0) at the end of the method when working with objects to ensure the accumulator starts as a clean number instead of accidentally grabbing an object!
