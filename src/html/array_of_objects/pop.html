pop()

Removing from the End

pop() does the exact opposite of push(). It plucks the very last object off the end of the array and completely removes it from the list. 

let fleet = [
    {
        name: "Enterprise",
        class: "Cruiser"
    },
    {
        name: "Defiant",
        class: "Escort"
    },
    {
        name: "Voyager",
        class: "Intrepid"
    }
];

// The last ship object gets decommissioned and removed from the array
let decommissionedShip = fleet.pop(); 

console.log(fleet); 
/* Result: [
    { name: "Enterprise", class: "Cruiser" },
    { name: "Defiant", class: "Escort" }
] */

// pop() actually hands us the removed object!
console.log(decommissionedShip);
// Result: { name: "Voyager", class: "Intrepid" }

Syntax 

array.pop()

Return Value

Type: Object (Returns the exact object that was removed, or undefined if the array was empty)

Description:

This method issues a direct decommissioning order to the rear guard. It plucks the very last object out of the array and physically shrinks the size of the fleet. Warning: This is a destructive method that permanently mutates the original array! However, it does not just vaporize the data; it actively returns the exact object that was just removed so we can store it in a variable or log its final status. If we use pop() on an entirely empty array, it safely returns undefined.
