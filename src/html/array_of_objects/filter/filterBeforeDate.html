AOO filterBeforeDate()

In our previous modules, we searched for exact text matches. But what if we need to review all ship logs that occurred before a specific chronological event, like an encounter with a spatial anomaly? To do this, we must temporarily upgrade our date strings into powerful Date objects. Once JavaScript recognizes the data as actual time, we can simply use the standard mathematical Less-Than operator (<) to sweep the past! 

// A standard Array of Objects (AOO) containing chronological ship logs
let shipLogs = [
    { event: "Departed Spacedock", date: "2026/01/01" },
    { event: "Crossed Neutral Zone", date: "2026/02/15" },
    { event: "Discovered Anomaly", date: "2026/03/10" },
    { event: "Initiated Evasive Maneuvers", date: "2026/03/12" },
    { event: "Repaired Hull Plating", date: "2026/03/15" }
];

let targetDateString = "2026/03/10"; 

// THE OLD WAY (Manual Sensor Sweep)
function filterBeforeDateManual(whichArray, whichDate) {
    let result = [];
    // Convert our target text string into a real Time object
    let targetTime = new Date(whichDate); 

    for (let z = 0; z < whichArray.length; z++) {
        // Convert the current log's date text into a Time object
        let itemTime = new Date(whichArray[z].date);

        // If the log's time is LESS THAN (before) our target time, keep it!
        if (itemTime < targetTime) {
            result.push(whichArray[z]);
        }
    }
    return result;
}

// THE MODERN WAY (Reusable Automated Function)
function filterBeforeDate(whichArray, whichDate) {
    let targetTime = new Date(whichDate);

    return whichArray.filter(function(item) {
        let itemTime = new Date(item.date);
        
        // The filter keeps the item only if it happened before the target!
        return itemTime < targetTime; 
    });
}

let logsBeforeAnomaly = filterBeforeDate(shipLogs, targetDateString);
console.log(logsBeforeAnomaly); 
// Result: We only get "Departed Spacedock" and "Crossed Neutral Zone"!

Direct Filtering (On The Fly!)

Just as we learned before, we can run this chronological sweep directly inline. Imagine we are building an interface for the Chief Engineer, and we need to instantly find all maintenance tickets that were submitted prior to a massive system upgrade on January 1st, 2026. We can convert the dates and filter the array all in one smooth motion! 

// A database of engineering tickets
let maintenanceTickets = [
    { system: "Life Support", status: "Resolved", date: "2025/11/14" },
    { system: "Deflector Dish", status: "Pending", date: "2025/12/28" },
    { system: "Warp Coils", status: "Resolved", date: "2026/01/05" },
    { system: "Transporters", status: "Pending", date: "2026/02/10" }
];

// We define our threshold (The big system upgrade on Jan 1st)
let upgradeTime = new Date("2026/01/01");

// Filter on the fly to find tickets from BEFORE the upgrade
let oldTickets = maintenanceTickets.filter(function(ticket) {
    return new Date(ticket.date) < upgradeTime;
});

console.log(oldTickets);
// We now have an array containing only the 2025 tickets (Life Support & Deflector Dish)!

Description:

The magic of this filter relies entirely on the new Date() constructor. When we pass a properly formatted date string (like "2026/03/10") into new Date(), JavaScript internally converts it into a massive number representing the exact amount of milliseconds that have passed since January 1st, 1970. Because both dates are suddenly translated into pure numbers, the Less-Than operator (<) works perfectly. It literally asks: "Is the millisecond value of this ship log a smaller number than the millisecond value of our target date?"
