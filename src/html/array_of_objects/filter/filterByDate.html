AOO filterByDate()

Sometimes we don't want a whole month or an entire year of logs; we need to pull the exact records from one specific day. Because we are looking for the entire date string in its exact format ("YYYY/MM/DD"), we don't need to chop it into pieces. We simply ask the JavaScript engine if the object's date is strictly equal (===) to our target date! 

// A standard Array of Objects (AOO) containing ship logs
let shipLogs = [
    { mission: "Maiden Voyage", date: "2024/02/05" },
    { mission: "Routine Patrol", date: "2026/03/09" },
    { mission: "Nebula Survey", date: "2026/03/10" },
    { mission: "Medical Evacuation", date: "2026/03/10" },
    { mission: "Asteroid Mining", date: "2026/03/11" }
];

let targetDate = "2026/03/10"; 

// THE OLD WAY (Manual Sensor Sweep)
function filterByDateManual(whichArray, whichDate) {
    let result = [];
    for (let z = 0; z < whichArray.length; z++) {
        if (whichArray[z].date === whichDate) {
            result.push(whichArray[z]);
        }
    }
    return result;
}

// THE MODERN WAY (Reusable Automated Function)
function filterByDate(whichArray, whichDate) {
    return whichArray.filter(function(item) {
        return item.date === whichDate; 
    });
}

let exactDayLogs = filterByDate(shipLogs, targetDate);
console.log(exactDayLogs);

Direct Filtering (On The Fly!)

Do we have to create a named wrapper function like filterByDate() every single time? Absolutely not!

One of the greatest superpowers of modern JavaScript is that we can apply a filter directly to an array and instantly save the result to a variable. When we are building a user interface and just need to grab specific data quickly, we can do it "inline" without ever writing a separate function box. 

// Imagine a massive database of Starfleet operations
let allMethods = [
    { name: "Alpha Protocol", category: "AOO_filter" },
    { name: "Beta Protocol", category: "core_system" },
    { name: "Gamma Protocol", category: "AOO_filter" }
];

// We can instantly create a brand new variable and filter directly into it!
let aooFilterLogs = allMethods.filter(function(item) {
    return item.category === "AOO_filter";
});

console.log(aooFilterLogs);
// We now have a clean array of ONLY the AOO_filter operations, built in a single step!

Description:

Whether we wrap it in a custom function for repeated use, or assign it directly to a variable on the fly, .filter() uses the Strict Equality Operator (===) to check both the value and the type of the data. Because both our target date and the database log are formatted as text strings, the engine compares them character by character. If a single number or slash is out of place, it returns false and the item is discarded.
