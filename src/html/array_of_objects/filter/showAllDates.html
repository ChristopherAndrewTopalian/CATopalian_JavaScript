AOO showAllDates()

Up until now, we have used .filter() to find specific objects and throw away the rest. But what if we don't want to throw anything away? What if we want to look at every single log in the ship's database, but we only want to extract the dates? To rip a single "column" of data out of a massive Array of Objects (AOO), we use the incredibly powerful .map() method! It sweeps through our objects, grabs the exact property we ask for, and hands us a clean array containing only that specific data. 

// A standard Array of Objects (AOO) containing detailed ship logs
let starshipDatabase = [
    { mission: "Asteroid Mining", sector: "Alpha", date: "2026/01/14" },
    { mission: "Diplomatic Escort", sector: "Beta", date: "2026/02/05" },
    { mission: "Nebula Survey", sector: "Gamma", date: "2026/03/22" }
];

// THE OLD WAY (Manual Sensor Sweep)
function showAllDatesManual(whichArray) {
    let result = [];
    for (let z = 0; z < whichArray.length; z++) {
        // We manually push just the 'date' property into our new array
        result.push(whichArray[z].date);
    }
    return result;
}

// THE MODERN WAY (Reusable Automated Function)
function showAllDates(whichArray) {
    // The .map() method automatically builds and returns the new array for us!
    return whichArray.map(function(item) {
        // We tell the map exactly which piece of data to extract from the object
        return item.date; 
    });
}

// We run our function to extract the data
let justTheDates = showAllDates(starshipDatabase);
console.log(justTheDates); 
// Result: ["2026/01/14", "2026/02/05", "2026/03/22"]
// We get a perfect list of strings, completely separated from the complex objects!

Direct Extraction (On The Fly!)

Just like our filter sweeps, we can use .map() directly inline when building user interfaces. Imagine we are building a dropdown menu for the ship's calendar, and we need a simple array of all the dates we currently have logs for. We can extract them on the fly! 

// A database of Chief Medical Officer treatment logs
let medicalLogs = [
    { patient: "Lt. Sulu", treatment: "Dermal Regenerator", date: "2026/04/10" },
    { patient: "Ens. Chekov", treatment: "Radiation Detox", date: "2026/04/12" },
    { patient: "Cmdr. Spock", treatment: "Green Blood Analysis", date: "2026/04/15" }
];

// Extract just the dates on the fly to populate our UI calendar
let treatmentDates = medicalLogs.map(function(log) {
    return log.date;
});

console.log(treatmentDates);
// We instantly have our clean array: ["2026/04/10", "2026/04/12", "2026/04/15"]

Syntax 

let newArray = oldArray.map(function(item) {
    return item.propertyName; // The exact piece of data you want to extract
});

Return Value

Type: Array (A completely new array containing the exact same number of items as the original array, but populated only with the specific data we extracted.)

Description:

The .map() method is the ultimate data transformer. Unlike .filter(), which can return a smaller array if items fail the test, .map() will always return an array of the exact same length as the original. If you feed it 100 objects, it will return 100 extracted properties. This makes it the absolute best tool in JavaScript for separating a single column of data (like a list of dates, names, or ID numbers) from a massive, complex database so we can display it cleanly in our interfaces.
