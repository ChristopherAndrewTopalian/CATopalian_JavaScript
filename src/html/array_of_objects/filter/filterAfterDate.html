AOO filterAfterDate()

When dealing with post-mission reports, discovering which events happened after a specific chronological anchor is critical. We use the exact same strategy as before: we temporarily upgrade our text strings into Date objects. But this time, we use the mathematical Greater-Than operator (>) to isolate all logs that occurred after our target date! 

// A standard Array of Objects (AOO) containing chronological ship logs
let shipLogs = [
    { event: "Departed Spacedock", date: "2026/01/01" },
    { event: "Crossed Neutral Zone", date: "2026/02/15" },
    { event: "Discovered Anomaly", date: "2026/03/10" },
    { event: "Initiated Evasive Maneuvers", date: "2026/03/12" },
    { event: "Repaired Hull Plating", date: "2026/03/15" }
];

// We want to see everything that happened AFTER we found the anomaly
let targetDateString = "2026/03/10"; 

// THE OLD WAY (Manual Sensor Sweep)
function filterAfterDateManual(whichArray, whichDate) {
    let result = [];
    let targetTime = new Date(whichDate); 

    for (let z = 0; z < whichArray.length; z++) {
        let itemTime = new Date(whichArray[z].date);

        // If the log's time is GREATER THAN (after) our target time, keep it!
        if (itemTime > targetTime) {
            result.push(whichArray[z]);
        }
    }
    return result;
}

// THE MODERN WAY (Reusable Automated Function)
function filterAfterDate(whichArray, whichDate) {
    let targetTime = new Date(whichDate);

    return whichArray.filter(function(item) {
        let itemTime = new Date(item.date);
        
        // The filter keeps the item only if it happened after the target!
        return itemTime > targetTime; 
    });
}

let postAnomalyLogs = filterAfterDate(shipLogs, targetDateString);
console.log(postAnomalyLogs); 
// Result: We only get "Initiated Evasive Maneuvers" and "Repaired Hull Plating"!

Direct Filtering (On The Fly!)

Let's apply our inline filtering superpower to a real Starfleet logistics problem. Imagine we have a massive database of newly commissioned starships, and Command needs a quick list of all vessels launched after the new stardate protocol began on March 1st, 2026. We can grab this precise data without ever building a permanent function! 

// A database of starship launch dates
let fleetLaunches = [
    { ship: "USS Titan", class: "Luna", launch: "2025/08/10" },
    { ship: "USS Zheng He", class: "Inquiry", launch: "2025/11/22" },
    { ship: "USS Stargazer", class: "Sagan", launch: "2026/03/05" },
    { ship: "USS Excelsior", class: "Excelsior II", launch: "2026/04/18" }
];

// Our target threshold (The new protocol date)
let protocolDate = new Date("2026/03/01");

// Filter on the fly to find ships launched AFTER the protocol
let newVessels = fleetLaunches.filter(function(vessel) {
    return new Date(vessel.launch) > protocolDate;
});

console.log(newVessels);
// We now instantly have the Stargazer and the Excelsior ready for deployment!

Description:

By upgrading our text into Date objects, we tap into JavaScript's internal chronological clock (which tracks time in pure milliseconds). Because of this, the Greater-Than operator (>) works flawlessly. The engine simply asks: "Does this log's date have a higher millisecond count than our target date?" Because dates further in the future always have a higher millisecond value, the sweep perfectly isolates events that happened after our anchor point!
