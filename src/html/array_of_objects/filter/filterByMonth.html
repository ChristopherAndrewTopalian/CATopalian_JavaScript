AOO filterByMonth()

When we are sorting through massive arrays of objects (AOO), we often need to isolate records from a specific timeframe. If our dates are formatted as text strings (like "YYYY/MM/DD"), we can use the .split('/') method to chop that string into an array of smaller pieces. Once we isolate the specific piece representing the month, we can run our .filter() sweep to instantly extract the exact logs we need! 

// A standard Array of Objects (AOO) containing ship logs
let shipLogs = [
    { mission: "Routine Patrol", date: "2026/01/15" },
    { mission: "Diplomatic Transport", date: "2026/02/08" },
    { mission: "Warp Core Refit", date: "2026/02/24" },
    { mission: "Nebula Survey", date: "2026/03/10" }
];

let targetMonth = "02"; // We want all logs from February

// THE OLD WAY (Manual Sensor Sweep)
function filterByMonthManual(whichArray, whichMonth) {
    let result = [];
    for (let z = 0; z < whichArray.length; z++) {
        // Chop the date string into 3 pieces: ["2026", "02", "08"]
        let parts = whichArray[z].date.split('/');

        // Check if the middle piece (index 1) matches our target month
        if (parts[1] === whichMonth) {
            result.push(whichArray[z]);
        }
    }
    return result;
}

// THE MODERN WAY (Automated Filtering)
function filterByMonth(whichArray, whichMonth) {
    // We return the .filter() directly! No empty arrays or push() needed.
    return whichArray.filter(function(item) {
        let parts = item.date.split('/');
        
        // If this equals true, the item is automatically kept!
        return parts[1] === whichMonth; 
    });
}

let februaryLogs = filterByMonth(shipLogs, targetMonth);
console.log(februaryLogs); 
// Result: We get the Diplomatic Transport and Warp Core Refit logs!

Syntax 

function filterByMonth(whichArray, whichMonth)

Return Value

Type: Array (A new array of objects containing only the records that occurred during the target month.)

Description:

This custom wrapper function perfectly merges string manipulation with array iteration. The .split('/') method looks for the slash characters and physically cuts the string at those exact points, creating a temporary sub-array of text. Because array indexes always start at 0, parts[0] holds the Year, parts[1] holds the Month, and parts[2] holds the Day. By returning the strict equality comparison (===) inside the filter's callback function, the JavaScript engine handles all the heavy lifting of copying the matching objects into a new, purified database.
