AOO filterByName()

When we manage crew manifests, equipment inventories, or starship registries, we frequently need to search our arrays for a specific name. Because a name is just a string of text, we can use the exact same logic we used for dates! We simply ask the JavaScript engine to sweep through the objects and check if the name property is strictly equal (===) to our target string. 

// A standard Array of Objects (AOO) representing our crew manifest
let crewManifest = [
    { name: "Picard", rank: "Captain", department: "Command" },
    { name: "La Forge", rank: "Lieutenant Commander", department: "Engineering" },
    { name: "Data", rank: "Lieutenant Commander", department: "Operations" },
    { name: "Crusher", rank: "Commander", department: "Medical" },
    { name: "Worf", rank: "Lieutenant", department: "Security" }
];

let targetName = "Data"; 

// THE OLD WAY (Manual Sensor Sweep)
function filterByNameManual(whichArray, whichName) {
    let result = [];
    for (let z = 0; z < whichArray.length; z++) {
        // We use strict equality to check if the text matches exactly
        if (whichArray[z].name === whichName) {
            result.push(whichArray[z]);
        }
    }
    return result;
}

// THE MODERN WAY (Reusable Automated Function)
function filterByName(whichArray, whichName) {
    return whichArray.filter(function(item) {
        // The filter keeps the item only if the name is an exact match!
        return item.name === whichName; 
    });
}

let androidOfficer = filterByName(crewManifest, targetName);
console.log(androidOfficer); 
// Result: We extract the exact object containing Commander Data's record!

Direct Filtering (On The Fly!)

Just like we saw with dates, we don't always need to build a reusable function. If we are deep in the middle of writing an interface and we suddenly need to pull the tactical specs for a specific starship, we can run our .filter() directly on the array and assign it straight to a new variable! 

// A massive database of active Starfleet vessels
let fleetRoster = [
    { name: "USS Enterprise", class: "Galaxy", status: "Active" },
    { name: "USS Defiant", class: "Defiant", status: "Docked" },
    { name: "USS Voyager", class: "Intrepid", status: "Delta Quadrant" },
    { name: "USS Cerritos", class: "California", status: "Active" }
];

// We need Voyager's stats immediately. Let's filter on the fly!
let lostShip = fleetRoster.filter(function(ship) {
    return ship.name === "USS Voyager";
});

console.log(lostShip);
// We now have an array containing only the USS Voyager, instantly ready for our UI!

Description:

When using strict equality (===) to filter by text, we must remember that JavaScript is case-sensitive. Searching for "data" will not find a record labeled "Data". In later, more advanced modules, we will learn how to temporarily force all text into lowercase (using .toLowerCase()) to make our searches completely foolproof. For now, matching our exact capital letters ensures our database extracts the precise records we request!
