values()

The values() method completes the Iterator trio alongside keys() and entries(). Instead of returning the index numbers, it returns an Iterator containing only the actual values (the objects themselves) stored inside the array.

Crucial Note: Because arrays are designed to hold values, this method is actually the default behavior of an array! Writing for (let ship of fleet) does the exact same thing under the hood. We only type out values() when we want our code to be strictly, visually explicit. 

let fleet = [
    { name: "Enterprise", class: "Cruiser" },
    { name: "Defiant", class: "Escort" },
    { name: "Voyager", class: "Intrepid" }
];

// Generate a strict manifest iterator of the ship objects
let shipManifest = fleet.values();

// Loop through the iterator to see the actual ships
for (let ship of shipManifest) {
    console.log(ship.name);
}

// Output:
// "Enterprise"
// "Defiant"
// "Voyager"

Syntax 

array.values()

Return Value

Type: Array Iterator (A specialized data stream of the array's values/objects)

Description:

This command generates a strict manifest of the fleet's actual physical assets. It bypasses the registry slots (index numbers) entirely and generates an "Iterator" that outputs only the distinct objects parked in the array. While this is the default looping behavior for arrays in JavaScript, explicitly calling values() is a great way to make our code perfectly readable alongside keys() and entries() data streams.
