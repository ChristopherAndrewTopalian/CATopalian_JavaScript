findLast()

The findLast() method does the exact same job as find(), but it executes its sweep in reverse! It starts at the absolute end of the array and works its way backward toward the front.

This is incredibly useful for reviewing chronological data, like an array of log objects, when we need to quickly locate the most recent occurrence of a specific event and view its full details. 

// Example 1: ES5 Version

let commsLog = [
    {
        time: "0800",
        status: "Clear"
    },
    {
        time: "0900",
        status: "Static"
    },
    {
        time: "1000",
        status: "Clear"
    },
    {
        time: "1100",
        status: "Static"
    },
    {
        time: "1200",
        status: "Clear"
    }
];

// Find the most recent (last) log entry where the status is "Static"
let latestInterference = commsLog.findLast(function(log) {
    return log.status === "Static";
});

console.log(latestInterference); 
// Result: { time: "1100", status: "Static" } 
// (It ignores the older 0900 static event!)

// Example 2: ES6 Version

let commsLog = [
    {
        time: "0800",
        status: "Clear"
    },
    {
        time: "0900",
        status: "Static"
    },
    {
        time: "1000",
        status: "Clear"
    },
    {
        time: "1100",
        status: "Static"
    },
    {
        time: "1200",
        status: "Clear"
    }
];

// Find the most recent (last) log entry where the status is "Static"
let latestInterference = commsLog.findLast(log => log.status === "Static");

console.log(latestInterference); 
// Result: { time: "1100", status: "Static" }

Syntax (ES5 Version) 

array.findLast(function(element, index, array) { 
    /* return true or false */ 
})

Syntax (ES6 Version) 

array.findLast((element, index, array) => { /* return true or false */ })

Return Value

Type: Object (Returns the matching object itself, or undefined if not found)

Description:

This method operates exactly like find(), but it executes its sensor sweep in reverse! It starts at the absolute end of the array and works its way backward toward the front. It returns the very first object it encounters that passes our test. This is incredibly useful for reviewing chronological data, like a Captain's Log, when we need to locate the most recent occurrence of a specific event without having to scan the entire history from the beginning.
