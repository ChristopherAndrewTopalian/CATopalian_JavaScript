from()

Array.from() is a unique command. It is a "Static Method," meaning we don't use it on a fleet we already built. Instead, we use it to instantly build a brand-new array out of raw, unstructured data (like a string of text) or data that looks like an array but isn't one.

Its true superpower is its optional second parameter: a built-in mapping function. This allows us to take raw data and instantly forge it into an array of complex objects! 

// Example 1: ES5 Version

let transmission = "WARP";

// Take a raw text string and instantly build an array of data packets (objects)
let signalFleet = Array.from(transmission, function(char) {
    return { 
        letter: char, 
        encrypted: true 
    };
});

console.log(signalFleet); 
/* Result: [
    { letter: "W", encrypted: true },
    { letter: "A", encrypted: true },
    { letter: "R", encrypted: true },
    { letter: "P", encrypted: true }
] */

// Example 2: ES6 Version

let transmission = "WARP";

// Take a raw text string and instantly build an array of data packets (objects)
let signalFleet = Array.from(transmission, char => ({ letter: char, encrypted: true }));

console.log(signalFleet); 
/* Result: [
    { letter: "W", encrypted: true },
    { letter: "A", encrypted: true },
    { letter: "R", encrypted: true },
    { letter: "P", encrypted: true }
] */

Syntax (ES5 Version) 

Array.from(dataStream, function(element) { 
    /* return formatted object */ 
})

Syntax (ES6 Version) 

Array.from(dataStream, element => { /* return formatted object */ })

Return Value

Type: Array (A brand-new, officially commissioned array of objects)

Description:

Notice: This is a Static Method! We do not call this on an individual fleet; we call it directly on the Array master computer. This command takes raw, civilian data streams (like HTML NodeLists or simple text strings) and officially conscripts them. By utilizing its built-in mapping function, we can instantly wrap those raw text pieces into fully functional Starfleet data objects. It essentially builds a brand-new fleet of objects out of raw materials!
