with()

If we want to change a single ship in our array, we normally have to overwrite it directly (like fleet[1] = newShip).

The with() command allows us to replace an object at a specific index and returns a brand-new array, keeping our original data formation completely secure.

Crucial Note (The Shallow Copy): While the array itself is brand new, the unreplaced objects inside it are still pointing to the exact same memory references as our original array! 

let fleet = [
    { name: "Enterprise", class: "Cruiser" }, // Index 0
    { name: "Defiant", class: "Escort" },     // Index 1
    { name: "Voyager", class: "Intrepid" }    // Index 2
];

// Create a new array *with* Index 1 safely replaced by the "Farragut" object
let alternateFleet = fleet.with(1, { name: "Farragut", class: "Cruiser" });

console.log(alternateFleet); 
/* Result: [
    { name: "Enterprise", class: "Cruiser" },
    { name: "Farragut", class: "Cruiser" },
    { name: "Voyager", class: "Intrepid" }
] */

// The original array's formation remains perfectly safe!
console.log(fleet[1].name);
// Result: "Defiant" (The Defiant is still securely docked at Index 1!)

// PROVING THE SHALLOW COPY:
alternateFleet[2].class = "Warship";
console.log(fleet[2].class);
// Result: "Warship" (Changing the unreplaced Voyager in the new array changes the old one too!)

Syntax 

array.with(index, value)

Return Value

Type: Array (A brand-new array containing shallow copies, with the targeted element replaced)

Description:

This modern ES2023 maneuver is the safe alternative to direct bracket notation assignment (e.g., fleet[1] = newShipObject). Instead of overwriting the original ship at that coordinate and permanently altering our database, with() swaps the ship out and immediately returns the result as a brand-new array. This allows us to run tactical simulations and alternate fleet configurations without risking our primary data. Just remember the shallow copy rule: the objects that weren't replaced still share the same memory as the originals!
