shift()

Removing from the Beginning

shift() removes the very first object (Index 0) from the array, shifting all the remaining objects forward to fill the gap. 

let fleet = [
    {
        name: "Enterprise",
        class: "Cruiser"
    },
    {
        name: "Defiant",
        class: "Escort"
    },
    {
        name: "Voyager",
        class: "Intrepid"
    }
];

// The flagship is extracted from the front of the fleet
let departedShip = fleet.shift(); 

console.log(fleet); 
/* Result: [
    { name: "Defiant", class: "Escort" },
    { name: "Voyager", class: "Intrepid" }
] */

// shift() actually hands us the extracted object!
console.log(departedShip);
// Result: { name: "Enterprise", class: "Cruiser" }

Syntax 

array.shift()

Return Value

Type: Object (Returns the exact object that was removed, or undefined if the array was empty)

Description:

This method issues a direct extraction order to the vanguard. It removes the very first object (Index 0) from the array and actively returns that extracted object so we can use it. Warning: This is a destructive method! All remaining ships in the formation are permanently shifted down to a lower index number (the ship at Index 1 becomes the new Index 0). If we use shift() on an entirely empty array, it safely returns undefined.
