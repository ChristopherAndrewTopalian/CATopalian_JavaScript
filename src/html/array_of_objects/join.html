join()

When we display our array on a user interface, we often want it to look like a normal sentence rather than a coded list. join() takes all the items in our array and stitches them together into a single text string.

Crucial Note: If we use join() directly on an array of objects, JavaScript will just print [object Object]! To fix this, we must first use map() to extract the specific text we want (like the ship's name), and then chain join() onto the end of it! 

let fleet = [
    {
        name: "Enterprise",
        class: "Cruiser"
    },
    {
        name: "Defiant",
        class: "Escort"
    },
    {
        name: "Voyager",
        class: "Intrepid"
    }
];

// WARNING: Calling join directly on objects fails!
let badReport = fleet.join(", "); 
console.log(badReport); 
// Result: "[object Object], [object Object], [object Object]"

// THE FIX: Map the names into a standard array first, then join them!
let goodReport = fleet.map(ship => ship.name).join(", ");

console.log(goodReport); 
// Result: "Enterprise, Defiant, Voyager"

Syntax 

array.map(element => element.property).join(separator)

Return Value

Type: String (A single, combined text transmission)

Description:

This method is our primary communications array. Because we are dealing with complex objects, we must first isolate the exact string data we want to transmit (usually by chaining it with a map() command). Once the strings are isolated, join() links them all together into one massive String. By default, it separates the items with a comma, but we can pass it any "separator" we want (like a space " ", a dash "-", or even a completely empty string "") to format the transmission exactly how we need it.
