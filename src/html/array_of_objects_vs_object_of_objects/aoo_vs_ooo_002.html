Fleet-Wide Broadcasts (Mastering Iteration)

We know how to retrieve a single ship instantly. But what if Starfleet Command issues a fleet-wide software patch? We need to iterate (loop) through the entire database and update every single vessel.

Because Starfleet systems have evolved over decades, there are multiple communication protocols (loops) you can use. Whether you are patching a legacy Array or a modern Object of Objects, a senior engineer must know how to read and write them all. Let's look at the complete toolbox.

Part 1: Looping an Array of Objects

Arrays are strictly ordered, numbered lists. This makes them very easy to loop through from top to bottom. 

let arrayFleet = [
    { name: 'Enterprise', lcarsVersion: 6.0 },
    { name: 'Defiant', lcarsVersion: 6.0 }
];

// --- Array Method A: The Traditional Loop (Maximum Speed) ---
// This is the oldest and fastest loop in the engine. Excellent for high-speed game logic.
for (let i = 0; i < arrayFleet.length; i++) {
    arrayFleet[i].lcarsVersion = 7.1;
    console.log(arrayFleet[i].name + " updated via Traditional Loop");
}

// --- Array Method B: The Native 'forEach' (High Readability) ---
// A cleaner, functional approach built directly into modern Arrays.
arrayFleet.forEach(function(ship) {
    ship.lcarsVersion = 7.2;
    console.log(ship.name + " updated via forEach");
});

Part 2: Looping an Object of Objects

Pure Objects do not have a numbered sequence. To loop through our high-speed direct-lookup databases, we must either use a specialized Object loop, or extract the data into an Array first. 

let objectFleet = {
    enterprise: { lcarsVersion: 6.0 },
    defiant: { lcarsVersion: 6.0 }
};

// --- Object Method A: The Native 'for...in' Loop ---
// Automatically sweeps the object, but only gives you the Key. Requires bracket notation.
for (let key in objectFleet) {
    objectFleet[key].lcarsVersion = 7.1;
    console.log(key + " updated via for...in");
}

// --- Object Method B: The ES5 Bridge (Object.keys) ---
// Extracts a list of keys: ["enterprise", "defiant"], then loops through them.
let fleetKeys = Object.keys(objectFleet);
fleetKeys.forEach(function(key) {
    objectFleet[key].lcarsVersion = 7.2;
    console.log(key + " updated via Object.keys");
});

// --- Object Method C: The Modern ES6+ (Object.entries) ---
// Extracts both the Key and the Data simultaneously, instantly unpacking them.
Object.entries(objectFleet).forEach(([key, ship]) => {
    ship.lcarsVersion = 7.3;
    console.log(key + " updated via Object.entries");
});

Method 4: The Hybrid Speed Loop (Array + Object)

What if we want the extreme speed and explicit readability of a traditional for loop, but our data is trapped inside an Object? We execute a hybrid maneuver. We extract the Keys into an Array, and then run a traditional loop on that Array, using explicit bracket notation to target the database. 

let objectFleet = {
        enterprise: { lcarsVersion: 6.0 },
        defiant: { lcarsVersion: 6.0 }
    };

    // 1. Extract the Keys into a numbered Array: ["enterprise", "defiant"]
    let fleetKeys = Object.keys(objectFleet);

    // 2. Run a blazing-fast traditional loop on the new Array
    for (let i = 0; i < fleetKeys.length; i++) 
    {
        // fleetKeys[i] is the name of the ship. 
        // objectFleet[ fleetKeys[i] ] is the direct comm-link to the data!
        objectFleet[fleetKeys[i]].lcarsVersion = 7.4;
        
        console.log(fleetKeys[i] + " updated via Hybrid Loop");
    }

    /*
    enterprise updated via Hybrid Loop
    defiant updated via Hybrid Loop
    */

Engineering Summary

A true logic engineer chooses the right tool for the job. If you are building a physics engine that requires maximum processing speed, the Traditional for loop is unmatched. If you are manipulating complex, deeply nested LCARS data, the modern Object.entries() provides the cleanest architecture. Familiarize yourself with all protocols; you will encounter them all in the field.
