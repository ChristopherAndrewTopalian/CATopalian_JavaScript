Object of Objects: Adding Entries (The "Push" Equivalent)

When operating an Array, we use push() to add a new vessel to the very end of a sequential list. But a multidimensional Object has no "end" and no numbered sequence.

To add a newly commissioned starship to our active registry, we do not push. Instead, we declare a brand new Key directly on the database and assign it a complete structural manifest. If the Key does not exist, the JavaScript engine instantly creates it for us and stores the new nested Object at those coordinates. Let's add the Voyager to our database. 

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        status: 'active' 
    },

    defiant: 
    {
        class: 'escort',
        status: 'docked'
    }
};

// Adding a new entry using Dot Notation
starfleetDatabase.voyager = {
    class: 'intrepid',
    status: 'deployed'
};

// Adding a new entry using Bracket Notation
starfleetDatabase['discovery'] = {
    class: 'crossfield',
    status: 'classified'
};

console.log(starfleetDatabase);

/*
Object { enterprise: {…}, defiant: {…}, voyager: {…}, discovery: {…} }

defiant: Object { class: "escort", status: "docked" }
discovery: Object { class: "crossfield", status: "classified" }
enterprise: Object { class: "constitution", status: "active" }
voyager: Object { class: "intrepid", status: "deployed" }

: Object { … }
*/

Syntax 

parentObject.newKey = { childKey: "value" };

parentObject['newKey'] = { childKey: "value" };

Return Value

Type: The assigned Value (in this case, the newly created nested Object). The original parent Object is permanently mutated in the memory banks to include the new entry.

Description:

This direct assignment acts as the Object equivalent to an Array's push() method. We can use either Dot Notation (.voyager) or Bracket Notation (['discovery']) to name the new Key. Bracket notation is especially powerful for our engineering tools because it allows us to use variables to dynamically name the Keys as we construct new ships on the fly. By simply assigning a Value to a Key that does not currently exist, the JavaScript engine automatically expands the database architecture to accommodate the new nested data.
