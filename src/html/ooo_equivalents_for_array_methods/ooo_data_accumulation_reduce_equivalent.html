Object of Objects: Data Accumulation (The "Reduce" Equivalent)

When operating an Array, the reduce() method iterates through a list, taking every item and mathematically combining it into a single, final output value (like a grand total).

To run a fleet-wide calculation on a multidimensional Object, we extract the vessels using Object.values() and chain the .reduce() method. The command requires two things: an "Accumulator" to hold the running total, and a starting number (usually 0). As it loops, it adds each ship's specs to the Accumulator, eventually returning the final sum. 

// Example 1: ES5 Version (Calculating Fleet Crew Capacity)

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        crew: 430
    },
    defiant: 
    {
        class: 'escort',
        crew: 50
    },
    voyager: 
    {
        class: 'intrepid',
        crew: 150
    }
};

// We pass in an Accumulator (total) and the current item (vessel).
// The ", 0" at the very end tells the Accumulator to start at zero.
let totalFleetCrew = Object.values(starfleetDatabase).reduce(function(total, vessel) {
    return total + vessel.crew;
}, 0);

console.log("Total Fleet Crew Capacity: " + totalFleetCrew); 
// Result: 630

// Example 2: ES6 Version (Calculating Fleet Crew Capacity)

let starfleetDatabase = {
    enterprise: { class: 'constitution', crew: 430 },
    defiant: { class: 'escort', crew: 50 },
    voyager: { class: 'intrepid', crew: 150 }
};

// The ES6 Arrow Function compresses the logic into a single, elegant mathematical equation.
let totalFleetCrew = Object.values(starfleetDatabase).reduce((total, vessel) => total + vessel.crew, 0);

console.log("Total Fleet Crew Capacity: " + totalFleetCrew); 
// Result: 630

Syntax (ES5 Version) 

Object.values(parentObject).reduce(function(accumulator, item) { 
    return accumulator + item.property; 
}, initialValue);

Syntax (ES6 Version) 

Object.values(parentObject).reduce((accumulator, item) => accumulator + item.property, initialValue);

Return Value

Type: Varies (usually a Number, String, or Object). Returns the single accumulated value generated after the final iteration of the loop completes. The original Object remains completely unmutated.

Description:

reduce() is the most conceptually advanced iteration method, but also the most powerful. While it is heavily used for mathematical sums (like adding up hit-points, cargo weight, or crew sizes), its true power lies in data transformation. By changing the initial value from a 0 to an empty Array [] or an empty Object {}, advanced developers use reduce() to completely restructure database architecture on the fly. Remember: whatever you return on the current loop becomes the Accumulator for the next loop!
