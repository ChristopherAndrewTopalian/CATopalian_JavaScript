Object of Objects: Reordering Data (The "Sort" Equivalent)

When operating an Array, the sort() method physically reorders the items in the list based on a mathematical comparison.

Multidimensional Objects cannot be sorted natively. However, because modern JavaScript preserves the insertion order of Object Keys, we can extract our database into a 2D Array using Object.entries(), sort that Array, and use Object.fromEntries() to construct a brand new Object in perfect alphabetical or tactical order. 

// Example 1: ES5 Version (Sorting Alphabetically by Vessel Name)

let starfleetDatabase = {
    voyager: { class: 'intrepid' },
    defiant: { class: 'escort' },
    enterprise: { class: 'constitution' }
};

// In a 2D Array, 'a[0]' and 'b[0]' represent the string Keys (the Names).
// We use a classic alphabetical sorting algorithm.
let sortedAlphabetically = Object.fromEntries(
    Object.entries(starfleetDatabase).sort(function(a, b) {
        if (a[0] < b[0]) { return -1; }
        if (a[0] > b[0]) { return 1; }
        return 0;
    })
);

console.log("Alphabetical Registry:", sortedAlphabetically);
/*
Alphabetical Registry:
Object { defiant: {…}, enterprise: {…}, voyager: {…} }
*/

// Example 2: ES6 Version (Sorting Numerically by Nested Specs)

let tacticalDatabase = {
    enterprise: { maxWarp: 9.0 },
    voyager: { maxWarp: 9.975 },
    defiant: { maxWarp: 9.5 }
};

// 'a[1]' and 'b[1]' represent our nested Objects.
// We access the maxWarp property to sort from Highest to Lowest (b - a).
let sortedBySpeed = Object.fromEntries(
    Object.entries(tacticalDatabase).sort((a, b) => b[1].maxWarp - a[1].maxWarp)
);

console.log("Tactical Speed Hierarchy:", sortedBySpeed);
/*
Tactical Speed Hierarchy:
Object { voyager: {…}, defiant: {…}, enterprise: {…} }
*/

Syntax (ES5 Version) 

let sortedObject = Object.fromEntries(
    Object.entries(parentObject).sort(function(a, b) {
        // Return negative, positive, or zero
    })
);

Syntax (ES6 Version) 

let sortedObject = Object.fromEntries(
    Object.entries(parentObject).sort((a, b) => b[1].number - a[1].number)
);

Return Value

Type: Object. Returns a brand new multidimensional Object with its internal Keys permanently reorganized into the requested chronological order.

Description:

The sort() method operates by comparing two items (a and b) against each other sequentially. Because our conversion chain creates a 2D Array, a and b are actually pairs. We must explicitly tell the engine whether to compare the names at index [0], or dive into the physical data at index [1]. This level of control allows us to instantly reorganize massive databases by date commissioned, crew size, shield capacity, or standard alphabetical registry.
