Object of Objects: Executing Orders (The "forEach" Equivalent)

When operating an Array, the forEach() method iterates through the entire sequence and executes a specific function for every single item. It is purely designed for "side effects"—performing actions rather than retrieving data.

To send a fleet-wide command across a multidimensional Object, we chain Object.entries() with the standard .forEach() method. This instantly unpacks our database into a 2D Array of Pairs, and then walks through them one by one. This allows us to effortlessly transmit a message to every console or perform a mass-update to the internal data of every single vessel in the registry. 

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        shields: 'offline' 
    },

    defiant: 
    {
        class: 'escort',
        shields: 'offline'
    },

    voyager: 
    {
        class: 'intrepid',
        shields: 'offline'
    }
};

console.log("INITIATING FLEET-WIDE DIRECTIVE");

// We chain Object.entries() with .forEach() to execute a command on every ship.
// Notice we are updating the original Objects data directly from within the loop!
Object.entries(starfleetDatabase).forEach(([vesselName, specs]) => 
{
    console.log("Transmitting Red Alert protocol to: " + vesselName.toUpperCase());
    
    // Side Effect: We mutate the actual database, raising all shields
    specs.shields = 'maximum';
});

console.log("---------------------------------------");
console.log("Defiant Shield Status:", starfleetDatabase.defiant.shields);

/*
INITIATING FLEET-WIDE DIRECTIVE
Transmitting Red Alert protocol to: ENTERPRISE
Transmitting Red Alert protocol to: DEFIANT
Transmitting Red Alert protocol to: VOYAGER
---------------------------------------
Defiant Shield Status: maximum
*/

Syntax 

Object.entries(parentObject).forEach(([key, data]) => {
    // Execute commands here
});

Return Value

Type: undefined. This is the most critical distinction of the forEach() method. It never returns data. If you try to save it to a variable (e.g., let result = ...forEach()), the variable will be empty. It exists solely to execute external commands or mutate existing data.

Description:

The forEach() method is the workhorse of interface generation and mass data alteration. When you need to loop through an Object to dynamically generate HTML buttons on a screen, or when you need to simultaneously update a property across thousands of entries, this is the tool of choice. By destructuring the [vesselName, specs], we gain absolute, surgical access to both the visual name and the internal memory address of the ship on every iteration.
