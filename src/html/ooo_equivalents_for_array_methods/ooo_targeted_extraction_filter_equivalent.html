Object of Objects: Targeted Extraction (The "Filter" Equivalent)

When operating an Array, the filter() method allows us to sift through a massive list and extract a smaller subset of data that meets a specific condition.

To filter a multidimensional Object while preserving our named Keys, we must execute a three-step command chain. First, we use Object.entries() to convert our database into a 2D Array. Second, we use the standard .filter() method to isolate the vessels we want. Finally, we wrap the entire operation in Object.fromEntries(), which magically sews the filtered Array back together into a brand new, perfectly structured Object of Objects. 

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        status: 'active' 
    },

    defiant: 
    {
        class: 'escort',
        status: 'docked'
    },

    voyager: 
    {
        class: 'intrepid',
        status: 'active'
    },
    
    cerritos: 
    {
        class: 'california',
        status: 'docked'
    }
};

// We chain three powerful commands together to create a brand new 
// Object containing ONLY the vessels that are currently 'docked'
let dockedVessels = Object.fromEntries(
    Object.entries(starfleetDatabase).filter(([vesselName, specs]) => specs.status === 'docked')
);

console.log("Docked Vessels Sub-Registry:", dockedVessels);

/*
Docked Vessels Sub-Registry:
Object { defiant: {…}, cerritos: {…} }

defiant: Object { class: "escort", status: "docked" }
cerritos: Object { class: "california", status: "docked" }

: Object { … }
*/

Syntax 

let subObject = Object.fromEntries(
    Object.entries(parentObject).filter(([key, data]) => data.property === 'condition')
);

Return Value

Type: Object. Returns a brand new multidimensional Object containing only the Key-Value pairs that passed the True/False filter test. The original parent Object is completely unmutated.

Description:

Object.fromEntries() is the missing link that completes the multidimensional Object lifecycle. For years, developers struggled to filter Objects because Array methods destroy the Object architecture. By chaining these commands, we essentially dismantle the ship (entries), run the parts through a scanner (filter), and reassemble the surviving pieces back into a fully operational vessel (fromEntries). This exact pattern is the industry standard for querying and parsing massive JSON configurations and NoSQL databases.
