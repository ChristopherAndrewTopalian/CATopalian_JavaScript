Object of Objects: Extracting a Section (The "Slice" Equivalent)

When operating an Array, the slice(start, end) method copies a section of our data into a brand new Array. It begins at the start index and stops right before the end index, leaving the original list completely untouched.

To extract a consecutive chunk of vessels from a multidimensional Object, we chain three commands. First, we use Object.entries() to convert our database into a 2D Array with numerical positions. Second, we use standard .slice() to extract the section we want. Finally, we wrap the result in Object.fromEntries() to reconstruct a brand new, perfectly structured Object of Objects. 

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution'
    },
    defiant: 
    {
        class: 'escort'
    },
    voyager: 
    {
        class: 'intrepid'
    },
    cerritos: 
    {
        class: 'california'
    },
    titan: 
    {
        class: 'luna'
    }
};

// We want a sub-registry containing the 2nd, 3rd, and 4th vessels.
// We start at index 1 (defiant) and stop BEFORE index 4 (titan).
let patrolSquadron = Object.fromEntries(
    Object.entries(starfleetDatabase).slice(1, 4)
);

console.log("Patrol Squadron Extracted:", patrolSquadron);

/*
Patrol Squadron Extracted:
Object { defiant: {…}, voyager: {…}, cerritos: {…} }

defiant: Object { class: "escort" }
voyager: Object { class: "intrepid" }
cerritos: Object { class: "california" }

: Object { … }
*/

Syntax 

let subObject = Object.fromEntries(
    Object.entries(parentObject).slice(startIndex, endIndex)
);

Return Value

Type: Object. Returns a brand new multidimensional Object containing only the vessels that fell within our sliced boundary. The original parent Object is completely unmutated.

Description:

The slice() equivalent is incredibly useful for pagination in user interfaces (e.g., "Displaying results 10 through 20"). Because modern JavaScript guarantees that Object Keys remain in the exact chronological order they were inserted, we can confidently rely on Object.entries() to give us an accurate numerical timeline of our database. This allows us to safely extract historical "chunks" of our fleet registry without risking data corruption.
