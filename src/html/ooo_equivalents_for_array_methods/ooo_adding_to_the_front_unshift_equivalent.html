Object of Objects: Adding to the Front (The "Unshift" Equivalent)

When operating an Array, we use unshift() to insert a new vessel at the absolute front of the queue. However, a multidimensional Object is structured like a subspace grid, not a sequential line. If we add a new ship using standard Dot Notation, it is appended to the bottom of the registry (acting like a push()).

But what if our display screens require the newest vessel to appear at the very top of the list? To achieve an unshift() in an Object of Objects, we must completely rebuild the registry. We do this by declaring our new entry first, and then using the Spread Syntax (...) to unpack and append the rest of the existing fleet directly beneath it. 

let starfleetDatabase = {
    defiant: 
    {
        class: 'escort',
        status: 'docked'
    },

    voyager: 
    {
        class: 'intrepid',
        status: 'deployed'
    }
};

// We format the new vessel as its own Object
let newVessel = {
    enterprise: 
    {
        class: 'constitution',
        status: 'active' 
    }
};

// We rebuild the database with our new vessel at the top, 
// spreading the old database beneath it.
starfleetDatabase = { ...newVessel, ...starfleetDatabase };

console.log(starfleetDatabase);

/*
Object { enterprise: {…}, defiant: {…}, voyager: {…} }

enterprise: Object { class: "constitution", status: "active" }
defiant: Object { class: "escort", status: "docked" }
voyager: Object { class: "intrepid", status: "deployed" }

: Object { … }
*/

Syntax 

parentObject = { ...newEntry, ...parentObject };

Return Value

Type: Object. Returns a brand new multidimensional Object constructed from the merged elements. By reassigning it to our original variable name, we overwrite the old registry with the new, perfectly ordered one.

Description:

While we rely on Object of Objects for instant, surgical coordinate lookups, there are times when we must loop through our data to render an interface. Modern JavaScript guarantees that non-numeric Keys are iterated in the exact order they were inserted. By utilizing the Spread Syntax (...), we bypass the limitations of Dot Notation and effectively "unshift" our data, ensuring our priority vessel takes the vanguard position in any visual readout.
