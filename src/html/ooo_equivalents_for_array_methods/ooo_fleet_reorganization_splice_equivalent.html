Object of Objects: Fleet Reorganization (The "Splice" Equivalent)

When operating an Array, the splice() method is a destructive force. It allows us to target a specific index, delete a precise number of items, and instantly inject new items into that exact empty space.

To execute a mid-registry reorganization in a multidimensional Object, we must convert our database into a 2D Array using Object.entries(). Once in Array format, we can .splice() the data. If we are inserting new vessels, we must pass them in as ['registryName', {specs}] pairs. Finally, we use Object.fromEntries() to compile the array back into an Object, and overwrite our original database. 

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution'
    },
    pegasus: 
    {
        class: 'oberth'
    },
    voyager: 
    {
        class: 'intrepid'
    }
};

// 1. Convert the database to a 2D Array
let registryArray = Object.entries(starfleetDatabase);

// 2. Perform the Splice Operation
// Syntax: splice(startIndex, deleteCount, ...newItems)
// We start at index 1 (pegasus), delete 1 vessel, and insert two new ones!
registryArray.splice(1, 1, 
    ['titan', { class: 'luna' }], 
    ['farragut', { class: 'nebula' }]
);

// 3. Rebuild the Object and overwrite the old database
starfleetDatabase = Object.fromEntries(registryArray);

console.log("Reorganized Fleet Registry:", starfleetDatabase);

/*
Reorganized Fleet Registry:
Object { enterprise: {…}, titan: {…}, farragut: {…}, voyager: {…} }

enterprise: Object { class: "constitution" }
titan: Object { class: "luna" }
farragut: Object { class: "nebula" }
voyager: Object { class: "intrepid" }

: Object { … }
*/

Syntax 

let tempArray = Object.entries(parentObject);

// Remove items AND insert new [key, value] pairs
tempArray.splice(startIndex, deleteCount, ['newKey1', {data1}], ['newKey2', {data2}]);

parentObject = Object.fromEntries(tempArray);

Return Value

Type: Array (of deleted items). The splice() operation itself returns an Array containing whatever vessels were deleted. However, its primary purpose is "mutation", physically altering the original sequence. By wrapping it in our conversion chain, we successfully reorganize the insertion order of our primary database.

Description:

This is the most complex structural operation we can perform on a multidimensional Object. Because JavaScript modernizes Object architecture by remembering the exact chronological order Keys were inserted, splice() gives us the power to rewrite history. If a user interface requires a specific vessel to be rendered strictly between two other vessels, this three-step conversion chain is the only mathematically sound way to forcibly insert a new Key into the middle of an Object's timeline.
