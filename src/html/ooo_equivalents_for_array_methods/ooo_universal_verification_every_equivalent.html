Object of Objects: Universal Verification (The "Every" Equivalent)

When operating an Array, the every() method acts as a universal safety check. It runs a test on our data and returns true only if every single item in the sequence passes the strict condition.

To run this same fleet-wide diagnostic on a multidimensional Object, we utilize Object.values(). This command strips away the string Keys (the ship names) and generates a pure Array containing only the nested data Objects. Once we have that temporary Array, we chain the standard .every() method directly to it, allowing us to instantly verify if our entire fleet meets a specific operational requirement. 

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        warpCore: 'stable' 
    },

    defiant: 
    {
        class: 'escort',
        warpCore: 'stable'
    },

    voyager: 
    {
        class: 'intrepid',
        warpCore: 'stable'
    }
};

// 1. We extract an Array of just the vessel specs using Object.values()
// 2. We chain .every() to check if ALL vessels have a stable warp core
let fleetReady = Object.values(starfleetDatabase).every(vessel => vessel.warpCore === 'stable');

console.log("Is the entire fleet warp-capable? " + fleetReady);

// Now, the Defiant takes battle damage
starfleetDatabase.defiant.warpCore = 'critical';

// We run the exact same diagnostic test again
let fleetReadyNow = Object.values(starfleetDatabase).every(vessel => vessel.warpCore === 'stable');

console.log("Is the fleet warp-capable after battle? " + fleetReadyNow);

/*
Is the entire fleet warp-capable? true
Is the fleet warp-capable after battle? false
*/

Syntax 

let result = Object.values(parentObject).every(item => item.property === 'condition');

Return Value

Type: Boolean. Returns true if the callback function returns a truthy value for every single Key-Value pair in the Object. Otherwise, it returns false. The original parent Object is completely unmutated.

Description:

Object.values() is the third and final core diagnostic tool, sitting right alongside keys() and entries(). It is specifically designed for moments when we care about the data, but do not care about the name. The beauty of the every() method is its hardware efficiency: it utilizes "short-circuit" logic. The absolute nanosecond it finds a vessel with a failing warp core, it aborts the loop, immediately returns false, and saves the CPU from having to check the rest of the database.
