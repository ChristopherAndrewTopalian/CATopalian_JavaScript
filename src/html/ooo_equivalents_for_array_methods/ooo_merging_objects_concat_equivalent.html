Object of Objects: Merging Databases (The "Concat" Equivalent)

When operating an Array, we use concat() to stitch multiple separate lists together into one massive sequence.

To fuse multiple multidimensional Objects together, we use the modern Spread Syntax (...). By unpacking separate quadrant registries inside a new set of curly braces, JavaScript instantly merges all the Keys into a single, unified master database. However, we must be warned: if two databases share the exact same vessel name, the database merged last will overwrite the earlier data! 

let alphaQuadrantFleet = {
    enterprise: 
    {
        class: 'constitution',
        status: 'active' 
    },
    defiant: 
    {
        class: 'escort',
        status: 'docked'
    }
};

let deltaQuadrantFleet = {
    voyager: 
    {
        class: 'intrepid',
        status: 'deployed'
    },
    equinox: 
    {
        class: 'nova',
        status: 'destroyed'
    }
};

// We use the Spread Syntax to unpack both fleets into a unified Object
let masterRegistry = { ...alphaQuadrantFleet, ...deltaQuadrantFleet };

console.log("Unified Master Registry:", masterRegistry);

/*
Unified Master Registry:
Object { enterprise: {…}, defiant: {…}, voyager: {…}, equinox: {…} }

enterprise: Object { class: "constitution", status: "active" }
defiant: Object { class: "escort", status: "docked" }
voyager: Object { class: "intrepid", status: "deployed" }
equinox: Object { class: "nova", status: "destroyed" }

: Object { … }
*/

Syntax 

let combinedObject = { ...sourceObject1, ...sourceObject2 };

// Alternative Legacy Method:
let combinedObject = Object.assign({}, sourceObject1, sourceObject2);

Return Value

Type: Object. Returns a completely new multidimensional Object containing all the Key-Value pairs from every merged source. The original source Objects remain completely untouched and unmutated.

Description:

The Spread Syntax (...) has become the golden standard for combining data structures. Instead of writing loops to copy vessels over one by one, the Spread operator instantly unpacks the architecture of multiple Objects and fuses them together. This is the equivalent of an Array concat(), with one vital rule of absolute authority: if sourceObject2 possesses a Key with the exact same string name as sourceObject1, the data from sourceObject2 will permanently overwrite the original data in the final merged output.
