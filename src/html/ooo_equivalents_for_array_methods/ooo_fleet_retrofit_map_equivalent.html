Object of Objects: Fleet Retrofit (The "Map" Equivalent)

When operating an Array, the map() method sweeps through the list, modifies every single item, and constructs a brand-new array out of the upgraded results without touching the original data.

To execute a 1-to-1 data transformation on a multidimensional Object, we chain three commands. First, Object.entries() breaks our database into [StringKey, NestedObject] pairs. Next, we use .map() to alter the data inside those pairs. Finally, Object.fromEntries() sews the pairs back together into a brand-new Object of Objects, leaving our original historical database completely unharmed. 

// Example 1: The ES5 Legacy Syntax

let starfleetDatabase = {
    enterprise: { class: 'constitution', shields: 100 },
    defiant: { class: 'escort', shields: 100 }
};

// We use standard functions and Object.assign to safely copy and upgrade the data
let retrofittedFleet = Object.fromEntries(
    Object.entries(starfleetDatabase).map(function(shipPair) {
        let shipName = shipPair[0];
        let specs = shipPair[1];
        
        // We create a fresh copy of the specs so we don't mutate the original!
        let upgradedSpecs = Object.assign({}, specs);
        upgradedSpecs.shields = 200; // Double the shield capacity!
        
        // We return the pair in its original [Key, Value] format
        return [shipName, upgradedSpecs];
    })
);

console.log("Original Enterprise Shields:", starfleetDatabase.enterprise.shields);
// Result: 100

console.log("Retrofitted Enterprise Shields:", retrofittedFleet.enterprise.shields);
// Result: 200

// Example 2: The Modern ES6 Standard

let starfleetDatabase = {
    enterprise: { class: 'constitution', shields: 100 },
    defiant: { class: 'escort', shields: 100 }
};

// We use Array Destructuring [shipName, specs] and the Spread Syntax (...)
// to condense the entire operation into a single, elegant command.
let retrofittedFleet = Object.fromEntries(
    Object.entries(starfleetDatabase).map(([shipName, specs]) => [
        shipName, 
        { ...specs, shields: 200 }
    ])
);

console.log("Retrofitted Defiant Shields:", retrofittedFleet.defiant.shields);
// Result: 200

Syntax (Legacy ES5 Syntax) 

let newObject = Object.fromEntries(
    Object.entries(parentObject).map(function(pair) {
        let key = pair[0];
        let data = pair[1];
        // modify data safely here
        return [key, data];
    })
);

Syntax (Modern ES6) 

let newObject = Object.fromEntries(
    Object.entries(parentObject).map(([key, data]) => [key, { ...data, newProp: 'value' }])
);

Return Value

Type: Object. Returns a brand-new, structurally identical multidimensional Object, but with all of the nested data transformed by your function.

Description:

map() is the ultimate tool for safe, non-destructive data mutation. Because it returns a completely new Object, it is the golden standard in modern frameworks (like React or Vue) where directly altering an original database is strictly forbidden. The ES6 version beautifully showcases the power of the Spread Syntax (...specs), which instantly unpacks all the old ship data into the new Object before applying our shield upgrades over the top.
