Object of Objects: Positional Lookup (The "At" Equivalent)

When operating an Array, the modern at() method allows us to grab an item based on its exact numerical position. It is especially famous for allowing negative numbers, like at(-1), to instantly retrieve the very last item in the sequence.

A multidimensional Object operates on named Keys, not index numbers. But if we need to retrieve the "most recently commissioned" vessel (the last one added to the registry), we can ask Object.keys() for an Array of our names, use at() on that Array, and then use Bracket Notation to access our data. 

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        status: 'active' 
    },

    defiant: 
    {
        class: 'escort',
        status: 'docked'
    },

    cerritos: 
    {
        class: 'california',
        status: 'drydock'
    }
};

// We ask JavaScript for an Array of our vessel names, 
// and we use .at(-1) to grab the very last name in the list.
let newestShipName = Object.keys(starfleetDatabase).at(-1);

// We use Bracket Notation to retrieve the exact ship data
let newestShipData = starfleetDatabase[newestShipName];

console.log("Most Recently Added:", newestShipName);
console.log("Vessel Specs:", newestShipData);

/*
Most Recently Added: cerritos

Vessel Specs: 
Object { class: "california", status: "drydock" }
*/

Syntax 

let targetKey = Object.keys(parentObject).at(indexNumber);
let targetData = parentObject[targetKey];

Return Value

Type: Varies (Object, String, Number, etc). This operation returns the exact nested data stored at the targeted Key. Unlike pop or shift, this is strictly a "read-only" lookup. The original parent Object is completely untouched and unmutated.

Description:

This technique is the ultimate bridge between Array logic and Object logic. By generating a temporary Array of our Keys, we gain access to all of the mathematical positioning tools that Arrays possess (like the at() method). Once we identify the correct string name, we seamlessly pass it back into our Object using dynamic Bracket Notation. This allows us to perfectly simulate relative positional lookups (like finding the 1st, 3rd, or last entry) inside an unordered structural database.
