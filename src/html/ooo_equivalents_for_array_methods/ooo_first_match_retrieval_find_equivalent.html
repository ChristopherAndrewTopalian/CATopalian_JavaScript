Object of Objects: First Match Retrieval (The "Find" Equivalent)

When operating an Array, the find() method executes a high-speed search. It scans the sequence and returns the very first item that passes the test, immediately halting the loop to save processing power.

To perform a targeted search on a multidimensional Object, we chain Object.entries() with the standard .find() method. Because entries() converts our database into a 2D Array of Pairs, a successful search will hand us a single Array containing [vesselName, vesselSpecs]. If the search turns up empty, it returns undefined. 

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        status: 'active' 
    },

    pegasus: 
    {
        class: 'oberth',
        status: 'missing'
    },

    equinox: 
    {
        class: 'nova',
        status: 'missing'
    }
};

// We use .find() to locate the FIRST vessel flagged as 'missing'
let searchResult = Object.entries(starfleetDatabase).find(([vesselName, specs]) => specs.status === 'missing');

// Check if the search actually found something before trying to read it!
if (searchResult !== undefined) 
{
    // Destructure the returned pair into two separate variables
    let [foundName, foundSpecs] = searchResult;
    
    console.log("Search and Rescue Target Acquired:");
    console.log("Registry : " + foundName.toUpperCase());
    console.log("Class    : " + foundSpecs.class);
} 
else 
{
    console.log("All vessels accounted for.");
}

/*
Search and Rescue Target Acquired:
Registry : PEGASUS
Class    : oberth
*/

Syntax 

let result = Object.entries(parentObject).find(([key, data]) => data.property === 'condition');

Return Value

Type: Array (if found) or Undefined (if not found). Unlike filter() which returns a new Object, find() returns a single 2-item Array containing the matched [StringKey, NestedObject]. Notice how the scanner found the Pegasus and immediately stopped, never even checking the Equinox.

Description:

The find() operation is designed for speed and efficiency. When managing massive databases containing tens of thousands of records, we do not want to use filter() if we are only looking for a single specific entry (like an ID number or a unique sensor anomaly). By pairing it with Object.entries(), we force JavaScript to iterate through our Object chronologically, guaranteeing that it grabs the oldest matching vessel in the registry and instantly releases the CPU to perform other tasks.
