Object of Objects: Locating Positions (The "indexOf" Equivalent)

When operating an Array, the indexOf() method searches for a specific item and returns its exact numerical position in the line (like 0, 1, or 2). If the item doesn't exist, it returns -1.

Multidimensional Objects use named Keys instead of numbers. But if we need to know a vessel's numerical placement in the rendering queue, we can extract an Array using Object.keys() or Object.values(), and then run our positional scanners. 

// Example 1: Finding Position by Name (indexOf)
// No callback function needed, works identically in ES5 and ES6

let starfleetDatabase = {
    enterprise: { class: 'constitution' },
    defiant: { class: 'escort' },
    voyager: { class: 'intrepid' }
};

// We convert the names to an Array, then find the Defiants number
let defiantPosition = Object.keys(starfleetDatabase).indexOf('defiant');
let pegasusPosition = Object.keys(starfleetDatabase).indexOf('pegasus');

console.log("Defiant is at index: " + defiantPosition); 
// Result: 1 (The second ship)

console.log("Pegasus is at index: " + pegasusPosition); 
// Result: -1 (Ship not found in registry)

// Example 2: Finding Position by Specs (findIndex) - ES5 Version

// We need the numerical position of the first 'intrepid' class ship, 
// but we do not know its name!

let intrepidPosition = Object.values(starfleetDatabase).findIndex(function(vessel) {
    return vessel.class === 'intrepid';
});

console.log("Intrepid class found at index: " + intrepidPosition);
// Result: 2

// Example 3: Finding Position by Specs (findIndex) - ES6 Version

let intrepidPositionES6 = Object.values(starfleetDatabase).findIndex(vessel => vessel.class === 'intrepid');

console.log("Intrepid class found at index: " + intrepidPositionES6);
// Result: 2

Syntax 

// When searching by Key Name:
Object.keys(parentObject).indexOf('targetKey');

// When searching by nested data:
Object.values(parentObject).findIndex(item => item.property === 'condition');

Return Value

Type: Number (Integer). Returns the numerical index (starting at 0) of the first matching item. If the scanner searches the entire database and finds absolutely nothing, it will always return -1.

Description:

In a multidimensional Object, retrieving a numerical index is primarily useful for user interface generation (e.g., displaying "Ship 3 of 50" on a viewscreen). indexOf() is highly efficient but only works with flat strings, making it perfect for searching our Object.keys() array. When we need to search deep inside our nested vessel data, we upgrade to findIndex() and pass it a testing function, allowing us to find a numerical position based on a ship's class, status, or shield strength.
