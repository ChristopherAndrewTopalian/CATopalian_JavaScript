Object of Objects: Iterating Pairs (The "Entries" Equivalent)

When operating an Array, the entries() method returns a list of arrays containing the [index, item]. This allows us to loop through the data while knowing exactly what position we are in.

A multidimensional Object is notoriously difficult to loop through using standard methods. However, by using the global Object.entries() command, JavaScript instantly scans our database and constructs a 2D Array where each item is a pair containing [stringKey, nestedObject]. By combining this with a for...of loop and modern Array Destructuring, we can simultaneously extract the vessel's name and its specs on every single loop iteration. 

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        status: 'active' 
    },

    defiant: 
    {
        class: 'escort',
        status: 'docked'
    },

    voyager: 
    {
        class: 'intrepid',
        status: 'deployed'
    }
};

// We use a for...of loop combined with [key, value] destructuring.
// Object.entries() feeds us the vesselName and the nested specs simultaneously!
for (let [vesselName, specs] of Object.entries(starfleetDatabase)) 
{
    console.log("Vessel Registry : " + vesselName.toUpperCase());
    console.log("Hull Class      : " + specs.class);
    console.log("Current Status  : " + specs.status);
    console.log("----------------------------");
}

/*
Vessel Registry : ENTERPRISE
Hull Class      : constitution
Current Status  : active
----------------------------
Vessel Registry : DEFIANT
Hull Class      : escort
Current Status  : docked
----------------------------
Vessel Registry : VOYAGER
Hull Class      : intrepid
Current Status  : deployed
----------------------------
*/

Syntax 

Object.entries(parentObject);

// Standard Iteration Syntax:
for (let [keyName, nestedData] of Object.entries(parentObject)) { ... }

Return Value

Type: Array (2D). Returns a nested Array containing every Key-Value pair from the parent Object. Example format: [["enterprise", {class: "constitution"}], ["defiant", {class: "escort"}]]. The original Object is unmutated.

Description:

Object.entries() is the master key to rendering user interfaces from a multidimensional Object. Because DOM elements (like Buttons or Divs) usually need to be generated via a loop, this command safely unpacks the entire grid into an iterable Array format. The true magic lies in the syntax let [vesselName, specs] inside the loop declaration. This is called Destructuring. Instead of forcing us to look up data using array[0] and array[1], JavaScript instantly assigns the string name to the first variable, and the physical data to the second variable, making our loop logic beautifully clean and readable.
