Object of Objects: Removing from the Front (The "Shift" Equivalent)

When operating an Array, we use shift() to remove the very first item in the sequence. Because a multidimensional Object uses named Keys instead of numbered indexes, we cannot simply tell JavaScript to "delete index 0."

However, modern JavaScript engines remember the exact insertion order of our Keys. If we need to blindly decommission the oldest vessel in our registry, the one sitting at the absolute front of the list, we can use Object.keys() to find its name, and then use dynamic Bracket Notation to wipe it from the memory banks. 

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        status: 'active' 
    },

    defiant: 
    {
        class: 'escort',
        status: 'docked'
    },

    voyager: 
    {
        class: 'intrepid',
        status: 'deployed'
    }
};

// We ask JavaScript for an Array of all our vessel names, 
// and we grab the very first one [0]
let firstShipName = Object.keys(starfleetDatabase)[0];

// (Optional) We can save the vessels data before it is gone
let decommissionedData = starfleetDatabase[firstShipName];

// We use dynamic Bracket Notation to delete the first vessel
delete starfleetDatabase[firstShipName];

console.log("Decommissioned:", firstShipName);
console.log("Remaining Database:", starfleetDatabase);

/*
Decommissioned: enterprise

Remaining Database:
Object { defiant: {…}, voyager: {…} }

defiant: Object { class: "escort", status: "docked" }
voyager: Object { class: "intrepid", status: "deployed" }

: Object { … }
*/

Syntax 

let firstKey = Object.keys(parentObject)[0];
delete parentObject[firstKey];

Return Value

Type: Boolean (from the delete operator). The delete action itself returns true upon success, completely mutating the original parent Object by erasing the first entry. If we need to return the actual data (just like a standard Array shift() does), we simply store a copy of the data in a temporary variable before executing the deletion.

Description:

Object.keys() is one of our most powerful diagnostic tools. It instantly scans a multidimensional Object and returns a standard Array containing all the Keys as Strings, preserving their insertion order. By targeting index [0] of that generated Array, we discover the exact string name of the first Key. We then pass that dynamically discovered string into our Bracket Notation delete operation, effectively "shifting" the first entry out of existence without ever needing to hardcode its name.
