Object of Objects: Verifying Existence (The "Includes" Equivalent)

When operating an Array, the includes() method scans a list for a simple string or number and returns a true or false boolean.

Because a multidimensional Object contains nested data, we cannot just ask if a simple string is "included" inside it. Instead, we use Object.values() to extract the vessel data, and chain it with the .some() method. This allows us to run a high-speed boolean check across the entire registry to verify if at least one vessel meets our criteria. 

// Example 1: ES5 Version

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        status: 'active' 
    },
    defiant: 
    {
        class: 'escort',
        status: 'docked'
    }
};

// We check if our fleet includes at least one 'escort' class vessel
let hasEscort = Object.values(starfleetDatabase).some(function(vessel) {
    return vessel.class === 'escort';
});

console.log("Does the fleet include an escort vessel? " + hasEscort);
// Result: Does the fleet include an escort vessel? true

// Example 2: ES6 Version

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        status: 'active' 
    },
    defiant: 
    {
        class: 'escort',
        status: 'docked'
    }
};

// We check if our fleet includes at least one 'escort' class vessel
let hasEscort = Object.values(starfleetDatabase).some(vessel => vessel.class === 'escort');

console.log("Does the fleet include an escort vessel? " + hasEscort);
// Result: Does the fleet include an escort vessel? true

Syntax (ES5 Version) 

Object.values(parentObject).some(function(item) { 
    return item.property === 'condition'; 
});

Syntax (ES6 Version) 

Object.values(parentObject).some(item => item.property === 'condition');

Return Value

Type: Boolean. Returns true if the callback function finds even a single match, and false if it scans the entire database without finding a match.

Description:

The .some() method is the direct counterpart to .every(), and serves as the structural equivalent of an Array's includes() method. It is highly optimized for performance using "short-circuit" logic. The absolute moment it evaluates a vessel that returns true, it immediately halts the loop, drops the remaining queue, and reports the verification back to command. Note: If you only need to know if a specific vessel's Name (Key) exists, you can bypass loops entirely and use the O(1) syntax: 'defiant' in starfleetDatabase.
