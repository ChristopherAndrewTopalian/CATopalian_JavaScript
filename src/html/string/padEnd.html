padEnd()

The padEnd() method is a structural formatting tool. It forces a string to reach a specific, exact length by repeatedly adding a filler character (like a space, a dot, or a dash) to the end of the text. It is absolutely essential for building clean tables, receipts, and perfectly aligned data columns. 

let ship1 = "Enterprise";
let ship2 = "Defiant";

// We want every ship name to take up exactly 15 characters of space.
// We will fill the empty space at the end with dots to make it easy to read!
let formattedShip1 = ship1.padEnd(15, ".");
let formattedShip2 = ship2.padEnd(15, ".");

console.log(formattedShip1 + "Sector 4"); 
// Result: "Enterprise.....Sector 4"

console.log(formattedShip2 + "Sector 4");
// Result: "Defiant........Sector 4"

// If the string is ALREADY longer than the target length, it does nothing:
let longShip = "Interstellar Transport";
console.log(longShip.padEnd(15, "."));
// Result: "Interstellar Transport" (It doesn't chop the text!)

Syntax 

string.padEnd(targetLength, padString)

Return Value

Type: String (A brand new string of the specified target length, with the pad string applied to the end.)

Description:

The padEnd() method is non-destructive and creates a new string. The first parameter is the targetLength (the total number of characters we want the final string to be). The second parameter is the padString (the character we want to use as filler). If we do not provide a padString, JavaScript will automatically use an empty, invisible space as the default filler. It is incredibly smart: if our filler string is too long to fit into the remaining space, the computer will automatically chop the filler string so everything fits perfectly. Also, it will never delete our original text; if our starting word is already longer than our target length, it simply returns the original word untouched.
