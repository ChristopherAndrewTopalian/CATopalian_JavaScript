lastIndexOf()

The lastIndexOf() method is a reverse targeting scanner. Instead of reading left-to-right, it scans the string from right-to-left to find the last occurrence of a specific word or character. However, it still returns the standard left-to-right index coordinate! 

let log = "Entering Sector 4. Patrolling Sector 4. Leaving Sector 4.";

// Lock onto the exact starting coordinate of the VERY LAST "Sector"
let mostRecentLog = log.lastIndexOf("Sector");
console.log(mostRecentLog); 
// Result: 48 (The "S" in the final "Sector" is at Index 48)

// Search for a threat that isn't there
let missingThreat = log.lastIndexOf("Borg");
console.log(missingThreat);
// Result: -1 (Target not found!)

// Advanced: Start scanning backwards from a specific coordinate!
// We tell the reverse-scanner to start at Index 30 and go backwards.
let middleLog = log.lastIndexOf("Sector", 30);
console.log(middleLog);
// Result: 30 (It found the middle "Sector" and ignored the last one!)

Syntax 

string.lastIndexOf(searchString, position)

Return Value

Type: Number (The index of the first character of the last found text. Returns -1 if the text is not found anywhere.)

Description:

This method operates exactly like indexOf(), but in reverse. It is incredibly useful for parsing long data files where we only care about the most recent entry. The biggest trap for beginners is the optional position parameter. In indexOf(), the position tells the computer to skip the front and scan forward. In lastIndexOf(), the position tells the computer to skip the end and scan backward toward the front of the string (Index 0). Remember, even though it scans backward, the index number it returns is still the standard coordinate counted from the left!
