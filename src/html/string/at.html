at()

The at() method allows us to read a single character from a string at a specific index number. Its true superpower is that it accepts negative numbers, allowing us to easily count backward from the end of the string without needing to calculate the string's total length. 

let registry = "NCC-1701-D";

// Standard index: Get the very first character (Index 0)
let firstChar = registry.at(0);
console.log(firstChar); 
// Result: "N"

// Negative index: Get the very last character (Index -1)
let lastChar = registry.at(-1);
console.log(lastChar); 
// Result: "D"

Syntax 

string.at(index)

Return Value

Type: String (A single character located at the specified position)

Description:

While we can normally use bracket notation (like registry[0]) to grab a character, bracket notation does not support negative numbers. Before at() was introduced in modern JavaScript, getting the last character required clunky math (like registry[registry.length - 1]). The at() command streamlines this, allowing developers to cleanly target characters from the front using positive integers, or from the rear using negative integers.
