matchAll()

The matchAll() method is a deep sensor sweep. While standard match() just gives us a simple list of what it found, matchAll() returns a highly detailed package for every single match, including its exact index coordinates and any specific sub-components (called "capturing groups") we asked for. 

let fleetData = "Ship: USS Enterprise (NCC-1701), Ship: USS Voyager (NCC-74656)";

// We want to find the whole designation, but also capture just the ship name
// and just the registry number separately. (The parentheses are "capturing groups").
// Note: matchAll() REQUIRES the "g" (global) flag at the end of the RegEx!
let regexPattern = /USS (\w+) \(NCC-(\d+)\)/g;

let deepScanResults = fleetData.matchAll(regexPattern);

// matchAll returns an Iterator, so we use Array.from() to turn it into a readable array
let resultsArray = Array.from(deepScanResults);

// Let us look at the highly detailed dossier for the first ship found:
console.log(resultsArray[0]); 
// Result: ["USS Enterprise (NCC-1701)", "Enterprise", "1701", index: 6, input: "Ship: USS..."]

// Now we can easily isolate the exact sub-components!
console.log("First Ship Name:", resultsArray[0][1]); // "Enterprise"
console.log("First Registry:", resultsArray[0][2]);  // "1701"

Syntax 

string.matchAll(regexp)

Return Value

Type: Iterator (Returns an iterator object that contains arrays for every single match, including all captured groups.)

Description:

This is a powerful, modern method for advanced data extraction. The most critical rule for matchAll() is that the Regular Expression we pass into it must have the global flag (/g). If we forget the "g", JavaScript will throw a fatal TypeError and crash the app! Unlike standard methods that return a simple Array, matchAll() returns an Iterator. An Iterator is a special type of object that must be looped over (using a for...of loop) or converted into an Array (using Array.from() or the spread operator) before we can read the data inside it.
