toLowerCase()

The toLowerCase() method is an input sanitizer. It reads a string and converts every single uppercase letter into a lowercase letter. It is completely non-destructive and is the absolute standard way to format user input (like email addresses or usernames) so the computer can compare data accurately without getting confused by random capitalizations. 

let databaseUsername = "riker_01";

// The user accidentally left their Caps Lock key on!
let userInput = "RiKeR_01";

// If the security system compares them directly, access is denied:
console.log(databaseUsername === userInput); 
// Result: false (JavaScript is strictly case-sensitive!)

// The Professional Solution: Sanitize the input first!
let sanitizedInput = userInput.toLowerCase();

console.log(sanitizedInput === databaseUsername);
// Result: true (Access granted!)

// Notice that numbers and symbols are completely unaffected:
let mixedData = "NCC-1701-D!".toLowerCase();
console.log(mixedData);
// Result: "ncc-1701-d!"

Syntax 

string.toLowerCase()

Return Value

Type: String (A brand-new string where all the alphabetic characters have been converted to lowercase.)

Description:

Because JavaScript uses raw numeric values to compare text, a capital "R" (82) is mathematically entirely different from a lowercase "r" (114). If we are building a search bar or a login screen, we must run the user's typed text through toLowerCase() before we try to match it against our database. This method only affects letters; it completely ignores spaces, numbers, and punctuation marks. Remember that this is the standard English-based converter. If our app is worldwide and deals with unique foreign alphabets (like Turkish), we should upgrade to toLocaleLowerCase() to prevent accidental misspellings!
