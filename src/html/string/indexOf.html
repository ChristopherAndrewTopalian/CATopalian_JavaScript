indexOf()

The indexOf() method is a targeting scanner. It searches a string from left to right to find a specific word or character. Instead of just telling us if it exists, it returns the exact index number where the very first letter of that word begins. 

let log = "Distress call: Sector 4. Repeat: Sector 4.";

// Lock onto the exact starting coordinate of the word "Sector"
let firstTarget = log.indexOf("Sector");
console.log(firstTarget); 
// Result: 15 (The "S" in the first "Sector" is at Index 15)

// Search for a threat that isn't there
let missingThreat = log.indexOf("Borg");
console.log(missingThreat);
// Result: -1 (Target not found!)

// Advanced: Start scanning AFTER the first target to find the second one!
// We tell the scanner to start looking at Index 20.
let secondTarget = log.indexOf("Sector", 20);
console.log(secondTarget);
// Result: 33

Syntax 

string.indexOf(searchString, position)

Return Value

Type: Number (The index of the first character of the found text. Returns -1 if the text is not found anywhere.)

Description:

This is one of the oldest and most frequently used commands in JavaScript. Because JavaScript counts starting from 0, it cannot return 0 when a word is missing (because 0 is a valid coordinate at the very front of the string!). Therefore, the creators decided that indexOf() will always return -1 to indicate a failure to find the target. It also accepts an optional second number, position, which tells the computer to completely ignore the beginning of the string and only start searching from that specific index onward.
