String.fromCharCode()

The String.fromCharCode() method is a decryption tool. It does the exact opposite of charCodeAt(). We feed it a sequence of raw UTF-16 numbers, and it translates them back into a human-readable text string. 

// We intercepted a raw numerical transmission from the previous lesson:
// 66, 111, 114, 103

let decryptedMessage = String.fromCharCode(66, 111, 114, 103);

console.log(decryptedMessage); 
// Result: "Borg"

// We can also pass it a single number to get a single character:
let alertLevel = String.fromCharCode(82);
console.log(alertLevel);
// Result: "R" (Red Alert!)

Syntax 

String.fromCharCode(num1, num2, /* ..., */ numN)

Return Value

Type: String (A new string created from the specified sequence of UTF-16 code units.)

Description:

Notice the capital S in String. Unlike previous methods where we called the command on a variable we created (like registry.charAt(0)), this is a static method. It must be called directly on the built-in JavaScript String object itself. We simply pass it a comma-separated list of numbers, and it physically constructs a brand new string for us. Just like its counterpart, because it relies on older 16-bit encoding, it cannot accurately translate massive numbers used for modern emojis or complex symbols.
