charCodeAt()

The charCodeAt() method lets us peek under the hood of JavaScript. Instead of returning the actual letter at a specific index, it returns the hidden numeric code (the UTF-16 integer) that the computer uses to represent that exact character. 

let transmission = "Borg";

// Get the raw numeric code for the capital "B" (Index 0)
let bCode = transmission.charCodeAt(0);
console.log(bCode); 
// Result: 66

// Lowercase letters have completely different codes! 
// Let us check the lowercase "o" (Index 1)
let oCode = transmission.charCodeAt(1);
console.log(oCode); 
// Result: 111

// If the index doesn't exist:
let emptySpace = transmission.charCodeAt(100);
console.log(emptySpace);
// Result: NaN (Not-a-Number)

Syntax 

string.charCodeAt(index)

Return Value

Type: Number (An integer between 0 and 65535 representing the UTF-16 code unit. Returns NaN if the index is out of bounds.)

Description:

Computers cannot process letters; they only understand numbers. Every single character we type on a keyboard is assigned a strict numeric value based on the UTF-16 encoding standard (which evolved from the classic ASCII table). The charCodeAt() method translates the human-readable text back into the computer's native numerical format. This is incredibly useful for building cryptography programs, writing data encryption algorithms, or creating custom sorting logic. Keep in mind that uppercase and lowercase letters are treated as entirely different entities with entirely different numeric codes!
