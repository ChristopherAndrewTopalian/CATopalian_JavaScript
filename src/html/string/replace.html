replace()

The replace() method is a powerful find-and-replace engine. It scans a string for a specific word or pattern, removes it, and seamlessly inserts brand-new text in its place. It is completely non-destructive, meaning it leaves our original string perfectly intact and hands us a brand-new edited copy. 

let commsLog = "Captain Picard to the bridge. Picard out.";

// Let's replace "Picard" with "Sisko".
// TRAP: If we just pass a normal string, it ONLY replaces the very first one!
let editedLog = commsLog.replace("Picard", "Sisko");

console.log(editedLog); 
// Result: "Captain Sisko to the bridge. Picard out." (The second one was ignored!)

// The Professional Solution: Use RegEx with the "g" (global) flag!
// This tells the engine to hunt down and replace EVERY single occurrence.
let redactedLog = commsLog.replace(/Picard/g, "[CLASSIFIED]");

console.log(redactedLog);
// Result: "Captain [CLASSIFIED] to the bridge. [CLASSIFIED] out."

// Remember, the original transmission is untouched:
console.log(commsLog);
// Result: "Captain Picard to the bridge. Picard out."

Syntax 

string.replace(searchFor, replaceWith)

Return Value

Type: String (A brand-new string with some or all matches of a pattern replaced by the new replacement text.)

Description:

The replace() method requires two arguments: what we want to find (searchFor), and what we want to swap it with (replaceWith). The biggest mistake beginners make is passing a standard text string as the first argument, assuming it will fix the whole document. Standard text strings only replace the very first match they find! To unleash the true power of this command and replace multiple words at once, we must use a Regular Expression with the global flag (/pattern/g). It is also highly case-sensitive, so searching for "Picard" will not replace "picard".
