toString()

The toString() method is the universal data translator. It takes a value and forces it to become a literal text string. It is universally used by developers to convert Numbers, Arrays, and other data types into raw text so they can be printed to the screen, saved to a text file, or manipulated using string-specific commands. 

// 1. The classic String method (returns the primitive string)
let registryObj = new String("NCC-1701");
console.log(registryObj.toString()); 
// Result: "NCC-1701"

// 2. The Professional Use: Converting Numbers!
let warpSpeed = 9.9; // This is a raw Number data type

// Let us say we want to use padStart() on it. If we don't convert it first, the app crashes!
let speedLog = warpSpeed.toString(); 

console.log(speedLog.padStart(5, "0"));
// Result: "009.9" (Success! The number is now behaving like text!)

// 3. Converting Arrays into text:
let awayTeam = ["Kirk", "Spock", "McCoy"];
console.log(awayTeam.toString());
// Result: "Kirk,Spock,McCoy" (It automatically joins them with commas!)

Syntax 

string.toString()

Return Value

Type: String (A string representing the specified object or value.)

Description:

The toString() method is built into the very DNA of JavaScript. If we call it on a standard text string, it simply returns the exact same string. But its true power lies in Type Coercion. String commands like replace() or padStart() will absolutely crash if we try to use them on a Number or an Array. By running our raw data through toString() first, we safely translate it into a text format. Keep in mind that when we call it on an Array, it automatically flattens the list and separates the items with commas!
