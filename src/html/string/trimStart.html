trimStart()

The trimStart() method is a precision front-end scrubber. It actively hunts down and deletes any invisible whitespace characters (like spaces or tabs) that are clinging to the very beginning of a string, while completely ignoring the spaces at the end. 

let commsLog = "       Captain on the bridge!   ";

// We want to clear the static (spaces) at the start of the transmission,
// but we need to keep the spaces at the end so the next log entry doesn't run into it.

let cleanedStart = commsLog.trimStart();

console.log(cleanedStart); 
// Result: "Captain on the bridge!   " (The front is clean, the back is untouched!)

// Professional Trivia: We might also see this written as trimLeft() in older code!
let legacyCode = "   Engage.".trimLeft();

console.log(legacyCode);
// Result: "Engage."

Syntax 

string.trimStart()

Return Value

Type: String (A brand-new string with all leading whitespace removed. The original string remains untouched.)

Description:

While trim() is the blunt instrument used to clean both sides of a string, trimStart() is the surgical tool used when we need to preserve the formatting on the right side. This is particularly useful when we are processing lines of a text file where the right-side spacing actually means something to the computer. Historical Note: Long ago, this method was originally called trimLeft(). In modern updates, they officially changed the name to trimStart() to make it consistent with padStart(), but they kept trimLeft() active as an alias so older websites wouldn't suddenly break!
