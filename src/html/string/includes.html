includes()

The includes() method is our universal text scanner. Instead of just checking the very beginning or the very end of a string, it searches the entire string to see if a specific word or character exists anywhere inside it. It returns a simple true or false. 

let transmission = "Warning: Borg cube detected in Sector 4";

// Scan the transmission for the word "Borg"
let threatDetected = transmission.includes("Borg");
console.log(threatDetected); 
// Result: true

// It is highly case-sensitive!
let lowercaseCheck = transmission.includes("borg");
console.log(lowercaseCheck);
// Result: false

// Advanced: We can tell the scanner exactly where to start looking.
// Let us start scanning at Index 20 (skipping the first half of the message)
let lateScan = transmission.includes("Warning", 20);
console.log(lateScan);
// Result: false (The word "Warning" is before Index 20!)

Syntax 

string.includes(searchString, position)

Return Value

Type: Boolean (true if the exact search string is found anywhere within the text; otherwise, false.)

Description:

Before includes() was added to modern JavaScript, developers had to use clunky math commands (like checking if indexOf() was greater than -1) just to see if a word existed in a sentence. This modern method makes scanning text incredibly readable and intuitive. Remember that it is strictly case-sensitive. It also features an optional second parameter called position. If we pass a number into this second slot, the computer will ignore the beginning of the string and only start searching from that specific index number onward.
