slice()

The slice() method is a precision laser cutter. It extracts a specific section of a string and returns it as a brand-new string, leaving the original text completely untouched. We simply tell the computer exactly which index coordinate to start cutting at, and which coordinate to stop at. 

let fullRegistry = "USS Enterprise NCC-1701-D";

// Let us extract just the ship's name.
// Start cutting at Index 4 (the "E"), and stop BEFORE Index 14!
let shipName = fullRegistry.slice(4, 14);

console.log(shipName); 
// Result: "Enterprise"

// If we leave out the second number, it slices all the way to the very end!
let designationCode = fullRegistry.slice(15);
console.log(designationCode);
// Result: "NCC-1701-D"

// Advanced: We can use NEGATIVE numbers to count backward from the end!
// Let us grab just the last two characters:
let shipClass = fullRegistry.slice(-2);
console.log(shipClass);
// Result: "-D"

Syntax 

string.slice(indexStart, indexEnd)

Return Value

Type: String (A new string containing the extracted section of the original text.)

Description:

The slice() method is one of the most frequently used commands in all of JavaScript. It requires an indexStart coordinate, and accepts an optional indexEnd coordinate. The absolute most important rule to memorize is the "Inclusive/Exclusive Rule": the method includes the character at the start coordinate, but stops before it cuts the character at the end coordinate. Its true superpower is its ability to accept negative numbers. Passing a -1 tells the computer to start cutting from the very last character in the string, making it incredibly easy to chop off the tail end of a sentence without needing to know exactly how long the sentence is!
