substring()

The substring() method is a highly forgiving data extractor. Just like slice(), it pulls a specific section out of a string based on the start and end coordinates we provide. However, it has a built-in safety net: if we accidentally put the coordinates in the wrong order, or if we try to use negative numbers, it will automatically correct our math and extract the text anyway! 

let database = "Section 31 Classified Data";

// Standard extraction: Start at Index 0, stop BEFORE Index 10
let division = database.substring(0, 10);
console.log(division); 
// Result: "Section 31"

// THE QUIRKY SWAP!
// What if we accidentally put the big number first? 
// substring() realizes our mistake and secretly swaps them for us!
let swappedCoordinates = database.substring(10, 0);
console.log(swappedCoordinates);
// Result: "Section 31" (If we did this with slice(), it would fail!)

// THE NEGATIVE TRAP!
// substring() absolutely hates negative numbers. It turns them into 0 instantly.
let negativeAttempt = database.substring(-5, 7);
console.log(negativeAttempt);
// Result: "Section" (It treated -5 as 0, and extracted from 0 to 7)

Syntax 

string.substring(indexStart, indexEnd)

Return Value

Type: String (A new string containing the extracted section of the original text.)

Description:

While substring() uses the exact same "Inclusive/Exclusive Rule" as slice(), its hidden logic makes it completely unique. The Argument Swapping Rule means that if our indexStart is greater than our indexEnd, the engine will physically flip the numbers around to prevent the app from crashing. The Zeroing Rule means that if we pass a negative number (like -5) or NaN, the engine will instantly convert it to a 0. Because of this quirky, unpredictable behavior, most modern professional developers prefer to use slice() for their daily cutting tools, as it follows stricter and more predictable mathematical logic!
