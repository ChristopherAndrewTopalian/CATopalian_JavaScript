isWellFormed()

The isWellFormed() method is a brand new, modern security scanner. It checks the deep structural integrity of a string to ensure no complex characters (like emojis) have been broken or corrupted during transmission. It returns a simple true or false. 

let standardMessage = "Federation signals are clear 🖖";

// A normal string with standard text and a complete emoji
let checkNormal = standardMessage.isWellFormed();
console.log(checkNormal); 
// Result: true

// Let's simulate a corrupted transmission with a broken emoji!
// We will manually insert half of a surrogate pair (\uD83D)
let corruptedMessage = "Data corrupted: \uD83D";

let checkCorrupted = corruptedMessage.isWellFormed();
console.log(checkCorrupted);
// Result: false (The string has a lone, broken character!)

Syntax 

string.isWellFormed()

Return Value

Type: Boolean (true if the string contains no lone surrogates; otherwise, false.)

Description:

This is a very new addition to JavaScript! Remember from our codePointAt() lesson that massive characters like emojis require two 16-bit blocks of memory (called a "surrogate pair") to render correctly. Sometimes, when data is sent across the internet, strings get chopped up, and an emoji loses its second half, leaving behind a "lone surrogate". If we try to process or encode a string with a broken surrogate, the app can crash or throw URI errors. The isWellFormed() method allows us to instantly verify the structural health of the text before we attempt to process it.
