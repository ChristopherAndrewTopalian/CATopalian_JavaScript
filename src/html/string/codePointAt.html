codePointAt()

The codePointAt() method is the modern upgrade to charCodeAt(). It returns the full Unicode value of a character. Its true superpower is that it can correctly read complex, modern characters like emojis and rare alien symbols that are too massive to fit into standard 16-bit data blocks. 

let transmission = "🖖 Peace and long life";

// Let us look at the Vulcan Salute emoji at Index 0.
// The old method breaks the emoji in half and returns garbage data!
let oldMethod = transmission.charCodeAt(0);
console.log(oldMethod); 
// Result: 55357 (This is just half of the emoji's code!)

// The modern method grabs the entire, massive Unicode value:
let modernMethod = transmission.codePointAt(0);
console.log(modernMethod); 
// Result: 128406 (The true numeric code for 🖖)

// Just like the old method, standard letters still work perfectly:
let pCode = transmission.codePointAt(2); 
console.log(pCode);
// Result: 80 (The code for capital "P")

Syntax 

string.codePointAt(index)

Return Value

Type: Number (A non-negative integer representing the full Unicode code point value. Returns undefined if the index is out of bounds.)

Description:

When JavaScript was created, the creators assumed every character in the world could fit into a single 16-bit block of memory (UTF-16). But as the internet grew to include thousands of emojis and complex ancient languages, they ran out of space. To fix this, complex characters are now split across two 16-bit blocks (called a "surrogate pair"). The classic charCodeAt() method is blind to this; it only reads the first half of the pair and returns a broken number. The modern codePointAt() method is smart enough to detect these massive characters, read both blocks of memory simultaneously, and return the true, complete numeric value.
