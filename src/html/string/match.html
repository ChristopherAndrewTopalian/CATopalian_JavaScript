match()

The match() method is an advanced pattern-recognition scanner. Instead of just searching for an exact word, we feed it a Regular Expression (RegEx) pattern, and it extracts every single piece of data from the string that matches that specific pattern. It gathers all the matching pieces and returns them neatly inside a brand-new Array! 

let sensorReadings = "Shield frequencies: 42.5 MHz, 108.2 MHz, 99.1 MHz.";

// We don't want the text! Let us extract ONLY the numbers.
// The RegEx pattern /\d+(\.\d+)?/g means "find all numbers and decimals globally"
let extractedNumbers = sensorReadings.match(/\d+(\.\d+)?/g);

console.log(extractedNumbers); 
// Result: ["42.5", "108.2", "99.1"]

// What if the scanner finds absolutely nothing?
let warpSignatures = sensorReadings.match(/warp/i);
console.log(warpSignatures);
// Result: null (Target pattern not found!)

Syntax 

string.match(regexp)

Return Value

Type: Array or Null

  • Array: Returns an array containing all the successful matches found in the string.
  • Null: Returns null if the pattern is not found anywhere in the text.

Description:

While we can pass a standard text string into match(), its true power is unlocked when we use Regular Expressions (patterns written between two forward slashes /pattern/). The most important thing to know about match() is the "g" (global) flag. If our RegEx pattern includes a "g" at the end, the scanner will search the entire string and return an Array of every single match it finds. If we forget the "g", it will stop scanning the second it finds the very first match and return a highly detailed array with extra properties about just that single item. Also, remember that unlike indexOf() which returns a -1 on failure, match() completely empties its hands and returns null!
