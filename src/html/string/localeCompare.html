localeCompare()

The localeCompare() method is a human-dictionary engine. It compares two strings and returns a number indicating whether the first string belongs before, after, or is identical to the second string in a perfectly alphabetized list. 

let species1 = "Zindi";
let species2 = "andorian";

// Standard JavaScript math thinks capital "Z" (90) is smaller than "a" (97)!
console.log(species1 < species2); 
// Result: true (This is terrible for alphabetizing a list!)

// localeCompare() understands actual human language rules:
let dictionarySort = species1.localeCompare(species2);
console.log(dictionarySort); 
// Result: 1 (Positive number means "Zindi" belongs AFTER "andorian")

// Advanced: We can tell it exactly which language rules to follow!
// In German, "ä" comes BEFORE "z". In Swedish, "ä" comes AFTER "z".
let letter = "ä";
console.log(letter.localeCompare("z", "de")); // German (Returns -1)
console.log(letter.localeCompare("z", "sv")); // Swedish (Returns 1)

Syntax 

referenceStr.localeCompare(compareString, locales, options)

Return Value

Type: Number

  • Negative Number (usually -1): The reference string occurs before the compare string.
  • Positive Number (usually 1): The reference string occurs after the compare string.
  • 0: The strings are completely equivalent.

Description:

Whenever we are building an app that sorts a list of user names, cities, or files alphabetically, we must use localeCompare(). If we rely on basic math operators, all capitalized words will group together at the top, ignoring actual alphabetical order. This method is incredibly powerful because of the optional locales parameter. By passing in a language code (like "de" for German, "fr" for French, or "sv" for Swedish), the engine instantly adapts to the unique grammatical sorting rules and accented characters of that specific culture.
