String.fromCodePoint()

The String.fromCodePoint() method is the modern, heavy-duty decryption tool. It does exactly what fromCharCode() does, but it has the power to process massive Unicode numbers (like emojis and rare symbols) and successfully reassemble them into readable text without corrupting the data. 

// Let us decrypt the Vulcan Salute from the previous lesson (Code: 128406)
let modernDecryption = String.fromCodePoint(128406);

console.log(modernDecryption); 
// Result: "🖖"

// We can mix standard text numbers with massive emoji numbers!
// 80="P", 101="e", 97="a", 99="c", 101="e"
let message = String.fromCodePoint(80, 101, 97, 99, 101, 128406);

console.log(message);
// Result: "Peace🖖"

Syntax 

String.fromCodePoint(num1, num2, /* ..., */ numN)

Return Value

Type: String (A new string created from the specified sequence of full Unicode code points.)

Description:

Just like its predecessor, this is a static method that must be called directly on the built-in capital-S String object. The classic fromCharCode() method crashes or returns garbage data if we feed it a number larger than 65535 (the maximum size of a 16-bit block). String.fromCodePoint() is smart enough to handle massive numbers up to 1114111. It automatically figures out if a character needs one block of memory or two (a surrogate pair), stitches them together flawlessly, and renders the correct emoji or complex symbol on the screen.
