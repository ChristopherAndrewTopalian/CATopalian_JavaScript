endsWith()

The endsWith() method is a boolean checker. It inspects the very end of a string to see if it perfectly matches a specific character or word we are looking for. It will only ever return true or false. 

let registry = "NCC-1701-D";

// Let us check if this is the Enterprise-D
let isGalaxyClass = registry.endsWith("D");
console.log(isGalaxyClass); 
// Result: true

// What if we check for lowercase "d"?
let caseSensitiveCheck = registry.endsWith("d");
console.log(caseSensitiveCheck);
// Result: false (It must be an exact match!)

// Advanced: We can pass a second number to fake the "end" of the string!
// Let us pretend the string is only 8 characters long ("NCC-1701")
let checkOriginal = registry.endsWith("1701", 8);
console.log(checkOriginal);
// Result: true

Syntax 

string.endsWith(searchString, endPosition)

Return Value

Type: Boolean (true if the end of the string perfectly matches the search characters; otherwise, false.)

Description:

This method is highly case-sensitive, meaning a capital "D" is not the same as a lowercase "d". Its true secret weapon is the optional endPosition parameter. By default, the computer looks at the very end of the string. But if we pass in a number as a second argument, we can artificially chop the string down to that length before the computer checks it. In our example, passing an 8 tells the computer to ignore the "-D" entirely and treat "NCC-1701" as the end of the string!
