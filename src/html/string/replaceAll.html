replaceAll()

The replaceAll() method is the modern, heavy-duty upgrade to the standard replace command. It completely eliminates the "first occurrence trap." If we hand it a standard text string, it will automatically hunt down and replace every single instance of that word throughout the entire document, no Regular Expressions required! 

let missionBrief = "Dock at Starbase 12. Refuel at Starbase 12. Defend Starbase 12.";

// The modern miracle: We can replace them ALL using just standard text!
let updatedBrief = missionBrief.replaceAll("Starbase 12", "Deep Space 9");

console.log(updatedBrief); 
// Result: "Dock at Deep Space 9. Refuel at Deep Space 9. Defend Deep Space 9."

// THE REGEX TRAP: If we DO decide to use Regular Expressions with this method,
// we absolutely MUST include the "g" (global) flag, or it will crash!

// let brokenBrief = missionBrief.replaceAll(/Starbase 12/i, "Outpost"); 
// -> THIS WILL THROW A FATAL TYPE ERROR!

let safeRegExBrief = missionBrief.replaceAll(/Starbase 12/g, "Outpost");
console.log(safeRegExBrief);
// Result: "Dock at Outpost. Refuel at Outpost. Defend Outpost."

Syntax 

string.replaceAll(searchFor, replaceWith)

Return Value

Type: String (A brand-new string where every single match of the target text has been replaced.)

Description:

Introduced in ECMAScript 2021, replaceAll() was created to save developers from having to write complex Regular Expressions just to do a simple, document-wide word swap. Like its predecessor, it is strictly case-sensitive and completely non-destructive to the original variable. The most important rule to teach our fingers is the RegEx Crash Rule: because the entire purpose of this method is to replace everything, if we pass a Regular Expression into it that is missing the global /g flag, JavaScript will assume we made a mistake and instantly throw a TypeError to protect our data from partial edits.
