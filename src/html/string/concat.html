concat()

The concat() method (short for concatenate) is used to fuse two or more strings together into one brand-new, continuous string. We start with a base string, and pass the pieces we want to attach as arguments inside the parentheses. 

let prefix = "USS ";
let shipName = "Voyager ";
let registry = "NCC-74656";

// Let us fuse all three individual strings together!
let fullDesignation = prefix.concat(shipName, registry);

console.log(fullDesignation); 
// Result: "USS Voyager NCC-74656"

// Important: The original strings are completely untouched!
console.log(prefix);
// Result: "USS "

Syntax 

string.concat(str1, str2, /* ..., */ strN)

Return Value

Type: String (A brand new string containing the combined text of all the provided strings.)

Description:

The concat() method is a non-destructive command. It does not alter the original variables we pass into it; it simply reads them, glues them together in the exact order we provided, and hands us a completely new string. Industry Secret: While concat() is the official method, professional developers almost never use it in modern code! It is much more common, faster, and easier to read if we just use the addition operator (+) to add strings together, or use modern Template Literals (using backticks) to inject variables directly into text.
