padStart()

The padStart() method is a structural formatting tool that forces a string to reach a specific length by repeatedly adding a filler character to the beginning of the text. It is universally used in programming to add "leading zeros" to ID numbers, timestamps, and database records so everything aligns perfectly. 

// We have a database of ship registry numbers, but they are all different lengths!
let reg1 = "42";
let reg2 = "871";
let reg3 = "1701";

// We want every registry number to be exactly 5 digits long.
// We will pad the front of the short numbers with zeros!
let formattedReg1 = reg1.padStart(5, "0");
let formattedReg2 = reg2.padStart(5, "0");
let formattedReg3 = reg3.padStart(5, "0");

console.log(formattedReg1); // Result: "00042"
console.log(formattedReg2); // Result: "00871"
console.log(formattedReg3); // Result: "01701"

// Wait! What if we try to pad a Number data type instead of a String?
let rawNumber = 9;
// console.log(rawNumber.padStart(2, "0")); -> THIS WILL CRASH!
// We must convert the number to a string first!
console.log(rawNumber.toString().padStart(2, "0")); // Result: "09"

Syntax 

string.padStart(targetLength, padString)

Return Value

Type: String (A brand new string of the specified target length, with the pad string applied to the beginning.)

Description:

The padStart() method operates exactly like padEnd(), just in reverse. The first parameter is the targetLength, and the second parameter is the padString (the filler character). The most critical rule to remember is that this is a String Method. It will absolutely crash the app if we try to call it directly on a Number data type! We must always convert our raw numbers to strings (using toString() or template literals) before we can pad them with leading zeros.
