trim()

The trim() method is a data scrubber. It actively hunts down and deletes any invisible whitespace characters (like spaces, tabs, or hidden line breaks) that are clinging to the very beginning or the very end of a string. It is absolutely essential for sanitizing user passwords and login emails! 

let databasePassword = "alpha-tango-9";

// The user was sloppy and accidentally hit the spacebar a few times!
let sloppyInput = "   alpha-tango-9   ";

// If we compare them directly, the security system triggers an alarm!
console.log(sloppyInput === databasePassword); 
// Result: false (Access Denied!)

// The Professional Solution: Scrub the dirt off the edges!
let cleanedInput = sloppyInput.trim();

console.log(cleanedInput === databasePassword);
// Result: true (Access Granted!)

// THE TRAP: trim() DOES NOT touch spaces in the middle of a string!
let messyName = "   Jean-Luc    Picard   ";
console.log(messyName.trim());
// Result: "Jean-Luc    Picard" (The edges are clean, but the middle is untouched!)

Syntax 

string.trim()

Return Value

Type: String (A brand-new string with all leading and trailing whitespace removed.)

Description:

Humans entering data during crisis situations, are sometimes messy typists. When building web forms, or secure Starfleet War Tactical apps, developers must assume the user accidentally included invisible spaces. The trim() method creates a clean copy of the string by deleting spaces, tabs, and newline characters from both ends. However, its most important rule is the Middle Preservation Rule: it will completely ignore any spaces that are trapped between actual characters. If we need to remove spaces from the middle of a sentence, we cannot use trim(); we must use the replaceAll() method instead!
