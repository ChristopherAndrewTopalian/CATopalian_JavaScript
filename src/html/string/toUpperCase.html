toUpperCase()

The toUpperCase() method is a capitalization engine. It reads a string and converts every single lowercase letter into an uppercase letter. It is non-destructive and is frequently used to format constant variables, standardize identification codes, or generate visual emphasis in user interfaces. 

let tacticalSensor = "warning: shields at 20 percent";

// The message is too quiet! We need it to grab the Captain's attention!
let visualAlert = tacticalSensor.toUpperCase();

console.log(visualAlert); 
// Result: "WARNING: SHIELDS AT 20 PERCENT"

// Standardizing identification codes for the database:
let userInputId = "ncc-1701-d";
let officialId = userInputId.toUpperCase();

console.log(officialId);
// Result: "NCC-1701-D" (Now it matches official Starfleet records!)

// Remember, numbers and symbols are completely ignored:
let mixedData = "warp 9.9!".toUpperCase();
console.log(mixedData);
// Result: "WARP 9.9!"

Syntax 

string.toUpperCase()

Return Value

Type: String (A brand-new string where all the alphabetic characters have been converted to uppercase.)

Description:

The toUpperCase() method is the mirror opposite of the lowercase converter. It is a fantastic tool for normalizing data that absolutely must be capitalized, like postal codes, license plates, or ship registries. Because it creates a completely new string, it will never accidentally overwrite the original data. Just like its twin, this method only affects alphabetic letters and completely ignores spaces, numbers, and punctuation. Also remember that this uses standard English mapping rules; if we are building an application for global users with complex alphabets, we should use the toLocaleUpperCase() method instead!
