search()

The search() method is a RegEx-powered targeting scanner. It behaves very much like indexOf() by returning the exact index coordinate of a target. However, instead of looking for a specific word, it hunts for a pattern, allowing us to find the location of data even when we don't know exactly what that data says! 

let sensorLog = "Sector 4 clear. Unknown anomaly detected at grid 88-Tango.";

// We don't know the exact grid name, but we know the pattern: 
// Two digits, a hyphen, and a word. (RegEx: /\d{2}-\w+/)
let targetCoordinate = sensorLog.search(/\d{2}-\w+/);

console.log(targetCoordinate); 
// Result: 47 (The "8" in "88-Tango" is located at Index 47)

// If the scanner fails to find the pattern anywhere in the log:
let borgSignature = sensorLog.search(/Borg/);
console.log(borgSignature);
// Result: -1 (Target pattern not found!)

// Note: If we pass it a standard string, it secretly converts it to RegEx for us!
let standardSearch = sensorLog.search("Sector");
console.log(standardSearch);
// Result: 0

Syntax 

string.search(regexp)

Return Value

Type: Number (The index coordinate of the first match. Returns -1 if the pattern is not found.)

Description:

To master JavaScript, we must comprehend the difference between search(), indexOf(), and match(). Use indexOf() when we are looking for a simple, exact word, it is much faster and uses less computer memory. Use match() when we want to actually extract the data and put it into an Array. Use search() when we only need to know the location (the index number) of a complex Regular Expression pattern. Keep in mind that search() entirely ignores the "g" (global) flag; it will always stop scanning the absolute second it finds the very first match.
