trimEnd()

The trimEnd() method is a precision back-end scrubber. It actively hunts down and deletes any invisible whitespace characters (like spaces, tabs, or hidden line breaks) that are clinging to the very end of a string, while completely protecting any spaces at the beginning. 

let engineeringLog = "     Warp core stable.     ";

// We absolutely MUST keep the 5 spaces at the beginning to maintain 
// the strict visual indentation of our database reports!
// But the spaces at the end are just wasting memory.

let cleanedEnd = engineeringLog.trimEnd();

console.log(cleanedEnd); 
// Result: "     Warp core stable." (The front is protected, the back is clean!)

// Professional Trivia: We might also see this written as trimRight() in older code!
let legacyCode = "Engage.   ".trimRight();

console.log(legacyCode);
// Result: "Engage."

Syntax 

string.trimEnd()

Return Value

Type: String (A brand-new string with all trailing whitespace removed. The original string remains untouched.)

Description:

The trimEnd() method is the exact mirror of trimStart(). It is a highly specialized tool used by developers to clean up the right side of user input without destroying the left side. This is especially critical when dealing with text where indentation matters. Just like its twin, Historical Note: this method was originally called trimRight() in the early days of JavaScript. It was officially renamed to trimEnd() to match the naming convention of padEnd(), but trimRight() still works perfectly today as an alias to ensure ancient websites don't crash!
