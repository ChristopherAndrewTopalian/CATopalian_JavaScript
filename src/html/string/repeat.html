repeat()

The repeat() method is a mass-production cloner. It takes a starting string and duplicates it a specific number of times, gluing all the clones together into one massive, continuous string. It completely eliminates the need to write for loops just to repeat text! 

let klaxon = "RED ALERT! ";

// Broadcast the warning across the ship 3 times
let broadcast = klaxon.repeat(3);

console.log(broadcast); 
// Result: "RED ALERT! RED ALERT! RED ALERT! "

// Professional Trick: Instantly draw divider lines for a terminal UI!
let dividerLine = "-".repeat(30);

console.log(dividerLine);
// Result: "------------------------------"

// What happens if we pass in a 0?
let silentKlaxon = klaxon.repeat(0);
console.log(silentKlaxon);
// Result: "" (Returns a completely empty string!)

Syntax 

string.repeat(count)

Return Value

Type: String (A brand new string containing the specified number of copies of the original text, glued together.)

Description:

The repeat() method requires a single parameter: the count (how many times we want to clone the string). While it seems simple, it has some very strict mathematical rules built into its engine! If we pass it a 0, it safely returns an empty string. If we pass it a decimal like 3.5, it will automatically round down to 3. But be warned: if we pass it a negative number (like -1), or an incredibly massive number that exceeds the browser's memory limit, it will trigger a fatal RangeError and crash the application!
