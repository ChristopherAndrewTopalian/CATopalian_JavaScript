startsWith()

The startsWith() method is a boolean frontend scanner. It inspects the very beginning of a string to see if it perfectly matches a specific character or word we are looking for. It is the exact opposite of endsWith() and will only ever return true or false. 

let transmission = "Priority One: Borg cube detected.";

// Let us check if this is an urgent message!
let isUrgent = transmission.startsWith("Priority One");

console.log(isUrgent); 
// Result: true (Route to the Captain immediately!)

// It is highly case-sensitive!
let caseCheck = transmission.startsWith("priority");
console.log(caseCheck);
// Result: false

// Advanced: We can pass a second number to fake the "start" of the string!
// Let's tell the scanner to skip the first 14 characters.
let checkThreat = transmission.startsWith("Borg", 14);

console.log(checkThreat);
// Result: true (The word "Borg" starts exactly at Index 14!)

Syntax 

string.startsWith(searchString, position)

Return Value

Type: Boolean (true if the beginning of the string perfectly matches the search characters; otherwise, false.)

Description:

This method is incredibly fast and efficient because it doesn't need to scan the entire document like includes() does; it just checks the front door. Like most modern string scanners, it is strictly case-sensitive. Its true power comes from the optional position parameter. By default, the computer starts looking at Index 0. But if we pass in a number as a second argument, we can artificially chop off the front of the string and force the computer to begin its "start" check from that specific coordinate deep inside the text!
