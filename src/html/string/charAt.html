charAt()

The charAt() method is the traditional, classic way to read a single character from a string at a specific index number. Unlike the modern at() command, it does not understand negative numbers. 

let registry = "NCC-1701-D";

// Get the character at Index 4
let middleChar = registry.charAt(4);
console.log(middleChar); 
// Result: "1"

// To get the last character, we must use math!
let lastChar = registry.charAt(registry.length - 1);
console.log(lastChar); 
// Result: "D"

// If we try to use a negative number or go out of bounds:
let outOfBounds = registry.charAt(-1);
console.log(outOfBounds); 
// Result: "" (Returns an empty string, not an error!)

Syntax 

string.charAt(index)

Return Value

Type: String (A single character, or an empty string "" if the index cannot be found)

Description:

This is the foundational method for extracting characters that has been in JavaScript since the very beginning. Because it does not support negative indexing, developers historically had to use the string.length - 1 formula to calculate the exact coordinate of the final character. If we provide an index number that doesn't exist (like 100 on a 10-character string), charAt() safely fails by returning a completely empty string, preventing our app from crashing.
