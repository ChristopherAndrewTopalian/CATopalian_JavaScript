split()

The split() method is a structural demolition tool. It takes a single string, hunts for a specific "separator" character (like a comma or a space), and physically shatters the string at every location where that character exists. It then gathers all the broken pieces and returns them to us inside a brand-new Array. 

let crewRoster = "Kirk,Spock,McCoy,Uhura";

// Shatter the string every time it sees a comma!
let crewArray = crewRoster.split(",");

console.log(crewArray); 
// Result: ["Kirk", "Spock", "McCoy", "Uhura"]

// What if we want to split a sentence into individual words?
// We use a blank space " " as the separator!
let command = "Fire photon torpedoes";
let wordsArray = command.split(" ");

console.log(wordsArray);
// Result: ["Fire", "photon", "torpedoes"]

// Advanced: We can put a strict limit on the number of pieces!
// Let us chop the roster, but only keep the first two crew members.
let awayTeam = crewRoster.split(",", 2);

console.log(awayTeam);
// Result: ["Kirk", "Spock"]

Syntax 

string.split(separator, limit)

Return Value

Type: Array (A brand-new Array containing the extracted substrings.)

Description:

This method is universally used to process CSV (Comma-Separated Values) files and user input. The separator parameter dictates exactly where the axe falls. If we omit the separator completely (split()), it will just shove the entire unbroken string into an Array. The most powerful trick to remember is the Empty String Hack: if we pass an empty string with absolutely no space inside it (split("")), the engine will aggressively shatter the text between every single letter, turning a word into an array of individual characters! The optional limit parameter allows us to tell the computer to stop chopping after a certain number of pieces have been collected.
