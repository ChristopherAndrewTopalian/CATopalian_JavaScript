toLocaleUpperCase()

The toLocaleUpperCase() method is the culturally aware capitalization tool. It converts every letter in a string to uppercase, but actively checks the specific grammatical rules of the user's native language to ensure that special characters and unique alphabets are capitalized correctly. 

let starbaseLocation = "istanbul";

// STANDARD UPPERCASE (The American/English default):
// The computer blindly changes the dotted lowercase "i" to a dotless "I"
let standardUpper = starbaseLocation.toUpperCase();
console.log(standardUpper); 
// Result: "ISTANBUL" (The spelling is now corrupted in Turkey!)

// LOCALE AWARE UPPERCASE (Using the 'tr-TR' language tag for Turkish):
// In Turkish, a dotted lowercase "i" MUST become a dotted capital "İ"
let turkishUpper = starbaseLocation.toLocaleUpperCase('tr-TR');
console.log(turkishUpper);
// Result: "İSTANBUL" (The Universal Translator respects the grammar!)

// If we just want to shout using the browser's default language:
let incomingThreat = "shields up";
console.log(incomingThreat.toLocaleUpperCase());
// Result: "SHIELDS UP"

Syntax 

string.toLocaleUpperCase(locales)

Return Value

Type: String (A brand new string converted to uppercase according to specific locale grammar rules.)

Description:

Just like its lowercase twin, toLocaleUpperCase() was created to fix the "Turkish I" problem. In standard English, a lowercase "i" becomes a dotless capital "I". But in Turkish, a lowercase "i" must retain its dot when capitalized, becoming "İ". If we build a worldwide search engine and use the standard method, our Turkish users won't be able to find the files they are looking for because the computer changed the spelling of their search terms! By passing a language tag like "tr-TR" into the locales parameter, or by leaving it blank so it auto-detects the user's operating system language, we guarantee that our app handles international text flawlessly.
