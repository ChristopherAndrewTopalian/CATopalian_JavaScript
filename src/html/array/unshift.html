unshift()

unshift() - Adding to the Beginning

What if you need to cut in line? unshift() shoves a new item into the very first slot (Index 0) and bumps all the other items down one space. 

let fleet = ["Defiant", "Voyager"];

// A new flagship takes the lead position
fleet.unshift("Enterprise"); 

console.log(fleet); 
// Result: ["Enterprise", "Defiant", "Voyager"]

Syntax 

array.unshift(element1, element2, /* ..., */ elementN)

Return Value

Type: Number

Description:

This method inserts new elements at the absolute front of the array (Index 0). The rest of the fleet is safely pushed back to higher index numbers to make room. It returns the new, updated length property of the array.
