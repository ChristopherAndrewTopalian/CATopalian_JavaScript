isArray()

Just like from(), the Array.isArray() command is a Static Method. You call it directly on the global Array object to run a strict structural integrity scan on any piece of data.

It answers one simple question with a true or false: "Is this data structure actually an array, or is it just a string, an object, or a number pretending to be one?" This is crucial for preventing errors before you try to run array-specific commands (like a for loop) on something that isn't a list! 

let standardFormation = ["Enterprise", "Defiant"];
let rogueSignal = "Borg Cube";

// Scan the formation
let checkFormation = Array.isArray(standardFormation);
console.log(checkFormation); // Result: true

// Scan the rogue signal
let checkSignal = Array.isArray(rogueSignal);
console.log(checkSignal); // Result: false
