join()

When you are ready to display your array on a user interface, you often want it to look like a normal sentence rather than a coded list. join() takes all the items in your array and stitches them together into a single text string, using whatever separator you choose! 

let fleet = ["Enterprise", "Defiant", "Voyager"];

// Join the fleet together using a comma and a space
let report = fleet.join(", "); 

console.log(report); 
// Result: "Enterprise, Defiant, Voyager"

Syntax 

array.join(separator)

Return Value

Type: String (A single, combined text transmission)

Description:

This method is our primary communications array. It takes every single item in the fleet, converts them into text, and links them all together into one massive String. By default, it separates the items with a comma, but we can pass it any "separator" we want (like a space, a dash, or even a completely empty string "") to format the transmission exactly how we need it.
