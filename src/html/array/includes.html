includes()

The Sensor Sweep

If you need to know immediately if a specific item exists in your massive database, run an includes() check. It returns a simple, lightning-fast true or false boolean value. 

let fleet = ["Enterprise", "Defiant", "Voyager"];

// Scan the array for a specific string
let isDefiantSafe = fleet.includes("Defiant");

console.log(isDefiantSafe); 
// Result: true

Syntax 

array.includes(searchElement, /* optional: */ fromIndex)

Return Value

Type: Boolean (true or false)

Description:

This method is a simple, highly effective proximity scanner. It checks if our array contains one specific item. If the target is detected anywhere in the formation, it instantly returns true. If the scan completes and the target is missing, it returns false. It does not require a callback function; we simply hand it the exact data we are looking for!
