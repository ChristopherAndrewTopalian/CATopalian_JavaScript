push() - Adding to the End

If we want to add a new item to the very back of the line, use push()

let fleet = ["Enterprise", "Defiant"];


// Send a new ship to the fleet 

fleet.push("Voyager"); 

console.log(fleet); 
// Result: ["Enterprise", "Defiant", "Voyager"]

Syntax 

array.push(element1, element2, /* ..., */ elementN)

Return Value

Type: Number

Description:

Returns the new length property of the array after the new elements have been successfully attached to the end of the formation.
