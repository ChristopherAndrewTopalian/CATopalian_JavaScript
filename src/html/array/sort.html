sort()

The sort() method is a permanent, fleet-wide reorganization command. By default, it sorts items alphabetically as strings. If we need to sort numerical data (like ship registry numbers), we must provide a compare function so the system knows exactly how to rank them! 

let registries = [74656, 1701, 75633, 1864]; // Voyager, Enterprise, Defiant, Reliant

// Reorganize the fleet numerically from lowest to highest
registries.sort((a, b) => a - b);

console.log(registries); 
// Result: [1701, 1864, 74656, 75633] (The original array is permanently altered)

Syntax (Classic ES5) 

array.sort(function(a, b) { 
    /* return a negative number, positive number, or zero */ 
})

Syntax (Modern ES6) 

array.sort((a, b) => { /* return a negative, positive, or zero */ })

Return Value

Type: Array (The original array, completely reordered)

Description:

This is the ultimate reorganization command. The Admiral issues a metric (like tonnage, registry number, or alphabetical order), and the entire fleet physically shifts positions to comply. We pass it a "compare function" that looks at two ships at a time (a and b) to determine their rank. Warning: This is a destructive maneuver! It does not create a new array; it permanently alters the formation of the original array.
