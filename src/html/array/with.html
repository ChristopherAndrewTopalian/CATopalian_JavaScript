with()

If we want to change a single ship in our array, we normally have to overwrite it directly (like fleet[1] = "Discovery").

with() allows us to replace an item at a specific index and returns a brand-new array, keeping our original data completely secure. 

let fleet = ["Enterprise", "Defiant", "Voyager"];

// Create a new array *with* Index 1 replaced by "Farragut"
let alternateFleet = fleet.with(1, "Farragut");

console.log(alternateFleet); 
// Result: ["Enterprise", "Farragut", "Voyager"]
