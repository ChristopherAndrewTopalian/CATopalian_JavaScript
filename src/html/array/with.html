with()

If we want to change a single ship in our array, we normally have to overwrite it directly (like fleet[1] = "Discovery").

with() allows us to replace an item at a specific index and returns a brand-new array, keeping our original data completely secure. 

let fleet = ["Enterprise", "Defiant", "Voyager"];

// Create a new array *with* Index 1 replaced by "Farragut"
let alternateFleet = fleet.with(1, "Farragut");

console.log(alternateFleet); 
// Result: ["Enterprise", "Farragut", "Voyager"]

// The original array remains safe!
console.log(fleet);
// Result: ["Enterprise", "Defiant", "Voyager"]

Syntax 

array.with(index, value)

Return Value

Type: Array (A brand-new array with the element replaced)

Description:

This modern ES2023 maneuver is the safe alternative to direct bracket notation assignment (e.g., fleet[1] = "Farragut"). Instead of overwriting the original ship at that coordinate and permanently altering our database, with() swaps the ship and immediately returns the result as a brand-new array. This allows us to run tactical simulations and alternate fleet configurations without risking our primary data.
