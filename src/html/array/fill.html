fill()

fill() is a heavy-handed command. It takes an existing array and overwrites the items inside it with a static, identical value. You can overwrite the entire array, or specify a start and end index to only overwrite a specific sector. 

let dockingBays = ["Empty", "Empty", "Empty", "Empty"];

// A fleet just arrived. Fill bays starting at Index 1 up to Index 3.
dockingBays.fill("Occupied", 1, 3);

console.log(dockingBays); 
// Result: ["Empty", "Occupied", "Occupied", "Empty"]

Syntax 

array.fill(value, /* optional: */ start, end)

Return Value

Type: Array (The original array, physically modified)

Description:

This method issues a blanket replacement order across the fleet. It takes one static value and aggressively overwrites the existing ships with it. We can deploy it across the entire array, or restrict it to a specific sector using the start and end indexes. Warning: This is a destructive maneuver! It permanently overwrites the original data in those target slots.
