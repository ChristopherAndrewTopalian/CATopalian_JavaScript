flat()

Sometimes, an array contains other arrays tucked inside of it (this is called a multi-dimensional array or a nested array).

The flat() method takes all of those separated, internal arrays and dumps them out into one single, unified, one-dimensional list. 

// We have an array containing two separate sub-squadron arrays
let sectorGrids = [
    ["Alpha", "Beta"], 
    ["Gamma", "Delta"]
];

// Flatten the structure into one continuous command list
let unifiedGrid = sectorGrids.flat();

console.log(unifiedGrid); 
// Result: ["Alpha", "Beta", "Gamma", "Delta"]
