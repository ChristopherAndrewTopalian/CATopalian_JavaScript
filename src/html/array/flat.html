flat()

Sometimes, an array contains other arrays tucked inside of it (this is called a multi-dimensional array or a nested array).

The flat() method takes all of those separated, internal arrays and dumps them out into one single, unified, one-dimensional list. 

// We have an array containing two separate sub-squadron arrays
let sectorGrids = [
    ["Alpha", "Beta"], 
    ["Gamma", "Delta"]
];

// Flatten the structure into one continuous command list
let unifiedGrid = sectorGrids.flat();

console.log(unifiedGrid); 
// Result: ["Alpha", "Beta", "Gamma", "Delta"]

Syntax 

array.flat(/* optional: */ depth)

Return Value

Type: Array (A brand-new, unified array)

Description:

If our array contains other arrays inside of it (like a massive Carrier ship holding nested squadrons of fighters), the flat() command orders them all to deploy into a single, unified battle line. It extracts the nested ships and places them directly into a brand-new array. By default, it only unpacks one level deep, but we can provide a depth number to tell it exactly how many nested layers to unpack!
