every()

The every() method runs a strict test on our entire array. It checks if every single item in the list passes a specific condition that we define. If even one item fails, the entire sweep returns false. 

let shieldLevels = [100, 100, 100, 95, 100];

// Check if every shield grid is perfectly maxed out
let allShieldsMaximum = shieldLevels.every(level => level === 100);

console.log(allShieldsMaximum); 
// Result: false (Because that 95 broke the perfect streak!)

Syntax (Classic ES5) 

array.every(function(element, index, array) { 
    /* return true or false */ 
})

Syntax (Modern ES6) 

array.every((element, index, array) => { /* return true or false */ })

Return Value

Type: Boolean (true or false)

Description:

This method runs a strict, system-wide diagnostic on the entire array. It checks if every single item in the formation passes a specific condition that we define. If even one single ship fails the test, the entire sweep immediately aborts and returns false. It only returns true if the entire fleet is in perfect compliance.
