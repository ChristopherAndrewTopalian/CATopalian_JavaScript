reverse()

The reverse() method takes our array and physically flips the entire order of the items.

Warning: This method physically alters our original array rather than making a safe copy! 

let formation = ["Flagship", "Escort", "Rear Guard"];

// Execute a 180-degree turn
formation.reverse();

console.log(formation); 
// Result: ["Rear Guard", "Escort", "Flagship"]

Syntax 

array.reverse()

Return Value

Type: Array (The original array, completely inverted)

Description:

This method orders an immediate, fleet-wide about-face. It physically flips the entire formation end-to-end, so the flagship in the front becomes the rear guard, and the ship in the back becomes the new vanguard. Warning: Just like the sort() command, this is a destructive maneuver! It does not create a new array; it permanently alters the physical formation of the original array.
