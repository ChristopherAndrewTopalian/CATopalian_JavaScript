forEach()

The forEach() method is the modern equivalent of the traditional for loop. It takes a function and executes it exactly one time for every single item currently sitting in the array.

It is a strict action command. Unlike filter() or map(), it does not create a new array. It simply runs down the line and triggers an event (like logging a message or updating a display) for each item it targets. 

let fleet = ["Enterprise", "Defiant", "Voyager"];

// Initiate a standard roll call for the entire formation
fleet.forEach(ship => {
    console.log(ship + " is holding position and awaiting orders.");
});

// Output:
// Enterprise is holding position and awaiting orders.
// Defiant is holding position and awaiting orders.
// Voyager is holding position and awaiting orders.
