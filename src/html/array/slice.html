slice()

The Reconnaissance Copy

Sometimes you need to look at a section of your array without destroying the original list. slice() makes a perfect copy of a specific chunk of the array. It takes a starting index and an ending index. 

let fleet = ["Enterprise", "Discovery", "Defiant", "Voyager"];

// Copy from Index 1 up to (but not including) Index 3
let assaultTeam = fleet.slice(1, 3); 

console.log(assaultTeam); 
// Result: ["Discovery", "Defiant"]
