slice()

Sometimes we need to look at a section of our array without destroying the original list. slice() makes a perfect copy of a specific chunk of the array. It takes a starting index and an ending index. 

let fleet = ["Enterprise", "Discovery", "Defiant", "Voyager"];

// Copy from Index 1 up to (but not including) Index 3
let assaultTeam = fleet.slice(1, 3); 

console.log(assaultTeam); 
// Result: ["Discovery", "Defiant"]

Syntax 

array.slice(start, end)

Return Value

Type: Array (A brand-new array)

Description:

This method safely copies a specific section of our array and returns it as a new array. The original fleet remains completely untouched and unharmed! It begins copying at the start index and stops right before the end index. If you do not provide an end index, it copies everything from the start point all the way to the end of the line.
