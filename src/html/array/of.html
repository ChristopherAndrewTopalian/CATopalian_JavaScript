of()

Just like from(), Array.of() is a Static Method called directly on the global Array object. It takes whatever individual arguments you hand it and instantly packs them into a brand-new array.

It was specifically engineered to fix a weird quirk in older JavaScript where typing Array(7) would create an array with 7 empty ghost slots, but typing Array.of(7) correctly creates an array containing the actual number 7! 

// Requisition a new Away Team from scratch
let awayTeam = Array.of("Worf", "Data", "Riker");

console.log(awayTeam); 
// Result: ["Worf", "Data", "Riker"]

// The quirk it fixes:
console.log(Array.of(7)); 
// Result: [7]
