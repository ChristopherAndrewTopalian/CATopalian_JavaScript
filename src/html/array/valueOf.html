valueOf()

The valueOf() method is a foundational JavaScript command that operates under the hood. When you call it on an array, it simply returns the exact array itself.

You will rarely ever type this command out manually, as JavaScript automatically uses it behind the scenes whenever it needs to evaluate the raw data of your object. 

let fleet = ["Enterprise", "Defiant"];

// Request the primitive value of the array
let actualValue = fleet.valueOf();

console.log(actualValue); 
// Result: ["Enterprise", "Defiant"]
