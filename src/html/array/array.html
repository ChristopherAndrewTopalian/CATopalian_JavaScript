Array

What is an Array?

Think of an array as a single container that can hold a list of multiple items at once. Instead of creating a separate variable for every single thing, you group related items together in an ordered, numbered list.

Creating an Array

Arrays are created using square brackets [ ]. Each item inside the array is separated by a comma. 

let fleet = ["Enterprise", "Defiant", "Voyager"];

Accessing Items (The Index)

JavaScript arrays are zero-indexed. This is a crucial concept: the computer starts counting at 0, not 1! To access an item, you use its index number inside square brackets. 

fleet[0]; // Returns Enterprise

fleet[1]; // Returns Defiant

fleet[2]; // Returns Voyager

Modifying the List

Arrays are dynamic, meaning you can add or remove items after the array has been created using built-in commands called "methods".

.push() Adds an item to the end of the array 

fleet.push("Discovery");

.pop() Removes the last item from the array 

fleet.pop();

.length Checking the size

We can always check how many items are currently in your array using the length property. 

fleet.length; // Returns 3
