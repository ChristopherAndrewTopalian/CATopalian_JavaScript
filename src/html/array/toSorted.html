toSorted()

toSorted() is the modern, purely functional version of the classic sort() command. It organizes your items (alphabetically or numerically) and hands you a brand-new, safely copied array without mutating the original list. 

let roster = ["Riker", "Picard", "Data", "Crusher"];

// Sort the crew alphabetically without destroying the original roster
let alphabeticalRoster = roster.toSorted();

console.log(alphabeticalRoster); 
// Result: ["Crusher", "Data", "Picard", "Riker"]

// Proof that the original fleet is completely untouched:
console.log(roster);
// Result: ["Riker", "Picard", "Data", "Crusher"]

Syntax (Default Alphabetical) 

array.toSorted()

Syntax (With ES5 Compare Function) 

array.toSorted(function(a, b) { 
    /* return a negative number, positive number, or zero */ 
})

Syntax (With ES6 Compare Function) 

array.toSorted((a, b) => { /* return a negative, positive, or zero */ })

Return Value

Type: Array (A brand-new, reorganized array)

Description:

This is the safe, non-destructive version of the classic sort() command. Introduced in modern JavaScript (ES2023), it performs the exact same fleet reorganization, but instead of mutating the original array, it returns a brand-new array containing the sorted elements. If no compare function is provided, it sorts the items alphabetically as strings.
