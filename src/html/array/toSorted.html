toSorted()

toSorted() is the modern, purely functional version of the classic sort() command. It organizes your items (alphabetically or numerically) and hands you a brand-new, safely copied array without mutating the original list. 

let roster = ["Riker", "Picard", "Data", "Crusher"];

// Sort the crew alphabetically without destroying the original roster
let alphabeticalRoster = roster.toSorted();

console.log(alphabeticalRoster); 
// Result: ["Crusher", "Data", "Picard", "Riker"]
