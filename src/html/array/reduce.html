reduce()

reduce() is arguably the most powerful (and most complex) method in JavaScript. It sweeps through your entire array and "reduces" all the items down into one single output value (like a total sum, or a master text string).

It uses an "Accumulator" (a running total) that gets updated every time it looks at the next ship in the line. 

// Example 1: ES5 Version

let crewComplements = [1000, 150, 500];

// Calculate the total number of personnel in the fleet
// 'total' is the accumulator, 'crew' is the current ship being counted
let totalPersonnel = crewComplements.reduce(function(total, crew) {
    return total + crew;
}, 0); // <-- This 0 is our initialValue!

console.log(totalPersonnel); 
// Result: 1650

// Example 2: ES6 Version

let crewComplements = [1000, 150, 500];

// Calculate the total number of personnel in the fleet
// 'total' is the accumulator, 'crew' is the current ship being counted
let totalPersonnel = crewComplements.reduce((total, crew) => total + crew, 0);

console.log(totalPersonnel); 
// Result: 1650

Syntax (ES5 Version) 

array.reduce(function(accumulator, currentValue, currentIndex, array) { 
    /* return the updated accumulator */ 
}, initialValue)

Syntax (ES6 Version) 

array.reduce((accumulator, currentValue, currentIndex, array) => { 
    /* return the updated accumulator */ 
}, initialValue)

Return Value

Type: Any (Returns a single compiled value, like a Number, String, or even an Object)

Description:

This is the absolute heavyweight champion of JavaScript. It sweeps through the entire array and "reduces" all the items down into one single output value (like calculating the total crew count of an entire fleet). It uses an "accumulator" to keep a running total as it moves from ship to ship. We always provide an initialValue (like 0) at the end of the method to ensure the accumulator starts safely from zero.
