concat()

When we have two separate arrays and you need to merge them into one massive list, we use concat(). This method does not alter our original arrays; instead, it returns a brand-new array containing all the combined data. 

let alphaSquadron = ["Enterprise", "Discovery"];
let betaSquadron = ["Defiant", "Voyager"];

// Merge Beta Squadron into Alpha Squadron
let grandArmada = alphaSquadron.concat(betaSquadron);

console.log(grandArmada); 
// Result: ["Enterprise", "Discovery", "Defiant", "Voyager"]

Syntax 

array.concat(array2, array3, /* ..., */ arrayN)

Return Value

Type: Array (A brand-new, combined array)

Description:

This method is used to assemble a massive allied armada. It takes our original array and seamlessly merges it with one or more additional arrays. The most important tactical detail: it is completely non-destructive! It leaves the original fleets perfectly intact in their respective sectors and returns a brand-new array containing the combined forces.
