reduceRight()

reduceRight() does the exact same massive computation as reduce(), compiling the entire array into a single value. The only difference is its tactical approach: it starts accumulating from the absolute end of the array and works its way backward to the front. 

// Example 1: ES5 Version

let encryptedSignal = ["A", "H", "P", "L", "A"];

// Decode the signal by reading it backward and combining the letters
let decodedWord = encryptedSignal.reduceRight(function(total, letter) {
    return total + letter;
}, ""); // <-- This empty string is our initialValue!

console.log(decodedWord); 
// Result: "ALPHA"

// Example 2: ES6 Version

let encryptedSignal = ["A", "H", "P", "L", "A"];

// Decode the signal by reading it backward and combining the letters
let decodedWord = encryptedSignal.reduceRight((total, letter) => total + letter, "");

console.log(decodedWord); 
// Result: "ALPHA"

Syntax (ES5 Version) 

array.reduceRight(function(accumulator, currentValue, currentIndex, array) { 
    /* return the updated accumulator */ 
}, initialValue)

Syntax (ES6 Version) 

array.reduceRight((accumulator, currentValue, currentIndex, array) => { 
    /* return the updated accumulator */ 
}, initialValue)

Return Value

Type: Any (Returns a single compiled value, like a String, Number, or Object)

Description:

This heavyweight command performs the exact same fleet-wide compilation as reduce(), but it executes its sequence in reverse. Starting from the rear guard and working its way to the vanguard, it uses an "accumulator" to keep a running total or, in this case, a combined string. It is the perfect tool for decrypting backward transmissions or processing a queue from last-in to first-out.
