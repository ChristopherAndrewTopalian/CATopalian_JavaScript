pop() - Removing from the End

pop() does the exact opposite of push. It plucks the very last item off the end of the array and completely removes it from the list. 

let fleet = ["Enterprise", "Defiant", "Voyager"];

// The last ship gets destroyed or decommissioned
fleet.pop(); 

console.log(fleet); 
// Result: ["Enterprise", "Defiant"]

Syntax 

array.pop()

Return Value

Type: Any (Depends on the data inside the array)

Description:

This method does not return a number! It actually returns the exact item that was just removed. If you use pop() on an empty array, it safely returns undefined.
