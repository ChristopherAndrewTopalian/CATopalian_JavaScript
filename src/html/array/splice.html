splice()

The Tactical Insert

splice() is the ultimate array tool. It allows you to add, remove, or replace items anywhere inside the array. You just tell it exactly what index number to start at, and how many items to delete before adding new ones. 

let fleet = ["Enterprise", "Defiant", "Voyager"];

// Start at Index 1. Delete 0 ships. Insert "Discovery".
fleet.splice(1, 0, "Discovery"); 

console.log(fleet); 
// Result: ["Enterprise", "Discovery", "Defiant", "Voyager"]
