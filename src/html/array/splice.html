splice()

splice() is the ultimate array tool. It allows you to add, remove, or replace items anywhere inside the array. You just tell it exactly what index number to start at, and how many items to delete before adding new ones. 

let fleet = ["Enterprise", "Defiant", "Voyager"];

// Start at Index 1. Delete 0 ships. Insert "Discovery".
fleet.splice(1, 0, "Discovery"); 

console.log(fleet); 
// Result: ["Enterprise", "Discovery", "Defiant", "Voyager"]

Syntax 

array.splice(start, deleteCount, item1, item2, /* ..., */ itemN)

Return Value

Type: Array (Contains the removed items)

Description:

This is a heavy-duty, destructive command. It physically alters the original array by removing items, inserting new ones, or doing both simultaneously. It begins at the start index, removes the exact number of ships specified by the deleteCount, and then inserts any new items directly into that gap. It returns an array containing any items that were successfully removed from the formation.
