some()

Earlier we used every() to check if the entire fleet passed a test. some() is much more sensitive. It sweeps the array and returns true if at least one single item matches your condition.

The moment it finds a single match, it immediately triggers the alert and stops scanning. 

let shieldGrids = [100, 100, 45, 100];

// Scan the fleet to see if ANY ship has shields below 50%
let redAlert = shieldGrids.some(level => level < 50);

console.log(redAlert); 
// Result: true (Because that 45 triggered the sensor!)

Syntax (Classic ES5) 

array.some(function(element, index, array) { 
    /* return true or false */ 
})

Syntax (Modern ES6) 

array.some((element, index, array) => { /* return true or false */ })

Return Value

Type: Boolean (true or false)

Description:

This method is our highly sensitive early warning system. It sweeps the array and checks if at least one single item matches our specific condition. The absolute millisecond it finds a single match, it immediately triggers the alert (returns true) and stops scanning. If the sweep completes and it finds absolutely nothing, it returns false.
