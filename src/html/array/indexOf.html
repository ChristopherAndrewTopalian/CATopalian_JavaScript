indexOf()

The indexOf() method is a lightning-fast locator beacon. You hand it a specific item (like a string or a number), and it sweeps the array to find it. The moment it detects a perfect match, it returns the Index Number of that item.

If it sweeps the entire array and doesn't find the item, it returns -1. 

let fleet = ["Voyager", "Enterprise", "Defiant"];

// Request the exact docking index of the Enterprise
let bayNumber = fleet.indexOf("Enterprise");

console.log(bayNumber); 
// Result: 1 (Remember, arrays always start counting at 0!)

Syntax 

array.indexOf(searchElement, /* optional: */ fromIndex)

Return Value

Type: Number (The exact index position, or -1)

Description:

This method locks onto a specific target and sweeps the fleet from front to back. The absolute millisecond it detects the item, it returns the exact index number (coordinates) of that first match and stops scanning. If the target is nowhere to be found in the current sector, it safely returns a -1. No callback functions are required; we just hand it the exact data we want to find!
