filter()

filter() is one of the most powerful tools in JavaScript. It sweeps through an array, tests every single item against a specific rule, and returns a brand-new array containing only the items that passed the test! 

// Example 1: ES5 Version

let warpSpeeds = [2, 9, 4, 8, 1, 6];

// The Rule: Only keep speeds greater than or equal to Warp 5
let highWarpOnly = warpSpeeds.filter(function(speed) {
    return speed >= 5;
});

console.log(highWarpOnly); 
// Result: [9, 8, 6]

// Example 2: ES6 Version

let warpSpeeds = [2, 9, 4, 8, 1, 6];

// The Rule: Only keep speeds greater than or equal to Warp 5
let highWarpOnly = warpSpeeds.filter(speed => speed >= 5);

console.log(highWarpOnly); 
// Result: [9, 8, 6]

Notice that the original warpSpeeds array remains completely unchanged in both examples. filter() always generates a safe, modified copy of your data, no matter which syntax you use to write it.

Syntax (Classic ES5) 

array.filter(function(element, index, array) { 
    /* return true or false */ 
})

Syntax (Modern ES6) 

array.filter((element, index, array) => { /* return true or false */ })

Return Value

Type: Array (A brand-new array)

Description:

This method executes a system-wide sensor sweep. It tests every single item in the array against a specific condition that we define. If an item passes the test (evaluates to true), it is copied into a brand-new array. If it fails, it is left behind. Our original fleet remains completely untouched and safely docked.
