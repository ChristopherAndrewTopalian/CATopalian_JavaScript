toReversed()

The classic reverse() method is dangerous because it physically alters your original array. The modern toReversed() method solves this by executing the exact same 180-degree flip, but it safely returns the result as a brand-new array. 

let standardFormation = ["Flagship", "Escort", "Rear Guard"];

// Execute the maneuver safely
let invertedFormation = standardFormation.toReversed();

console.log(invertedFormation); 
// Result: ["Rear Guard", "Escort", "Flagship"]

// The original array is perfectly untouched!
console.log(standardFormation); 
// Result: ["Flagship", "Escort", "Rear Guard"]
