toReversed()

The classic reverse() method is dangerous because it physically alters the original array. The modern toReversed() method solves this by executing the exact same 180-degree flip, but it safely returns the result as a brand-new array. 

let standardFormation = ["Flagship", "Escort", "Rear Guard"];

// Execute the maneuver safely
let invertedFormation = standardFormation.toReversed();

console.log(invertedFormation); 
// Result: ["Rear Guard", "Escort", "Flagship"]

// The original array is perfectly untouched!
console.log(standardFormation); 
// Result: ["Flagship", "Escort", "Rear Guard"]

Syntax 

array.toReversed()

Return Value

Type: Array (A brand-new array in reverse order)

Description:

Introduced in the modern ES2023 update, this is the completely safe, non-destructive alternative to the classic reverse() command. It executes a complete 180-degree fleet about-face, moving the rear guard to the vanguard and vice versa. However, instead of mutating our existing data, it returns the newly ordered formation as a brand-new array. Our original fleet remains perfectly intact.
