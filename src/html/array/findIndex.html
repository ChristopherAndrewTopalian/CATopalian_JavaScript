findIndex()

While find() returns the actual item you are looking for, findIndex() returns the exact position (the index number) of that item inside the array.

It sweeps from left to right. The moment it finds the first match, it reports the index number and stops scanning. If it scans the entire array and finds absolutely nothing, it will safely return -1. 

let fleet = ["Voyager", "Enterprise", "Defiant"];

// Find the exact docking bay (index) of the Enterprise
let targetCoordinates = fleet.findIndex(ship => ship === "Enterprise");

console.log(targetCoordinates); 
// Result: 1 (Because arrays always start counting at 0!)
