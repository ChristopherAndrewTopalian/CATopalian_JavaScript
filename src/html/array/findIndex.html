findIndex()

While find() returns the actual item we are looking for, findIndex() returns the exact position (the index number) of that item inside the array.

It sweeps from left to right. The moment it finds the first match, it reports the index number and stops scanning. If it scans the entire array and finds absolutely nothing, it will safely return -1. 

// Example 1: ES5 Version

let fleet = ["Voyager", "Enterprise", "Defiant"];

// Find the exact docking bay (index) of the Enterprise
let targetCoordinates = fleet.findIndex(function(ship) {
    return ship === "Enterprise";
});

console.log(targetCoordinates); 
// Result: 1 (Because arrays always start counting at 0!)

// Example 2: ES6 Version

let fleet = ["Voyager", "Enterprise", "Defiant"];

// Find the exact docking bay (index) of the Enterprise
let targetCoordinates = fleet.findIndex(ship => ship === "Enterprise");

console.log(targetCoordinates); 
// Result: 1 (Because arrays always start counting at 0!)

Syntax (ES5 Version) 

array.findIndex(function(element, index, array) { 
    /* return true or false */ 
})

Syntax (ES6 Version) 

array.findIndex((element, index, array) => { /* return true or false */ })

Return Value

Type: Number (The index position, or -1)

Description:

While find() returns the actual item we are looking for, findIndex() returns the exact position (the index number) of that item inside the array. It sweeps from left to right. The moment it finds the first match, it reports the index number (the coordinates) and stops scanning. If it scans the entire array and finds absolutely nothing, it safely returns a -1.
