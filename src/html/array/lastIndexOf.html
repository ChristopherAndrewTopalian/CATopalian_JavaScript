lastIndexOf()

The lastIndexOf() method is a highly tactical search tool. It does the exact same job as indexOf()—locating a specific item and returning its index number—but it executes its scan in reverse.

It starts at the absolute end of the array and sweeps backward. If you have duplicates in your fleet, it will pinpoint the one furthest in the back. 

let fleet = ["Defiant", "Enterprise", "Voyager", "Defiant"];

// Locate the rearmost Defiant-class ship in the formation
let rearGuardPosition = fleet.lastIndexOf("Defiant");

console.log(rearGuardPosition); 
// Result: 3 (It ignores the one sitting at Index 0!)
