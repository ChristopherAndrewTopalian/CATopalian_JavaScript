toSpliced()

The classic splice() is a heavy-duty tool that rips items out of the array. toSpliced() allows us to remove or inject items at a specific index, but it generates a fresh, updated copy of the array instead of tearing the original one apart. 

let fleet = ["Enterprise", "Defiant", "Voyager"];

// Target index 1. Remove 1 ship (Defiant). Insert "Discovery".
let updatedFleet = fleet.toSpliced(1, 1, "Discovery");

console.log(updatedFleet); 
// Result: ["Enterprise", "Discovery", "Voyager"]

// Proof that the original fleet is completely untouched!
console.log(fleet); 
// Result: ["Enterprise", "Defiant", "Voyager"]

Syntax 

array.toSpliced(start, deleteCount, item1, item2, /* …, */ itemN)

Return Value

Type: Array (A brand-new array with the specified modifications applied)

Description:

Introduced in the ES2023 update, this is the completely safe, non-destructive alternative to the classic splice() maneuver. It allows you to target a specific coordinate (index), remove a specific number of ships, and instantly deploy new ships into that exact gap. However, instead of permanently mutilating the original data, it executes these heavy modifications and returns the result as a brand-new array. Our original fleet remains safely docked.
