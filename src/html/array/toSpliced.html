toSpliced()

The classic splice() is a heavy-duty tool that rips items out of your array. toSpliced() allows you to remove or inject items at a specific index, but it generates a fresh, updated copy of the array instead of tearing the original one apart. 

let fleet = ["Enterprise", "Defiant", "Voyager"];

// Target index 1. Remove 1 ship (Defiant). Insert "Discovery".
let updatedFleet = fleet.toSpliced(1, 1, "Discovery");

console.log(updatedFleet); 
// Result: ["Enterprise", "Discovery", "Voyager"]
