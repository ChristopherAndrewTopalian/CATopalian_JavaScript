find()

While filter() returns a list of everything that matches your search, find() is a precision strike. It sweeps the array and returns the very first item that matches your condition, and then it immediately stops looking. 

let crew = ["Riker", "Data", "Worf", "Data"];

// Locate the first instance of "Data" in the array
let androidTarget = crew.find(member => member === "Data");

console.log(androidTarget); 
// Result: "Data" (It ignores the second one at the end of the list)
