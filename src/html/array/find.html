find()

While filter() returns a list of everything that matches your search, find() is a precision strike. It sweeps the array and returns the very first item that matches your condition, and then it immediately stops looking. 

// Example 1: ES5 Version

let crew = ["Riker", "Data", "Worf", "Data"];

// Locate the first instance of "Data" in the array
let androidTarget = crew.find(function(member) {
    return member === "Data";
});

console.log(androidTarget); 
// Result: "Data" (It ignores the second one at the end of the list)

// Example 2: ES6 Version

let crew = ["Riker", "Data", "Worf", "Data"];

// Locate the first instance of "Data" in the array
let androidTarget = crew.find(member => member === "Data");

console.log(androidTarget); 
// Result: "Data" (It ignores the second one at the end of the list)

Syntax (ES5 Version) 

array.find(function(element, index, array) { 
    /* return true or false */ 
})

Syntax (ES6 Version) 

array.find((element, index, array) => { /* return true or false */ })

Return Value

Type: Any (Returns the item itself, or undefined)

Description:

While filter() gathers every ship that matches a condition, find() is a precision strike. It sweeps the array from left to right and returns the very first item that successfully passes our test. The absolute millisecond it finds a match, the method stops scanning to save processing power. If the entire sweep finishes and nothing matches, it safely returns undefined.
