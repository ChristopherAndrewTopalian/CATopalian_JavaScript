flatMap()

The flatMap() method is a highly efficient, two-in-one command. First, it sweeps through your array and runs a function on every item (just like a standard map()). Then, it automatically takes the results and flattens them into a single, one-dimensional array.

It is the perfect tool for when you need to deploy multiple items (like shuttles) from a list of ships, but you want all those deployed items to end up in one unified list, rather than a bunch of separate, nested lists. 

let ships = ["Enterprise", "Voyager"];

// Command each ship to deploy two shuttles
let deployedShuttles = ships.flatMap(ship => [ship + " Shuttle 1", ship + " Shuttle 2"]);

console.log(deployedShuttles); 
// Result: ["Enterprise Shuttle 1", "Enterprise Shuttle 2", "Voyager Shuttle 1", "Voyager Shuttle 2"]

Syntax (Classic ES5) 

array.flatMap(function(element, index, array) { 
    /* return the modified and unpacked element */ 
})

Syntax (Modern ES6) 

array.flatMap((element, index, array) => { /* return the modified and unpacked element */ })

Return Value

Type: Array (A brand-new, completely unpacked array)

Description:

This advanced command executes two distinct tactical maneuvers at the exact same time. First, it sweeps the fleet and modifies each item (just like map()). But then, if any of those modified items are themselves an array (like a carrier ship holding a squadron of fighters), it immediately "unpacks" them, flattening everything out into one single, unified brand-new array.
