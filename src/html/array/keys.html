keys()

The keys() method is the direct counterpart to the entries() method we built earlier. Instead of giving you both the index number and the ship name, keys() completely ignores the ships and returns an iterator containing only the index numbers (the docking bays). 

let fleet = ["Enterprise", "Defiant", "Voyager"];

let dockingBays = fleet.keys();

// Loop through to see the available bay numbers
for (let bay of dockingBays) {
    console.log(bay);
}
// Output:
// 0
// 1
// 2
