findLastIndex()

Combining the logic of the previous two commands, findLastIndex() scans your array in reverse (starting from the back) and returns the index number of the very first match it encounters. 

let commsLog = ["Clear", "Static", "Clear", "Static", "Clear"];

// Find the exact index number of the most recent "Static" burst
let latestInterferenceIndex = commsLog.findLastIndex(signal => signal === "Static");

console.log(latestInterferenceIndex); 
// Result: 3

Syntax (Classic ES5) 

array.findLastIndex(function(element, index, array) { 
    /* return true or false */ 
})

Syntax (Modern ES6) 

array.findLastIndex((element, index, array) => { /* return true or false */ })

Return Value

Type: Number (The index position, or -1)

Description:

Combining the logic of the previous commands, findLastIndex() scans our array in reverse (starting from the back) and returns the exact index number (coordinates) of the very first match it encounters. If the rear-guard sweep finishes and detects absolutely nothing, it safely returns a -1.
