shift()

shift() - Removing from the Beginning

shift() removes the very first item (Index 0) from the array, shifting all the remaining items forward to fill the gap. 

let fleet = ["Enterprise", "Defiant", "Voyager"];

// The flagship leaves the fleet
fleet.shift(); 

console.log(fleet); 
// Result: ["Defiant", "Voyager"]

Syntax 

array.shift()

Return Value

Type: Any (Depends on the data inside the array)

Description:

This method removes the very first item (Index 0) from the array and returns that extracted item. All remaining ships in the formation are automatically shifted down to a lower index number. If the array is empty, it returns undefined.
