findLast()

The findLast() method does the exact same job as find(), but it executes its sweep in reverse! It starts at the absolute end of the array and works its way backward toward the front.

This is incredibly useful for reviewing chronological data, like a Captain's Log, when you need to quickly locate the most recent occurrence of a specific event. 

let commsLog = ["Clear", "Static", "Clear", "Static", "Clear"];

// Find the most recent (last) instance of "Static"
let latestInterference = commsLog.findLast(signal => signal === "Static");

console.log(latestInterference); 
// Result: "Static"

Syntax (Classic ES5) 

array.findLast(function(element, index, array) { 
    /* return true or false */ 
})

Syntax (Modern ES6) 

array.findLast((element, index, array) => { /* return true or false */ })

Return Value

Type: Any (Returns the item itself, or undefined)

Description:

This method operates exactly like find(), but it executes its sensor sweep in reverse! It starts at the absolute end of the array and works its way backward toward the front. It returns the very first item it encounters that passes our test. This is incredibly useful for reviewing chronological data, like a Captain's Log, when we need to locate the most recent occurrence of a specific event without scanning the entire history.
