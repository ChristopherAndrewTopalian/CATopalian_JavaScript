at()

The at() method takes an integer value and returns the item at that specific index. While it works just like standard bracket notation [0], its true superpower is that it allows negative integers to count backward from the end of the array!

This means we can easily target the last ship in the fleet without needing to calculate fleet.length - 1. 

let fleet = ["Enterprise", "Defiant", "Voyager"];

// Target the first ship
let flagship = fleet.at(0);
console.log(flagship); // Result: "Enterprise"

// Target the very last ship in the formation
let rearGuard = fleet.at(-1); 
console.log(rearGuard); // Result: "Voyager"
