map()

map() is arguably one of the most used methods in all of JavaScript. It sweeps through our original array, takes every single item, runs a function to modify that item, and then constructs a brand-new array out of the upgraded results.

It is the ultimate tool for running a fleet-wide retrofit without permanently altering our original database records. 

// Example 1: ES5 Version

let oldFleet = ["Enterprise", "Defiant", "Voyager"];

// Upgrade every ship by appending the word "Refit" to its name
let upgradedFleet = oldFleet.map(function(ship) {
    return ship + " (Refit)";
});

console.log(upgradedFleet); 
// Result: ["Enterprise (Refit)", "Defiant (Refit)", "Voyager (Refit)"]

// The original fleet remains untouched!
console.log(oldFleet);
// Result: ["Enterprise", "Defiant", "Voyager"]

// Example 2: ES6 Version

let oldFleet = ["Enterprise", "Defiant", "Voyager"];

// Upgrade every ship by appending the word "Refit" to its name
let upgradedFleet = oldFleet.map(ship => ship + " (Refit)");

console.log(upgradedFleet); 
// Result: ["Enterprise (Refit)", "Defiant (Refit)", "Voyager (Refit)"]

// The original fleet remains untouched!
console.log(oldFleet);
// Result: ["Enterprise", "Defiant", "Voyager"]

Syntax (ES5 Version) 

array.map(function(element, index, array) { 
    /* return the modified element */ 
})

Syntax (ES6 Version) 

array.map((element, index, array) => { /* return the modified element */ })

Return Value

Type: Array (A brand-new array)
