entries()

The entries() method returns a special Array Iterator object. When you loop through it, it provides an array containing both the Index Number (the docking bay) and the Value (the ship name) for every single item in your fleet. 

let fleet = ["Enterprise", "Defiant", "Voyager"];

let dockingManifest = fleet.entries();

// Use a classic for...of loop to read the iterator
for (let entry of dockingManifest) {
    console.log(entry);
}
// Output:
// [0, "Enterprise"]
// [1, "Defiant"]
// [2, "Voyager"]

Syntax 

array.entries()

Return Value

Type: Array Iterator (A specialized data stream of key/value pairs)

Description:

This command generates a complete, secure manifest of the entire fleet. Instead of just listing the ships, it creates an "Iterator" that outputs a paired data packet containing both the exact registry slot (the index) and the ship itself (the element). It is highly useful when we need to loop through a formation and require absolute confirmation of both what the ship is and exactly where it is parked.
