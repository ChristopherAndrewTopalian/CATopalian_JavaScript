copyWithin()

copyWithin() is a highly tactical method that copies a section of your array and pastes it over another section within the exact same array, without changing the total length of the list.

It requires a target index (where to paste), a start index (what to copy), and an optional end index. 

let formation = ["Enterprise", "Defiant", "Voyager", "Discovery", "Farragut"];

// Target Index 0 (paste over Enterprise).
// Copy from Index 3 (Discovery) to the end.
formation.copyWithin(0, 3);

console.log(formation); 
// Result: ["Discovery", "Farragut", "Voyager", "Discovery", "Farragut"]
