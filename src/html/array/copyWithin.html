copyWithin()

copyWithin() is a highly tactical method that copies a section of our array and pastes it over another section within the exact same array, without changing the total length of the list. It requires a target index (where to paste), a start index (what to copy), and an optional end index. 

let formation = ["Enterprise", "Defiant", "Voyager", "Discovery", "Farragut"];

// Target Index 0 (paste over Enterprise).
// Copy from Index 3 (Discovery) to the end.
formation.copyWithin(0, 3);

console.log(formation); 
// Result: ["Discovery", "Farragut", "Voyager", "Discovery", "Farragut"]

Syntax 

array.copyWithin(target, start, /* optional: */ end)

Return Value

Type: Array (The original array, physically modified)

Description:

This is a highly specialized internal cloning maneuver. It reads a sequence of ships from one sector of our array (defined by start and end) and instantly overwrites another sector (starting at the target index) with a direct copy of that sequence. The total size of the fleet never changes, but the internal formation is completely rewritten. Warning: This is also a destructive maneuver that permanently alters the original array!
