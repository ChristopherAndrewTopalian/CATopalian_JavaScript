from()

Array.from() is a unique command. It is a "Static Method," meaning you don't use it on a fleet you already built. Instead, you use it to instantly build a brand-new array out of raw, unstructured data (like a string of text) or data that looks like an array but isn't one (like a NodeList from your HTML). 

let transmission = "WARP";

// Take a raw text string and break it into a perfectly formatted array
let signalArray = Array.from(transmission);

console.log(signalArray); 
// Result: ["W", "A", "R", "P"]

Syntax 

Array.from(dataStream, /* optional: */ mapFunction)

Return Value

Type: Array (A brand-new, officially commissioned array)

Description:

Notice: This is a Static Method! We do not call this on our individual fleet; we call it directly on the Array master computer. This command takes raw, civilian data streams (like HTML NodeLists or simple text strings) and officially conscripts them, converting them into a proper, fully functional Starfleet Array. It essentially builds a brand-new fleet out of raw materials!
