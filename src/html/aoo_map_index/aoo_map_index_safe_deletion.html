Array of Objects: Safe Deletion (Synchronizing the Index)

The Indexed Array Pattern gives us pure looping speed and 0ms instant lookups. However, there is one critical "danger zone" we must manage: Deletion.

When a ship is destroyed or decommissioned, we must remove it from both the Spreadsheet (Array) and the Card Catalog (Map). If we delete it from the Array but forget the Map, we have a "ghost" ship taking up memory. If we delete it from the Map but forget the Array, the ship will still render on our screens but we will never be able to target it. 

// Example 1: The Two-Step Deletion Process

var fleetArray = [
    { id: 'voyager', class: 'intrepid' },
    { id: 'defiant', class: 'escort' }
];

var fleetIndex = new Map();

for (var i = 0; i < fleetArray.length; i++) {
    fleetIndex.set(fleetArray[i].id, fleetArray[i]);
}

var targetId = 'defiant';

// STEP 1: Remove from the Map (Instant 0ms lookup)
fleetIndex.delete(targetId);

// STEP 2: Remove from the Array (Requires finding the exact row)
var rowIndex = fleetArray.findIndex(function(ship) {
    return ship.id === targetId;
});

// If the ship exists in the array, splice it out
if (rowIndex !== -1) {
    fleetArray.splice(rowIndex, 1);
}

console.log("Remaining Ships in Array:", fleetArray.length); // 1
console.log("Remaining Ships in Map:", fleetIndex.size);     // 1

// Example 2: The Ultimate Automation (ES6 Class)

// To prevent ourselves from ever forgetting the two-step process,
// we can wrap both data structures inside a unified 'Class'. 
// This creates a "black box" that handles the synchronization for us.

class FleetManager {
    constructor() {
        this.list = [];         // The Spreadsheet
        this.index = new Map(); // The Card Catalog
    }

    add(ship) {
        this.list.push(ship);
        this.index.set(ship.id, ship);
    }

    get(id) {
        // 0ms instant lookup
        return this.index.get(id);
    }

    remove(id) {
        this.index.delete(id);
        
        let rowIndex = this.list.findIndex(ship => ship.id === id);
        if (rowIndex !== -1) {
            this.list.splice(rowIndex, 1);
        }
    }

    get spreadsheet() {
        // Expose the raw Array so we can still use .filter() and .map()
        return this.list;
    }
}

// How to use our new automated superpower:
const starfleet = new FleetManager();
starfleet.add({ id: 'enterprise', class: 'constitution' });

// Safely delete it from both structures automatically!
starfleet.remove('enterprise');

Performance & Architecture

Map Deletion Speed: O(1). The map.delete(id) command calculates the memory address and unlinks the tether instantly.

Array Deletion Speed: O(N). The array.splice() command must first find the correct row, remove it, and then physically shift every subsequent row up by one to fill the gap.

Description:

By consolidating our Array and Map into a unified Class, we create a foolproof data architecture. Our engine can loop through starfleet.spreadsheet at 60 Frames Per Second to render graphics, while our AI logic can call starfleet.get('id') to instantly target specific entities. We have successfully achieved the ultimate balance between human readability and raw hardware performance.
