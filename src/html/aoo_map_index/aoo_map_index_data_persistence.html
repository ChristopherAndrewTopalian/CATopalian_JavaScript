Array of Objects: Data Persistence (Saving and Loading)

Whether we are saving a game state or committing an Artificial Intelligence's memories to a hard drive, we must serialize our data into a flat text format like JSON.

The beauty of the Indexed Array Pattern is that it clearly separates our "Permanent Truth" from our "Temporary Hardware Acceleration." The Array of Objects is our Permanent Truth. The Map Index is just a temporary tool we use in RAM to make lookups faster.

Therefore, when we save our application, we completely ignore the Map. We only save the master Array. When we load the application back up, we parse the Array and quickly rebuild the Map Index from scratch. 

// Example 1: Saving the State (Serialization)

var fleetArray = [
    { id: 'voyager', status: 'deep_space' },
    { id: 'enterprise', status: 'spacedock' }
];

var fleetIndex = new Map();
for (var i = 0; i < fleetArray.length; i++) {
    fleetIndex.set(fleetArray[i].id, fleetArray[i]);
}

// THE SAVE FUNCTION
// We do not stringify the Map. We only stringify our master spreadsheet.
var savedGameData = JSON.stringify(fleetArray);

console.log("Data ready for Hard Drive:");
console.log(savedGameData);
/*
[{"id":"voyager","status":"deep_space"},{"id":"enterprise","status":"spacedock"}]
*/

// Example 2: Loading the State (Deserialization and Rebuilding)

// Imagine this string was just loaded from a file or local storage
var loadedString = '[{"id":"voyager","status":"deep_space"},{"id":"defiant","status":"patrol"}]';

// Rebuild the Permanent Truth (The Array)
var restoredFleetArray = JSON.parse(loadedString);

// Rebuild the Temporary Hardware Tool (The Map Index)
var restoredFleetIndex = new Map();

for (var i = 0; i < restoredFleetArray.length; i++) {
    restoredFleetIndex.set(restoredFleetArray[i].id, restoredFleetArray[i]);
}

// Test the restoration
var targetShip = restoredFleetIndex.get('defiant');

console.log("Restored Target:", targetShip.status);
/*
Restored Target: patrol
*/

Architecture & Design

Why not save the Map? Maps are complex data structures designed for memory reference logic. They do not serialize into JSON cleanly. By relying entirely on the Array for our save state, our data remains portable. It can be sent to a PHP server, saved into an SQLite database, or downloaded as a text file perfectly.

Description:

Data Persistence proves why we use the Indexed Array Pattern instead of switching entirely to Maps. An Array of Objects is the universal language of data storage across all of computer science. By keeping the Array as our core Truth, we guarantee that our game worlds and SI cortices can be saved, paused, and transmitted flawlessly, while still benefiting from 0ms lookup speeds during active execution.
