Array of Objects: The Map Index Pattern (0ms Lookups)

We rely on the Array of Objects as our primary data structure because it provides incredibly powerful built-in methods like map(), filter(), and forEach(). However, as our databases scale to hundreds of thousands of records, searching the Array row-by-row using find() creates a massive CPU bottleneck.

To achieve 0ms instant lookups without sacrificing our beloved Array methods, we implement the Indexed Array Pattern. We keep our Array as the master spreadsheet, but we build an invisible ES6 Map alongside it to act as a direct "Card Catalog." Because JavaScript passes Objects by memory reference, the Map holds a direct tether to the data, allowing us to bypass sequential searching entirely. 

// Example 1: ES5 Version (Building the Master Fleet and the Tactical Index)

var fleetArray = [
    { id: 'voyager', class: 'intrepid', shields: 100 },
    { id: 'defiant', class: 'escort', shields: 100 },
    { id: 'enterprise', class: 'constitution', shields: 100 }
];

// The Map will act as our instant 0ms lookup directory.
// We initialize it once using the 'new' keyword.
var fleetIndex = new Map();

// We loop through the Array ONCE during initialization to build the Index.
for (var i = 0; i < fleetArray.length; i++) {
    var currentShip = fleetArray[i];
    
    // We store the exact Object reference, NOT the row number.
    fleetIndex.set(currentShip.id, currentShip);
}

console.log("Index Size:", fleetIndex.size);
/*
Index Size: 3
*/

// Example 2: ES6 Version (The 0ms Lookup and Instant Mutation)

// During combat, a for-loop is too slow. Instead of searching the Array,
// we ask the Map to hand us the physical memory reference instantly.
let targetShip = fleetIndex.get('defiant');

console.log("Ship Found:", targetShip.class);
/*
Ship Found: escort
*/

// THE MAGIC TRICK: Because the Map and the Array hold a reference to the
// exact same Object in the computer's memory, modifying the target here
// automatically updates the master Array!
targetShip.shields = 15;

console.log("Array Data Automatically Updated:", fleetArray[1].shields);
/*
Array Data Automatically Updated: 15
*/

Syntax (Index Creation) 

let lookupIndex = new Map();
lookupIndex.set(uniqueID, objectReference);

Syntax (Instant Retrieval) 

let data = lookupIndex.get(uniqueID);

Performance & Architecture

Lookup Speed: O(1) Constant Time. The Map calculates the memory address and jumps directly to the Object, completely ignoring the length of the Array.

Description:

The Indexed Array Pattern solves the fundamental divide in computer science between iterating over data and looking up data. By generating an ES6 Map alongside our Array of Objects, we construct a hybrid engine. When we need to process every entity 60 times a second, we loop through the pure Array to maximize CPU cache efficiency. When a specific event occurs, such as a user clicking a ship or an AI deciding to target a specific ID, we route the request through the Map to retrieve the exact Object instantly, bypassing the Array entirely.
