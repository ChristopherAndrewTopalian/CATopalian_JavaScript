Array of Objects: Instant Mutation (Object References)

A common fear when using the Indexed Array Pattern is that our Array and our Map will fall out of sync. If we update a ship's shield capacity in the Map, do we have to manually update the Array too?

The answer is no. In JavaScript, Objects are not copied when they are added to an Array or a Map. Instead, they are passed by Memory Reference. The Array and the Map are both holding an invisible tether to the exact same physical Object in the computer's RAM. Modifying the Object from either side instantly updates it everywhere. 

// Example 1: ES5 Version (The Shared Reference)

var fleetArray = [
    { id: 'voyager', status: 'docked' },
    { id: 'defiant', status: 'docked' }
];

var fleetIndex = new Map();

for (var i = 0; i < fleetArray.length; i++) {
    // We are NOT making a copy of the Object.
    // We are pointing the Map to the exact same Object in memory.
    fleetIndex.set(fleetArray[i].id, fleetArray[i]);
}

// We retrieve the Object instantly using the Map
var targetShip = fleetIndex.get('voyager');

// We modify the Object
targetShip.status = 'warp';

// We check the master Array. It is already updated!
console.log("Array Row 0 Status:", fleetArray[0].status);
/*
Array Row 0 Status: warp
*/

// Example 2: ES6 Version (Two-Way Synchronization)

// The tether works in both directions. If our 60 FPS physics loop 
// modifies the Array, the Map instantly sees the changes.

// The physics loop modifies the Array directly
fleetArray[1].status = 'damaged';

// We check the Map index. It is already updated!
console.log("Map Index Status:", fleetIndex.get('defiant').status);
/*
Map Index Status: damaged
*/

Memory Architecture

Pass by Reference: Complex data types (Objects and Arrays) are stored in the computer's memory heap. When you assign an Object to a variable, an Array, or a Map, JavaScript only stores the memory address (the pointer) of that Object.

Description:

The concept of Memory References is what makes the Indexed Array Pattern so powerful. We are not duplicating data and wasting RAM. We have a single, definitive "Truth" (the Object) stored in memory, and we have two distinct tools to access it: the Spreadsheet (Array) for looping, and the Card Catalog (Map) for instant retrieval. Because both tools point to the exact same Truth, mutation is effortless and perfectly synchronized.
