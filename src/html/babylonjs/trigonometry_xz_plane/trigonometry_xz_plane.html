Babylon.js: Tactical Trigonometry (XZ Plane)

Welcome to the Astrometrics Lab! When deploying a sensor net or building a circular holographic menu, placing every mesh manually is highly inefficient. Instead, we use the magic of Trigonometry. By running a for loop, we can ask the JavaScript engine to calculate the Sine and Cosine of an angle, instantly generating a perfect ring of 16 tactical data cubes resting on the ground (the XZ plane)! 

// Initialize Engine and Canvas
const canvas = document.getElementById("renderCanvas");
const engine = new BABYLON.Engine(canvas, true, {}, true);

const createScene = function () {
    const scene = new BABYLON.Scene(engine);
    scene.clearColor = new BABYLON.Color4(0.05, 0.05, 0.1, 1); 

    // Position the camera to look down at our circular formation
    const camera = new BABYLON.ArcRotateCamera("MainCamera", Math.PI / 2, Math.PI / 3, 20, BABYLON.Vector3.Zero(), scene);
    camera.attachControl(canvas, false);

    const light = new BABYLON.HemisphericLight("Starlight", new BABYLON.Vector3(0, 1, 0), scene);
    light.intensity = 0.8;

    // Build the Tactical Base Plane
    const tacticalPlane = BABYLON.MeshBuilder.CreateGround("BasePlane", {width: 20, height: 20, subdivisions: 10}, scene);
    const gridMaterial = new BABYLON.StandardMaterial("GridMat", scene);
    gridMaterial.wireframe = true; 
    gridMaterial.emissiveColor = new BABYLON.Color3(0, 0.3, 0); 
    tacticalPlane.material = gridMaterial;

    // --- TRIGONOMETRY SENSOR RING ---
    const numberOfCubes = 16;
    const radius = 6; // Distance from the center of the grid

    for (let i = 0; i < numberOfCubes; i++)
    {
        // Calculate the angle (theta) for this specific cube in Radians
        // A full circle is Math.PI * 2
        let theta = (i / numberOfCubes) * (Math.PI * 2);

        // Create the cube
        let relayCube = BABYLON.MeshBuilder.CreateBox("cube" + i, {size: 1}, scene);

        // Apply the Trigonometry to the X and Z axes!
        // X = Radius * Cosine(theta)
        // Z = Radius * Sine(theta)
        relayCube.position.x = radius * Math.cos(theta);
        relayCube.position.z = radius * Math.sin(theta);
        
        // Rest the cube perfectly on the ground
        relayCube.position.y = 0.5; 

        // Rotate the cube so it faces the center of the circle!
        relayCube.rotation.y = -theta;

        // Apply a glowing tactical material
        let cubeMat = new BABYLON.StandardMaterial("mat" + i, scene);
        cubeMat.diffuseColor = new BABYLON.Color3(0, 1, 1);
        cubeMat.emissiveColor = new BABYLON.Color3(0, 0.5, 0.8);
        relayCube.material = cubeMat;
    }

    return scene;
};

const tacticalScene = createScene();

engine.runRenderLoop(function () {
    tacticalScene.render();
});

window.addEventListener("resize", function () {
    engine.resize();
});

Astrometrics Math: Sine & Cosine

Radians vs Degrees: In standard geometry, a circle is 360 degrees. However, programming languages (including JavaScript and Babylon.js) calculate angles using Radians. A full circle in radians is equal to Math.PI * 2.

Cosine (The X-Axis): When calculating coordinates on a circle, the Cosine of the angle determines the horizontal distance from the center.

Sine (The Z-Axis): Because we are laying our circle flat on the ground, we use the Sine of the angle to determine the forward/backward "depth" distance from the center.

Dynamic Rotation: Did you notice how every cube physically points toward the center of the grid? By setting relayCube.rotation.y = -theta, we commanded Babylon to apply our exact trig angle to the physical rotation of the mesh!
