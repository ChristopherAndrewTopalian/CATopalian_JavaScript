Babylon.js: Tactical Trigonometry (XY Plane)

While holographic interfaces are often placed flat on the ground, officers frequently need to interact with vertical displays! Imagine standing on the bridge and looking directly at a circular target-lock or a shield modulation ring hovering in the air. To stand a holographic circle up like a Ferris wheel, we simply take our Trigonometry and map it to the X and Y axes instead of X and Z! 

// Initialize Engine and Canvas
const canvas = document.getElementById("renderCanvas");
const engine = new BABYLON.Engine(canvas, true, {}, true);

const createScene = function () {
    const scene = new BABYLON.Scene(engine);
    scene.clearColor = new BABYLON.Color4(0.05, 0.05, 0.1, 1); 

    // We adjust our camera slightly so we are looking straight at the vertical ring
    const camera = new BABYLON.ArcRotateCamera("MainCamera", Math.PI / 2, Math.PI / 2.5, 25, BABYLON.Vector3.Zero(), scene);
    camera.attachControl(canvas, false);

    const light = new BABYLON.HemisphericLight("Starlight", new BABYLON.Vector3(0, 1, 0), scene);
    light.intensity = 0.8;

    // Build the Tactical Base Plane
    const tacticalPlane = BABYLON.MeshBuilder.CreateGround("BasePlane", {width: 20, height: 20, subdivisions: 10}, scene);
    const gridMaterial = new BABYLON.StandardMaterial("GridMat", scene);
    gridMaterial.wireframe = true; 
    gridMaterial.emissiveColor = new BABYLON.Color3(0, 0.3, 0); 
    tacticalPlane.material = gridMaterial;

    // VERTICAL TRIGONOMETRY RING
    const numberOfCubes = 16;
    const radius = 6; 
    const heightOffset = 8; // We need to lift the center of the wheel off the ground!

    for (let i = 0; i < numberOfCubes; i++) {
        
        let theta = (i / numberOfCubes) * (Math.PI * 2);

        // Create the cube, but lets us stretch it to look like a shield emitter!
        let relayCube = BABYLON.MeshBuilder.CreateBox("cube" + i, {height: 0.5, width: 2, depth: 0.5}, scene);

        // Map the Trigonometry to the X and Y axes!
        relayCube.position.x = radius * Math.cos(theta);
        
        // We add our heightOffset so the bottom of the wheel doesn't clip through the floor
        relayCube.position.y = (radius * Math.sin(theta)) + heightOffset; 
        
        // Z remains at 0 so it stays perfectly flat against our imaginary vertical wall
        relayCube.position.z = 0; 

        // Rotate the mesh around the Z-axis so the emitters face the center
        relayCube.rotation.z = theta;

        // Apply a Tactical Amber glowing material
        let cubeMat = new BABYLON.StandardMaterial("mat" + i, scene);
        cubeMat.diffuseColor = new BABYLON.Color3(1, 0.6, 0);
        cubeMat.emissiveColor = new BABYLON.Color3(0.8, 0.4, 0);
        relayCube.material = cubeMat;
    }

    return scene;
};

const tacticalScene = createScene();

engine.runRenderLoop(function () {
    tacticalScene.render();
});

window.addEventListener("resize", function () {
    engine.resize();
});

Astrometrics Math: The Vertical Shift

The Y-Axis: When calculating a flat ground array (the XZ plane), the Sine function is used on the Z-axis to create depth. By moving that exact same math to the Y-axis (Y = Radius * Sine(theta)), we translate that depth into vertical height!

The Height Offset: Math doesn't know about physical floors; it centers itself on zero. If our radius is 6, the lowest point of our circle drops to -6. By adding our heightOffset variable to the Y position, we dynamically elevate the entire structure so it hovers safely above the tactical grid.

The Z-Rotation: Because the orientation of our meshes has changed, applying rotation to the Y-axis would spin them like tops. To make them face inward along this new vertical plane, we apply the theta angle to the Z-axis instead (relayCube.rotation.z = theta).
