Babylon.js: Materials and the Tactical Grid

A holodeck simulation isn't very useful if everything looks like white clay! In 3D engines, the shape of an object (the Mesh) and the way it looks (the Material) are two completely separate things. You construct the shape first, and then you "wrap" it in a Material. Today, we are going to create a classic StandardMaterial. We will turn our base plane into a glowing wireframe tactical grid, and we will paint our spatial anomaly a dangerous alert red! 

// Initialize Engine and Canvas
const canvas = document.getElementById("renderCanvas");
const engine = new BABYLON.Engine(canvas, true, {}, true);

const createScene = function () {
    const scene = new BABYLON.Scene(engine);
    scene.clearColor = new BABYLON.Color4(0.05, 0.05, 0.1, 1); 

    const camera = new BABYLON.ArcRotateCamera("MainCamera", Math.PI / 2, Math.PI / 3, 10, BABYLON.Vector3.Zero(), scene);
    // Notice the "false" here! This stops the web page from scrolling when we zoom!
    camera.attachControl(canvas, false);

    const light = new BABYLON.HemisphericLight("Starlight", new BABYLON.Vector3(1, 1, 0), scene);
    light.intensity = 0.8;

    // Build the Meshes (Shapes)
    // We add "subdivisions: 10" so our plane has internal grid lines!
    const tacticalPlane = BABYLON.MeshBuilder.CreateGround("BasePlane", {width: 10, height: 10, subdivisions: 10}, scene);
    
    const anomalySphere = BABYLON.MeshBuilder.CreateSphere("AnomalyAlpha", {diameter: 2, segments: 32}, scene);
    anomalySphere.position.y = 1;

    // Create a Wireframe Material for the Tactical Grid
    const gridMaterial = new BABYLON.StandardMaterial("GridMat", scene);
    gridMaterial.wireframe = true; // This forces the engine to only draw the lines!
    gridMaterial.emissiveColor = new BABYLON.Color3(0, 1, 0); // Glowing tactical green
    
    // Apply the material to the plane
    tacticalPlane.material = gridMaterial;

    // Create a Solid Red Material for the Anomaly
    const alertMaterial = new BABYLON.StandardMaterial("AlertMat", scene);
    alertMaterial.diffuseColor = new BABYLON.Color3(1, 0, 0); // Solid Red
    
    // Apply the material to the sphere
    anomalySphere.material = alertMaterial;

    return scene;
};

const tacticalScene = createScene();

engine.runRenderLoop(function () {
    tacticalScene.render();
});

window.addEventListener("resize", function () {
    engine.resize();
});

The Science of Materials

Colors in Babylon: Unlike standard web design that uses rgb(255, 0, 0), Babylon uses a Color3 system based on percentages from 0 to 1. So, pure red is (1, 0, 0), pure green is (0, 1, 0), and pure blue is (0, 0, 1)!

Diffuse vs. Emissive: diffuseColor is the base color of an object when a light shines on it (like paint). emissiveColor makes the object look like it is glowing from the inside, ignoring shadows entirely. Perfect for holograms and LED lights!
