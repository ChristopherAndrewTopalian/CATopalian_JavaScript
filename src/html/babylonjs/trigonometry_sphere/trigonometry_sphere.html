Babylon.js: The Trigonometric Sphere

We have successfully charted the XZ, XY, and YZ planes. Now, it is time to combine them into a single, unified holographic structure! By running all three trigonometric formulas simultaneously inside a single loop, we can generate an intersecting spherical matrix. This is the exact underlying geometry used to build deflector shields, navigational gyroscopes, and planetary containment fields! 

// Initialize Engine and Canvas
const canvas = document.getElementById("renderCanvas");
const engine = new BABYLON.Engine(canvas, true, {}, true);

const createScene = function () {
    const scene = new BABYLON.Scene(engine);
    scene.clearColor = new BABYLON.Color4(0.05, 0.05, 0.1, 1); 

    // Position the camera to get a beautiful angled view of the sphere
    const camera = new BABYLON.ArcRotateCamera("MainCamera", Math.PI / 4, Math.PI / 3, 30, BABYLON.Vector3.Zero(), scene);
    camera.attachControl(canvas, false);

    const light = new BABYLON.HemisphericLight("Starlight", new BABYLON.Vector3(0, 1, 0), scene);
    light.intensity = 0.8;

    // Build the Tactical Base Plane
    const tacticalPlane = BABYLON.MeshBuilder.CreateGround("BasePlane", {width: 25, height: 25, subdivisions: 10}, scene);
    const gridMaterial = new BABYLON.StandardMaterial("GridMat", scene);
    gridMaterial.wireframe = true; 
    gridMaterial.emissiveColor = new BABYLON.Color3(0, 0.3, 0); 
    tacticalPlane.material = gridMaterial;

    // THE UNIFIED SPHERE
    const numberOfCubes = 16;
    const radius = 8; 
    const heightOffset = 10; // The shared center point hovering above the grid

    // We create our 3 distinct colored materials first so we can reuse them efficiently
    const matCyan = new BABYLON.StandardMaterial("matCyan", scene);
    matCyan.emissiveColor = new BABYLON.Color3(0, 0.8, 1);

    const matAmber = new BABYLON.StandardMaterial("matAmber", scene);
    matAmber.emissiveColor = new BABYLON.Color3(1, 0.6, 0);

    const matMagenta = new BABYLON.StandardMaterial("matMagenta", scene);
    matMagenta.emissiveColor = new BABYLON.Color3(0.8, 0, 0.8);

    // A single, highly efficient loop generates all 72 cubes!
    for (let i = 0; i < numberOfCubes; i++) {
        
        let theta = (i / numberOfCubes) * (Math.PI * 2);

        // THE HORIZONTAL RING (XZ Plane - Cyan)
        let cubeXZ = BABYLON.MeshBuilder.CreateBox("xz" + i, {size: 1.2}, scene);
        cubeXZ.position.x = radius * Math.cos(theta);
        cubeXZ.position.z = radius * Math.sin(theta);
        cubeXZ.position.y = heightOffset; // Locked to the center height
        cubeXZ.rotation.y = -theta;
        cubeXZ.material = matCyan;

        // THE VERTICAL FRONT RING (XY Plane - Amber)
        let cubeXY = BABYLON.MeshBuilder.CreateBox("xy" + i, {size: 1.2}, scene);
        cubeXY.position.x = radius * Math.cos(theta);
        cubeXY.position.y = (radius * Math.sin(theta)) + heightOffset; 
        cubeXY.position.z = 0; // Locked to the center depth
        cubeXY.rotation.z = theta;
        cubeXY.material = matAmber;

        // THE VERTICAL SIDE RING (YZ Plane - Magenta)
        let cubeYZ = BABYLON.MeshBuilder.CreateBox("yz" + i, {size: 1.2}, scene);
        cubeYZ.position.x = 0; // Locked to the center width
        cubeYZ.position.y = (radius * Math.sin(theta)) + heightOffset; 
        cubeYZ.position.z = radius * Math.cos(theta);
        cubeYZ.rotation.x = theta;
        cubeYZ.material = matMagenta;
    }

    return scene;
};

const tacticalScene = createScene();

engine.runRenderLoop(function () {
    tacticalScene.render();
});

window.addEventListener("resize", function () {
    engine.resize();
});

Astrometrics Math: The Shared Origin

Loop Efficiency: Because all three circles require the exact same fractional angle to space their cubes evenly, we do not need three separate for loops. By calculating theta once per cycle, we can perfectly synchronize the construction of the entire sphere.

The Unified Core: A sphere is just a series of circles that all share the exact same center point. Notice how every single ring utilizes the heightOffset variable? By locking the XZ ring's Y-position, the XY ring's Z-position, and the YZ ring's X-position to the exact same central coordinate (0, 10, 0), the three dimensions intersect flawlessly.
