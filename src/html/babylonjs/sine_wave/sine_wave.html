Babylon.js: The Subspace Sine Wave

Trigonometry is not just for building circles; it is the fundamental mathematics of frequencies, vibrations, and energy! When scanning for subspace distress beacons or analyzing warp plasma flow, officers must comprehend wave mechanics. By taking the Math.sin() function and unrolling it across a straight line, we reveal the beautiful, oscillating geometry of a pure Sine Wave. 

// Initialize Engine and Canvas
const canvas = document.getElementById("renderCanvas");
const engine = new BABYLON.Engine(canvas, true, {}, true);

const createScene = function () {
    const scene = new BABYLON.Scene(engine);
    scene.clearColor = new BABYLON.Color4(0.05, 0.05, 0.1, 1); 

    // Position the camera to look straight at the wave like a 2D monitor
    const camera = new BABYLON.ArcRotateCamera("MainCamera", Math.PI / 2, Math.PI / 2.2, 35, BABYLON.Vector3.Zero(), scene);
    camera.attachControl(canvas, false);

    const light = new BABYLON.HemisphericLight("Starlight", new BABYLON.Vector3(0, 1, 0), scene);
    light.intensity = 0.8;

    // Build the Tactical Base Plane
    const tacticalPlane = BABYLON.MeshBuilder.CreateGround("BasePlane", {width: 30, height: 10, subdivisions: 10}, scene);
    const gridMaterial = new BABYLON.StandardMaterial("GridMat", scene);
    gridMaterial.wireframe = true; 
    gridMaterial.emissiveColor = new BABYLON.Color3(0, 0.3, 0); 
    tacticalPlane.material = gridMaterial;

    // THE SUBSPACE SINE WAVE
    const numberOfNodes = 60; // How many spheres make up our wave
    const spacing = 0.4;      // How far apart each sphere is
    const startX = -12;       // Start the wave on the far left of the grid
    const amplitude = 4;      // How tall the wave gets
    const heightOffset = 6;   // Lift the whole wave off the floor

    // Create a glowing Subspace Blue material
    const waveMat = new BABYLON.StandardMaterial("waveMat", scene);
    waveMat.diffuseColor = new BABYLON.Color3(0.2, 0.6, 1);
    waveMat.emissiveColor = new BABYLON.Color3(0.1, 0.4, 0.8);

    for (let i = 0; i < numberOfNodes; i++) {
        
        // Calculate the X position (marching in a straight line)
        let currentX = startX + (i * spacing);

        // Map the Y position to the Sine of X!
        // We multiply by amplitude to make the wave taller.
        let currentY = (Math.sin(currentX) * amplitude) + heightOffset;

        // Create the energy node (sphere)
        let energyNode = BABYLON.MeshBuilder.CreateSphere("node" + i, {diameter: 0.6}, scene);

        // Apply the coordinates
        energyNode.position.x = currentX;
        energyNode.position.y = currentY;
        energyNode.position.z = 0; // Lock it perfectly flat against the Z-axis
        
        energyNode.material = waveMat;
    }

    return scene;
};

const tacticalScene = createScene();

engine.runRenderLoop(function () {
    tacticalScene.render();
});

window.addEventListener("resize", function () {
    engine.resize();
});

Astrometrics Math: Unrolling the Wave

The Linear X-Axis: In our circle modules, we used fractions of Math.PI to bend our objects into a ring. Here, we simply let the X-axis march forward in a straight line (currentX = startX + spacing).

The Oscillating Y-Axis: Because the Sine function naturally outputs a smooth, repeating pattern of numbers between -1 and 1, feeding our linear X-value into Math.sin(currentX) automatically generates the peaks and valleys of a wave!

Amplitude: A raw Sine wave is very shallow. By multiplying the result of the Sine calculation by our amplitude variable (Math.sin(currentX) * 4), we stretch the wave vertically, creating massive, towering energy spikes!
