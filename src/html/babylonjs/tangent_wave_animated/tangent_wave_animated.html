Babylon.js: Live Tachyon Burst (Animated Tangent)

A stable warp field flows like a Sine wave, but a ruptured subspace manifold is violent and unpredictable. By adding a time-based phase shift to the Math.tan() function, we can observe tachyons propagating through real-space. Watch as the energy nodes spike toward infinity, hit the mathematical asymptote, and re-enter the scan grid from the opposite extreme! 

// Initialize Engine and Canvas
const canvas = document.getElementById("renderCanvas");
const engine = new BABYLON.Engine(canvas, true, {}, true);

const createScene = function () {
    const scene = new BABYLON.Scene(engine);
    scene.clearColor = new BABYLON.Color4(0.05, 0.0, 0.05, 1); // Purple tint

    const camera = new BABYLON.ArcRotateCamera("MainCamera", Math.PI / 2, Math.PI / 2.2, 35, BABYLON.Vector3.Zero(), scene);
    camera.attachControl(canvas, false);

    const light = new BABYLON.HemisphericLight("Starlight", new BABYLON.Vector3(0, 1, 0), scene);
    light.intensity = 0.8;

    // Build the Tactical Base Plane (Red Alert)
    const tacticalPlane = BABYLON.MeshBuilder.CreateGround("BasePlane", {width: 30, height: 10, subdivisions: 10}, scene);
    const gridMaterial = new BABYLON.StandardMaterial("GridMat", scene);
    gridMaterial.wireframe = true; 
    gridMaterial.emissiveColor = new BABYLON.Color3(0.3, 0, 0); 
    tacticalPlane.material = gridMaterial;

    // THE LIVE TACHYON BURST
    const numberOfNodes = 120; // High node count for smooth curves
    const spacing = 0.2;      
    const startX = -12;       
    const amplitude = 2;      
    const heightOffset = 6;   

    // Tachyon Orange/Red material
    const waveMat = new BABYLON.StandardMaterial("waveMat", scene);
    waveMat.diffuseColor = new BABYLON.Color3(1, 0.4, 0.1);
    waveMat.emissiveColor = new BABYLON.Color3(0.8, 0.2, 0.0);

    // Array to hold our volatile nodes
    const waveNodes = [];

    for (let i = 0; i < numberOfNodes; i++) {
        
        let currentX = startX + (i * spacing);
        let currentY = (Math.tan(currentX) * amplitude) + heightOffset;

        let energyNode = BABYLON.MeshBuilder.CreateSphere("node" + i, {diameter: 0.4}, scene);

        energyNode.position.x = currentX;
        energyNode.position.y = currentY;
        energyNode.position.z = 0; 
        
        energyNode.material = waveMat;

        // Save the node and its starting X position for the animation loop
        waveNodes.push({
            mesh: energyNode,
            baseX: currentX
        });
    }

    // ANIMATION: The Volatile Propagation
    let time = 0;
    const waveSpeed = 0.03; // Slightly slower so the cadets can track the spikes

    scene.onBeforeRenderObservable.add(function () {
        // Increment time every frame
        time += waveSpeed;

        for (let i = 0; i < waveNodes.length; i++) {
            let nodeData = waveNodes[i];
            
            // The phase shift applied to the Tangent function!
            let newY = (Math.tan(nodeData.baseX - time) * amplitude) + heightOffset;
            
            nodeData.mesh.position.y = newY;
        }
    });

    return scene;
};

const tacticalScene = createScene();

engine.runRenderLoop(function () {
    tacticalScene.render();
});

window.addEventListener("resize", function () {
    engine.resize();
});

Astrometrics Math: Asymptotic Motion

The Illusion of Jumping: In Babylon.js, as the time variable pushes the mathematical result of Math.tan() incredibly high, the spheres physically fly off the top edge of our camera view. In the very next microsecond, the math crosses the asymptote, resulting in an incredibly deep negative number, and the sphere instantly appears at the bottom of the grid, rushing upwards again!

Speed Regulation: You may notice we set the waveSpeed to 0.03 instead of the 0.05 we used for Sine and Cosine. Because the Tangent wave curves so violently near its asymptotes, slowing the animation slightly allows our tactical displays (and human eyes) to process the chaotic movement without blurring.
