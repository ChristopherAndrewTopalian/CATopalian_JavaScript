Babylon.js: Textures and Security Protocols

Our patrol drones have successfully scanned the spatial anomaly, and the data is returning a high-resolution visual! It is time to upgrade our flat colors into realistic Textures. A texture is simply a 2D image (like a JPG or PNG) that the engine mathematically wraps around a 3D shape. However, to view textures on your own computer, you must run a Local Web Server. Browser security protocols will block 3D engines from stealing files off your hard drive if you just double-click the HTML file. We recommend installing the "Live Server" extension in VS Code to easily open a secure comms channel!

Alternatively we could start a server with Node.js,
or we could use NW.js if we add a package.json so we can easily drop our folder onto the NW.exe icon
or we could just upload our files to github and publish it with github pages to see the textures work, as long as the textures are also on the github server.

Ways to View our Textures in 3D

1. Live Server Extension VSCode
2. NW.js exe
3. Node.js Server
4. Github Pages
5. Any free web server online 

// Initialize Engine and Canvas
const canvas = document.getElementById("renderCanvas");
const engine = new BABYLON.Engine(canvas, true, {}, true);

const createScene = function () {
    const scene = new BABYLON.Scene(engine);
    scene.clearColor = new BABYLON.Color4(0.05, 0.05, 0.1, 1); 

    const camera = new BABYLON.ArcRotateCamera("MainCamera", Math.PI / 2, Math.PI / 3, 10, BABYLON.Vector3.Zero(), scene);
    camera.attachControl(canvas, false);

    const light = new BABYLON.HemisphericLight("Starlight", new BABYLON.Vector3(1, 1, 0), scene);
    light.intensity = 0.8;

    // Build the Grid
    const tacticalPlane = BABYLON.MeshBuilder.CreateGround("BasePlane", {width: 15, height: 15, subdivisions: 15}, scene);
    const gridMaterial = new BABYLON.StandardMaterial("GridMat", scene);
    gridMaterial.wireframe = true; 
    gridMaterial.emissiveColor = new BABYLON.Color3(0, 0.6, 0); 
    tacticalPlane.material = gridMaterial;

    // Reveal the Anomaly: Klingon Vessel!
    const anomalySphere = BABYLON.MeshBuilder.CreateSphere("KlingonShip", {diameter: 2, segments: 32}, scene);
    anomalySphere.position.y = 1;
    
    // Instead of a diffuseColor, we load a diffuseTexture from our media database!
    const klingonMaterial = new BABYLON.StandardMaterial("KlingonMat", scene);
    klingonMaterial.diffuseTexture = new BABYLON.Texture("textures/klingon_hull.jpg", scene);
    anomalySphere.material = klingonMaterial;

    // Texture the Starfleet Drones
    const innerDrone = BABYLON.MeshBuilder.CreateSphere("InnerScout", {diameter: 0.8, segments: 16}, scene);
    innerDrone.position.y = 1; 
    innerDrone.position.x = 4; // Positioned statically for the texture inspection
    
    const starfleetMaterial = new BABYLON.StandardMaterial("StarfleetMat", scene);
    starfleetMaterial.diffuseTexture = new BABYLON.Texture("textures/recon_drone.jpg", scene);
    // We can also add emissive color to make the texture glow slightly!
    starfleetMaterial.emissiveColor = new BABYLON.Color3(0, 0.2, 0.5); 
    
    innerDrone.material = starfleetMaterial;

    return scene;
};

const tacticalScene = createScene();

// We removed the animation math to focus purely on inspecting our new textures!
engine.runRenderLoop(function () {
    tacticalScene.render();
});

window.addEventListener("resize", function () {
    engine.resize();
});

The Science of Texturing

The Texture Object: By calling new BABYLON.Texture("path/to/image.jpg", scene), we load an image file straight into the graphics card's memory.

UV Mapping: How does the engine know how to wrap a flat rectangular image around a round sphere without stretching it weirdly? Babylon primitives (like CreateSphere) come automatically unwrapped with mathematical UV coordinates. It automatically pinches the top and bottom of your JPG to fit perfectly over the poles of the sphere!
