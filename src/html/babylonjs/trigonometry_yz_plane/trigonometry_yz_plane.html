Babylon.js: Tactical Trigonometry (YZ Plane)

To complete our Astrometrics training, we must master the final dimension: the sideways vertical ring. Think of the massive containment rings around a starship's warp nacelles, or a lateral sensor sweep arching over the ship. To achieve this, we lock the X-axis in place and map our Trigonometry purely to the Y and Z axes! 

// Initialize Engine and Canvas
const canvas = document.getElementById("renderCanvas");
const engine = new BABYLON.Engine(canvas, true, {}, true);

const createScene = function () {
    const scene = new BABYLON.Scene(engine);
    scene.clearColor = new BABYLON.Color4(0.05, 0.05, 0.1, 1); 

    // Position the camera at a perfect 45-degree angle so we can clearly see the side-facing ring
    const camera = new BABYLON.ArcRotateCamera("MainCamera", Math.PI / 4, Math.PI / 2.5, 25, BABYLON.Vector3.Zero(), scene);
    camera.attachControl(canvas, false);

    const light = new BABYLON.HemisphericLight("Starlight", new BABYLON.Vector3(0, 1, 0), scene);
    light.intensity = 0.8;

    // Build the Tactical Base Plane
    const tacticalPlane = BABYLON.MeshBuilder.CreateGround("BasePlane", {width: 20, height: 20, subdivisions: 10}, scene);
    const gridMaterial = new BABYLON.StandardMaterial("GridMat", scene);
    gridMaterial.wireframe = true; 
    gridMaterial.emissiveColor = new BABYLON.Color3(0, 0.3, 0); 
    tacticalPlane.material = gridMaterial;

    // LATERAL TRIGONOMETRY RING
    const numberOfCubes = 16;
    const radius = 6; 
    const heightOffset = 8; // Lift the center off the floor

    for (let i = 0; i < numberOfCubes; i++) {
        
        let theta = (i / numberOfCubes) * (Math.PI * 2);

        // We make the width 2 so it stretches across the X-axis like an archway!
        let relayCube = BABYLON.MeshBuilder.CreateBox("cube" + i, {height: 0.5, width: 2, depth: 0.5}, scene);

        // Lock the X-axis to 0
        relayCube.position.x = 0;

        // Map the Y-axis to Sine (Vertical Height) + the floor offset
        relayCube.position.y = (radius * Math.sin(theta)) + heightOffset; 

        // Map the Z-axis to Cosine (Forward/Backward Depth)
        relayCube.position.z = radius * Math.cos(theta); 

        // Rotate the mesh around the X-axis so the flat emitters face the center of the ring
        relayCube.rotation.x = theta;

        // Apply a Tactical Magenta glowing material
        let cubeMat = new BABYLON.StandardMaterial("mat" + i, scene);
        cubeMat.diffuseColor = new BABYLON.Color3(1, 0, 1);
        cubeMat.emissiveColor = new BABYLON.Color3(0.6, 0, 0.6);
        relayCube.material = cubeMat;
    }

    return scene;
};

const tacticalScene = createScene();

engine.runRenderLoop(function () {
    tacticalScene.render();
});

window.addEventListener("resize", function () {
    engine.resize();
});

Astrometrics Math: The Lateral Shift

The Z-Axis: Just like we mapped the Cosine to the X-axis to push objects left and right, we map the Cosine to the Z-axis (Z = Radius * Cosine(theta)) to push our ring forward and backward across the grid.

The X-Rotation: The physical orientation of a mesh changes depending on which plane it lives on. Because this ring is standing up sideways, applying rotation to the Z or Y axis would twist the meshes out of alignment. To make them face inward along the YZ plane, we apply the theta angle directly to the X-axis (relayCube.rotation.x = theta).
