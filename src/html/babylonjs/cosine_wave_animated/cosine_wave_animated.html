Babylon.js: Phase-Shifted Telemetry (Animated Cosine)

In engineering and wave mechanics, it is crucial to understand phase. The Math.cos() function generates a wave identical in shape and size to the Sine wave, but it is phase-shifted. While a Sine wave begins at zero and rises, a Cosine wave begins at its maximum amplitude. Animating this wave allows engineers to monitor secondary power couplings and structural integrity fields in real-time. 

// Initialize Engine and Canvas
const canvas = document.getElementById("renderCanvas");
const engine = new BABYLON.Engine(canvas, true, {}, true);

const createScene = function () {
    const scene = new BABYLON.Scene(engine);
    scene.clearColor = new BABYLON.Color4(0.1, 0.08, 0.05, 1); 

    const camera = new BABYLON.ArcRotateCamera("MainCamera", Math.PI / 2, Math.PI / 2.2, 35, BABYLON.Vector3.Zero(), scene);
    camera.attachControl(canvas, false);

    const light = new BABYLON.HemisphericLight("Starlight", new BABYLON.Vector3(0, 1, 0), scene);
    light.intensity = 0.8;

    const tacticalPlane = BABYLON.MeshBuilder.CreateGround("BasePlane", {width: 30, height: 10, subdivisions: 10}, scene);
    const gridMaterial = new BABYLON.StandardMaterial("GridMat", scene);
    gridMaterial.wireframe = true; 
    gridMaterial.emissiveColor = new BABYLON.Color3(0.3, 0.2, 0); 
    tacticalPlane.material = gridMaterial;

    // THE PHASE-SHIFTED COSINE WAVE
    const numberOfNodes = 60; 
    const spacing = 0.4;      
    const startX = -12;       
    const amplitude = 4;      
    const heightOffset = 6;   

    // Create a glowing Engineering Gold material
    const waveMat = new BABYLON.StandardMaterial("waveMat", scene);
    waveMat.diffuseColor = new BABYLON.Color3(0.9, 0.7, 0.1);
    waveMat.emissiveColor = new BABYLON.Color3(0.8, 0.5, 0.0);

    const waveNodes = [];

    for (let i = 0; i < numberOfNodes; i++) {
        
        let currentX = startX + (i * spacing);
        
        // Map the Y position to the Cosine of X
        let currentY = (Math.cos(currentX) * amplitude) + heightOffset;

        let energyNode = BABYLON.MeshBuilder.CreateSphere("node" + i, {diameter: 0.6}, scene);

        energyNode.position.x = currentX;
        energyNode.position.y = currentY;
        energyNode.position.z = 0; 
        
        energyNode.material = waveMat;

        waveNodes.push({
            mesh: energyNode,
            baseX: currentX
        });
    }

    // ANIMATION: The Sensor Sweep
    let time = 0;
    const waveSpeed = 0.05; 

    scene.onBeforeRenderObservable.add(function () {
        time += waveSpeed;

        for (let i = 0; i < waveNodes.length; i++) {
            let nodeData = waveNodes[i];
            
            // Calculate the new Y using Math.cos()
            let newY = (Math.cos(nodeData.baseX - time) * amplitude) + heightOffset;
            
            nodeData.mesh.position.y = newY;
        }
    });

    return scene;
};

const tacticalScene = createScene();

engine.runRenderLoop(function () {
    tacticalScene.render();
});

window.addEventListener("resize", function () {
    engine.resize();
});

Astrometrics Math: The Cosine Shift

The Code Difference: The only mathematical difference between this module and the previous one is swapping Math.sin() for Math.cos() in both the initial loop and the render loop.

The Visual Difference: Because Math.cos(0) equals 1 (whereas Math.sin(0) equals 0), the Cosine wave starts at its highest peak. If you were to place this Gold wave directly on top of the Blue Sine wave, you would see the Gold wave "leading" the Blue wave by a quarter of a wavelength across the grid.
