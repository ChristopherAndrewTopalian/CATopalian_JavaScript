Babylon.js: Live Subspace Telemetry (Animated Sine)

A static sensor scan is rarely enough. To properly calibrate the deflector dish, Astrometrics must analyze wave propagation in real-time! By adding a continuously updating time variable to our X-axis coordinates before running them through the Math.sin() function, we can shift the phase of the wave, creating a flowing animation of pure energy. 

// Initialize Engine and Canvas
const canvas = document.getElementById("renderCanvas");
const engine = new BABYLON.Engine(canvas, true, {}, true);

const createScene = function () {
    const scene = new BABYLON.Scene(engine);
    scene.clearColor = new BABYLON.Color4(0.05, 0.05, 0.1, 1); 

    const camera = new BABYLON.ArcRotateCamera("MainCamera", Math.PI / 2, Math.PI / 2.2, 35, BABYLON.Vector3.Zero(), scene);
    camera.attachControl(canvas, false);

    const light = new BABYLON.HemisphericLight("Starlight", new BABYLON.Vector3(0, 1, 0), scene);
    light.intensity = 0.8;

    const tacticalPlane = BABYLON.MeshBuilder.CreateGround("BasePlane", {width: 30, height: 10, subdivisions: 10}, scene);
    const gridMaterial = new BABYLON.StandardMaterial("GridMat", scene);
    gridMaterial.wireframe = true; 
    gridMaterial.emissiveColor = new BABYLON.Color3(0, 0.3, 0); 
    tacticalPlane.material = gridMaterial;

    // THE SUBSPACE SINE WAVE
    const numberOfNodes = 60; 
    const spacing = 0.4;      
    const startX = -12;       
    const amplitude = 4;      
    const heightOffset = 6;   

    const waveMat = new BABYLON.StandardMaterial("waveMat", scene);
    waveMat.diffuseColor = new BABYLON.Color3(0.2, 0.6, 1);
    waveMat.emissiveColor = new BABYLON.Color3(0.1, 0.4, 0.8);

    // Array to hold our nodes so we can update them later
    const waveNodes = [];

    for (let i = 0; i < numberOfNodes; i++) {
        
        let currentX = startX + (i * spacing);
        let currentY = (Math.sin(currentX) * amplitude) + heightOffset;

        let energyNode = BABYLON.MeshBuilder.CreateSphere("node" + i, {diameter: 0.6}, scene);

        energyNode.position.x = currentX;
        energyNode.position.y = currentY;
        energyNode.position.z = 0; 
        
        energyNode.material = waveMat;

        // Save the node and its starting X position for the animation loop
        waveNodes.push({
            mesh: energyNode,
            baseX: currentX
        });
    }

    // ANIMATION: The Sensor Sweep
    let time = 0;
    const waveSpeed = 0.05; // How fast the wave travels

    scene.onBeforeRenderObservable.add(function () {
        // Increment time every frame
        time += waveSpeed;

        // Loop through all our saved nodes and update their Y position
        for (let i = 0; i < waveNodes.length; i++) {
            let nodeData = waveNodes[i];
            
            // Add 'time' to the baseX to shift the wave left/right
            // Subtracting time makes it move right, adding makes it move left!
            let newY = (Math.sin(nodeData.baseX - time) * amplitude) + heightOffset;
            
            nodeData.mesh.position.y = newY;
        }
    });

    return scene;
};

const tacticalScene = createScene();

engine.runRenderLoop(function () {
    tacticalScene.render();
});

window.addEventListener("resize", function () {
    engine.resize();
});

Astrometrics Math: Wave Propagation

The Storage Array: To animate objects in a 3D engine, we need a way to reference them after they are built. We created an empty array const waveNodes = [] and pushed each sphere into it, along with its permanent X-axis position.

The Render Loop: Babylon.js uses scene.onBeforeRenderObservable.add() to run code right before a new frame is drawn to the screen. This is where our engine room does the heavy lifting!

Phase Shifting: By taking our base X position and subtracting our constantly growing time variable (nodeData.baseX - time), we trick the Sine function into thinking the X-axis is sliding sideways. This translates into smooth, vertical Y-axis updates that create the illusion of forward momentum!
