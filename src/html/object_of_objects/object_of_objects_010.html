The Automated Shipyard (Factory Functions)

Deep cloning an existing object is safe, but it requires a lot of computing power. If Starfleet needs to rapidly deploy hundreds of defense drones in a simulation, manually cloning them will cause the system to lag.

To generate massive amounts of ships efficiently while keeping our code purely functional, we use a Factory Function. Instead of copying an old object, a factory function is simply a machine that takes in raw materials (parameters) and returns a brand-new, completely independent Object every time you call it. 

// Define the Factory Function (The Automated Shipyard)
function createStarship(shipName, shipClass, currentStatus) {
    // Return a completely brand new Object literal
    return {
        name: shipName,
        class: shipClass,
        status: currentStatus,
        shields: 100 // All ships start with 100% shields natively
    };
}

// Initialize the empty Fleet Registry (Our Object of Objects)
let starfleetDatabase = {};

// Rapidly spawn fresh ships directly into the registry
starfleetDatabase.enterprise = createStarship('Enterprise', 'Constitution', 'Active');
starfleetDatabase.defiant = createStarship('Defiant', 'Escort', 'Docked');

// The ships are completely independent and generated instantly
starfleetDatabase.defiant.shields = 50;

console.log(starfleetDatabase.enterprise.shields); // Returns 100
console.log(starfleetDatabase);

/*
100

Object { enterprise: {…}, defiant: {…} }

defiant: Object { name: "Defiant", class: "Escort", status: "Docked", shields: 50 }

enterprise: Object { name: "Enterprise", class: "Constitution", status: "Active", shields: 100 }
*/

Syntax 

function factory(params) { return { key: params }; }
registryObject.keyName = factory(arguments);

Return Value

Type: Object (Returns a fresh, distinct Object instance built exactly to the specifications provided in the function arguments).

Description:

The Factory Function is a highly secure, functional approach to game design and database management. By wrapping an Object literal inside a return statement, you bypass the "Reference Trap" entirely. Every time the function executes, the JavaScript engine allocates a completely new sector of memory for the returned Object. This allows developers to instantly populate multidimensional registries (like an Object of Objects) with hundreds of unique entities without ever risking cross-contamination of their data.
