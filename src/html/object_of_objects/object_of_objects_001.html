The Object of Objects (Nested Data)

A real Starfleet vessel is much more complex than a single word.

To handle complex data, JavaScript allows us to place an Object inside of another Object. This creates a multi-dimensional hierarchical database. Let's upgrade our registry so that each ship's Key points to an entirely new Object containing its complete manifest. 

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        status: 'active' 
    },

    defiant: 
    {
        class: 'escort',
        status: 'docked'
    }
};

console.log(starfleetDatabase);

/*
Object { enterprise: {…}, defiant: {…} }

defiant: Object { class: "escort", status: "docked" }

enterprise: Object { class: "constitution", status: "active" }

: Object { … }
*/

Syntax 

let parentObject = { childObject: { key: "value" } };

Return Value

Type: Object (A hierarchical, multidimensional data structure). Logging the parent Object displays the parent Keys, and indicates that they contain nested child Objects.

Description:

The "Object of Objects" is the architectural foundation of advanced software engineering. By nesting Objects, you create a parent-child relationship in your data. The primary Key (like enterprise) serves as a main directory folder, and the Value is the folder's contents (another Object containing class and status). This allows developers to organize massive, complex amounts of information, like the LCARS system on a starship, while maintaining the instant lookup speeds that Objects are famous for.
