Scanning the Fleet (Iterating Nested Objects)

When dealing with a massive multidimensional database, we don't always know the exact names of the ships stored inside. If Starfleet Command issues an order to pull the records for every vessel in a sector, we need the computer to automate the extraction.

To do this, we combine the for...in loop we learned earlier with bracket notation. The loop acts as a broad-spectrum sensor sweep. It targets each primary folder, extracts its exact name, and immediately uses that name to pull the nested Object stored inside. 

let starfleetDatabase = {
    defiant: 
    {
        class: 'escort',
        status: 'docked'
    },

    enterprise:
    {
        class: 'constitution',
        status: 'active' 
    }
};

// Run a broad sensor sweep to output each nested manifest
for (let vessel in starfleetDatabase)
{
    // 'vessel' holds the string (e.g., 'defiant')
    // starfleetDatabase[vessel] extracts the nested Object
    console.log(starfleetDatabase[vessel]);
}

/*
Object { class: "escort", status: "docked" }

class: "escort"

status: "docked"


Object { class: "constitution", status: "active" }

class: "constitution"

status: "active"
*/

Syntax 

for (let key in parentObject) { 
    console.log(parentObject[key]); 
}

Return Value

Type: Iteration (Retrieves each child Object sequentially from the main database block).

Description:

When a for...in loop executes on a multi-layered Object, the temporary variable (in this case, let vessel) grabs the string name of the top-level Key. To actually access the data inside, you must pass that string variable back into the parent Object using bracket notation (starfleetDatabase[vessel]). The engine steps through every entry, dynamically calculating the coordinates and retrieving the entire nested Object block for each item, without requiring hardcoded Dot Notation.
