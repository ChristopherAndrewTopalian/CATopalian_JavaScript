Filtering the Registry (Maintaining Fast Lookups)

In advanced simulations and game design, maintaining instant O(1) data retrieval is critical for engine performance. If we convert our multidimensional Object into an Array to filter it, we lose our direct comm-links to the ships!

To filter a registry while maintaining our high-speed lookup architecture, we must perform an extraction and a reconstruction. We filter out the vessels we don't need, and immediately rebuild the remaining data back into a pure Object of Objects. 

// Example 1: ES5 Version (The Rebuild Loop)

let starfleetDatabase = {
    enterprise: { class: 'constitution', status: 'active' },
    defiant: { class: 'escort', status: 'active' },
    farragut: { class: 'nebula', status: 'docked' }
};

// Create a brand new empty database
let activeFleet = {};

// Sweep the original database and only copy over the active vessels
for (let key in starfleetDatabase) {
    if (starfleetDatabase[key].status === 'active') {
        activeFleet[key] = starfleetDatabase[key];
    }
}

console.log(activeFleet);

/*
Object { enterprise: {…}, defiant: {…} }

defiant: Object { class: "escort", status: "active" }

enterprise: Object { class: "constitution", status: "active" }
*/

// Example 2: ES6+ Version (Entries to Filter to Object)

let starfleetDatabase = {
    enterprise: { class: 'constitution', status: 'active' },
    defiant: { class: 'escort', status: 'active' },
    farragut: { class: 'nebula', status: 'docked' }
};

// Deconstruct, filter, and reconstruct in one continuous chain
let activeFleet = Object.fromEntries(
    Object.entries(starfleetDatabase).filter(([key, ship]) => ship.status === 'active')
);

console.log(activeFleet);

/*
Object { enterprise: {…}, defiant: {…} }

defiant: Object { class: "escort", status: "active" }

enterprise: Object { class: "constitution", status: "active" }
*/

Syntax (ES5 Version) 

for (let key in oldObject) { if (condition) { newObject[key] = oldObject[key]; } }

Syntax (ES6+ Version) 

Object.fromEntries( Object.entries(oldObject).filter(([key, value]) => condition) );

Return Value

Type: Object (Returns a brand-new Object of Objects, completely separated from the original, containing only the filtered data).

Description:

This tactical maneuver ensures your data remains in a high-performance state. In the ES5 method, we manually construct a new Object and use a standard for...in loop with an if statement to carefully copy over only the matching files. In the ES6+ method, we use Object.entries() to temporarily turn the registry into an Array, run our rapid .filter() command, and then immediately wrap the entire operation in Object.fromEntries(). This specialized command instantly collapses the filtered Array back into a fully functioning, fast-lookup Object.
