Deep Scanning (Double Dot Notation)

In the previous lesson, we retrieved the entire internal manifest for a specific starship. But what if we don't need the whole file? What if the Captain only wants to know the operational status of the Enterprise, and nothing else?

Because we are dealing with an Object inside of an Object, we can chain our comm links together using Double Dot Notation. Each dot tells the engine to step one level deeper into the memory hierarchy. 

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        status: 'active' 
    },

    defiant: 
    {
        class: 'escort',
        status: 'docked'
    }
};

// Drill down to the Enterprise, then retrieve just its class
console.log(starfleetDatabase.enterprise.class);

/*
constitution
*/

Syntax 

parentObject.childObject.propertyName;

Return Value

Type: Variable (Returns the specific data type stored at the final deepest Key, in this case, a String).

Description:

Chaining dot notation is how you navigate multi-dimensional data structures. The engine reads the command from left to right. First, it locates starfleetDatabase. Next, the first dot tells it to open the enterprise folder. Finally, the second dot tells it to extract the specific value attached to the class Key. This precision targeting allows you to instantly extract a single data point from a massive database without loading the entire structure into active memory.
