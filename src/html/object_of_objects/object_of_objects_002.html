Serializing Data (JSON.stringify)

We now have a multi-dimensional database holding the manifest of our fleet. But what if we need to transmit this data across subspace to another starbase? We cannot transmit live JavaScript memory. We must flatten the entire structure into a simple, continuous text format that any computer can read.

To do this, we use the engine's built-in JSON (JavaScript Object Notation) module. Specifically, the stringify() method converts our complex Object of Objects into a single, flat string of text ready for transmission. 

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        status: 'active' 
    },

    defiant: 
    {
        class: 'escort',
        status: 'docked'
    }
};

// Serialize the multidimensional database for transmission
console.log(JSON.stringify(starfleetDatabase));

/*
{"enterprise":{"class":"constitution","status":"active"},"defiant":{"class":"escort","status":"docked"}}
*/

Syntax 

JSON.stringify(objectName);

Return Value

Type: String (Returns a perfectly formatted JSON text string representing the Object and all of its nested children).

Description:

The JSON.stringify() method is an essential serialization tool. When applied to a nested Object, the engine scans the entire multidimensional structure and translates it into a universal text format. Notice in the output that all Keys and String Values are automatically wrapped in double quotes. This resulting string is completely inert, it is no longer a functioning Object, making it perfect for saving to a hard drive, storing in a raw text file, or sending over a network.
