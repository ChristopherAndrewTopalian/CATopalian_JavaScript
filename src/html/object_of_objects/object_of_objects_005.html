Sorting Nested Data

Unlike Arrays, flat Objects and multidimensional Objects do not have a strict, sequential order. They are designed for instant direct-access, not alphabetical lists. However, LCARS interfaces frequently need to display starship manifests alphabetically by class, status, or name.

To sort an Object of Objects, we must execute a two-step maneuver. First, we use Object.entries() to convert the registry into an Array of Arrays. Second, we use the sort() method combined with localeCompare() to compare the specific nested strings and organize the list alphabetically. 

// Example 1: ES5 Version

let starfleetDatabase = {
    defiant: 
    {
        class: 'escort',
        color: 'gray'
    },
    enterprise:
    {
        class: 'constitution',
        color: 'white' 
    }
};

// Convert to array and sort alphabetically by vessel class
let sortedByClass = Object.entries(starfleetDatabase).sort(function(a, b) {
    return a[1].class.localeCompare(b[1].class);
});

console.log(sortedByClass);

/*
Array [ (2) […], (2) […] ]

0: Array [ "enterprise", {…} ]

1: Array [ "defiant", {…} ]

length: 2
*/

// Example 2: ES6 Version

let starfleetDatabase = {
    defiant: 
    {
        class: 'escort',
        color: 'gray'
    },
    enterprise:
    {
        class: 'constitution',
        color: 'white' 
    }
};

// Convert to array and sort alphabetically using Arrow Syntax
let sortedByClass = Object.entries(starfleetDatabase)
    .sort((a, b) => a[1].class.localeCompare(b[1].class));

console.log(sortedByClass);

/*
Array [ (2) […], (2) […] ]

0: Array [ "enterprise", {…} ]

1: Array [ "defiant", {…} ]

length: 2
*/

Syntax (ES5 Version) 

Object.entries(objectName).sort(function(a, b) { 
    return a[1].property.localeCompare(b[1].property); 
});

Syntax (ES6 Version) 

Object.entries(objectName).sort((a, b) => a[1].property.localeCompare(b[1].property));

Return Value

Type: Array (Returns a brand-new, multidimensional Array containing the original Object's keys and nested values, sequenced according to your sorting parameters).

Description:

This operation bridges the gap between Objects and Arrays. Object.entries() takes a flat or nested Object and forces it into an Array format, where each item is a paired list: ["key", {nestedData}]. Because the nested data is pushed into index [1] of these new arrays, our sorting function must target a[1] and b[1] to reach inside the folder and read the specific string (like the ship's class) we want to compare. Finally, localeCompare() handles the complex alphabetization mathematics natively.
