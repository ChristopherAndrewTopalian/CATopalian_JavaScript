Advanced Data Storage (Nested Arrays)

So far, the folders inside our multidimensional database have only held simple text strings. But a real Starfleet vessel requires complex lists—like a cargo manifest, an armaments inventory, or a crew roster.

JavaScript Objects are incredibly flexible. The Value assigned to a Key does not have to be a string or another Object; it can also be an Array. Once we use our dot notation to drill down and retrieve that Array, we can immediately use standard array loops to read the data inside. 

// Example 1: ES5 Version

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        crew: ['Kirk', 'Spock', 'McCoy'] 
    },

    defiant: 
    {
        class: 'escort',
        crew: ['Sisko', 'Kira', 'Dax']
    }
};

// 1. Target the specific ship's crew array
let enterpriseRoster = starfleetDatabase.enterprise.crew;

// 2. Loop through the array using a classic ES5 function
enterpriseRoster.forEach(function(officer) {
    console.log(officer);
});

/*
Kirk
Spock
McCoy
*/

// Example 2: ES6 Version

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        crew: ['Kirk', 'Spock', 'McCoy'] 
    },

    defiant: 
    {
        class: 'escort',
        crew: ['Sisko', 'Kira', 'Dax']
    }
};

// 1. Target the specific ship's crew array
let defiantRoster = starfleetDatabase.defiant.crew;

// 2. Loop through the array using ES6 Arrow Syntax
defiantRoster.forEach(officer => console.log(officer));

/*
Sisko
Kira
Dax
*/

Syntax (ES5 Version) 

parentObject.childObject.arrayName.forEach(function(item) { /* logic */ });

Syntax (ES6 Version) 

parentObject.childObject.arrayName.forEach(item => /* logic */);

Return Value

Type: Iteration (Executes a function for every item inside the targeted nested array).

Description:

This technique demonstrates how different data architectures interact. By chaining double dot notation (starfleetDatabase.enterprise.crew), the engine navigates through the Object layers and returns the Array. Once the engine is holding that Array, it unlocks all native Array methods (like .length, .map(), or .forEach()). You can simply attach the array method directly to the end of your dot notation chain to seamlessly process the nested list.
