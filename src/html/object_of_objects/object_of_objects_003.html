Retrieving a Nested Record (Single Dot Notation)

We know how to build a multidimensional database, and we know how to serialize the entire thing for transmission. But in standard day-to-day operations, you rarely need the entire fleet manifest at once. Usually, you just need to pull the complete file on one specific vessel.

To extract a nested Object from the main registry, we use the exact same Dot Notation we learned with flat Objects. By pointing to the primary Key, the engine will return everything stored inside that coordinate, which, in this case, is an entirely separate Object. 

let starfleetDatabase = {
    enterprise: 
    {
        class: 'constitution',
        status: 'active' 
    },

    defiant: 
    {
        class: 'escort',
        status: 'docked'
    }
};

// Open a direct channel to retrieve the Enterprise's full nested manifest
console.log(starfleetDatabase.enterprise);

/*
Object { class: "constitution", status: "active" }

class: "constitution"

status: "active"

: Object { … }
*/

Syntax 

parentObject.childObject;

Return Value

Type: Object (Returns the inner child Object and all of its properties).

Description:

When dealing with an Object of Objects, using a single level of Dot Notation targets the "folder" rather than the specific files inside. By asking the engine for starfleetDatabase.enterprise, you are instructing it to go to the main registry, find the Enterprise, and hand you the entire block of memory stored there. The engine returns the nested Object exactly as it was written, allowing you to view the ship's full internal specifications at a glance.
